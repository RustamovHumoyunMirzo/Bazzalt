# Gameplay hot reload

Editor/hot_reload.py watches used sources and project includes. A debounced QThread runs ScriptCompiler.Build; versioned digest filenames avoid overwriting loaded native modules. Completion runs on the UI thread, refreshes Lua bytecode and calls the private bridge configure_scripts(..., reload=True). Stop generations discard stale results. Shutdown joins the worker before destroying the runtime.

Engine::ReloadScripts stages the main native/Lua runtimes and each existing streaming-cell runtime. Matching UUID/type pairs migrate state. Candidate Start skips OnCreate and behavior registration. Candidates retain scoped collision subscriptions under their own stable owners. Any precommit failure destroys candidates without OnDestroy and leaves previous live instances registered. All native registrations change before OnReload notifications. Cell ownership remains intact for later unload.

Native generated optional exports enumerate property name/type/text and save/restore custom state. No ScriptModuleApi struct layout changes. Behavior hooks are appended to the existing virtual lifecycle, and older modules without state readers reject preservation. Module jobs are drained before snapshot/unload. Scoped graphics and application listeners are disconnected; OnReload reconnects script subscriptions. Constructors and top-level Lua code must be declarative: arbitrary user side effects are not transactional.

Lua copies supported data using bounded recursive tables between VMs, preserving new methods/defaults. Optional OnSaveReloadState and OnRestoreReloadState hooks project or migrate a data table. New attachments initialize through OnCreate after commit; matched instances receive OnReload. It excludes Entity, functions, closure locals and VM globals. Unsupported state rejects reload rather than silently dropping it. Independent Lua systems owned by other VMs remain untouched. Reloaded systems must be registered again in OnReload. OnReload failures occur after commit and are logged (Lua behavior disabled); no scene/physics rollback is attempted.

Global subsystem lifetimes and compiled engine/extension code are deliberately outside gameplay hot reload. Preserve opaque C++ state through versioned string hooks, not raw memory. Test with BazzaltHotReloadTests and Editor.tests.test_hot_reload, plus scripting/runtime regression suites.
