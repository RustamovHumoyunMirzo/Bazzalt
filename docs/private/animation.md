# Animation pipeline

Public contracts are Animation.h, Animator.h, IKConstraint.h and AnimationSystem.h. Scene automatically owns the system. The animation math/import/runtime code has no Filament types. Engine loop and presentation remain private. C++ and Lua share the same runtime; user code never initializes animation infrastructure.

AnimationRig loads bounded glTF/GLB node TRS tracks and buffer accessors from imported cache paths. Dense float STEP, LINEAR and CUBICSPLINE samplers are validated once; immutable rigs are weak-cached by UUID/path/timestamp. Private SampleAnimationClip bypasses repeated full key validation during playback. Quaternions use slerp for linear tracks and normalized Hermite cubic interpolation. Morph animation, sparse/compressed track data and automatic humanoid definitions are not implemented. Malformed tracks fail explicitly.

Controller assets (.banim, version 1) hold state machines, phase-synchronized 1D/2D freeform trees, numeric conditions and transitions. Timers are per Animator. Crossfades continue the outgoing state; only one automatic transition starts per evaluation. Layers are lexical-order override/additive blends; constraints follow layers. Retargeting can resolve a separate SourceModel, map generic bone names or explicit indices, correct bind rotations and preserve target bone lengths. Imported clips are immutable; graph layout positions are editor-only data ignored by the runtime parser.

Root motion computes unwrapped clip deltas, including loop displacement, before removing root translation/rotation from the visual skeleton. Physics mode submits kinematic movement during fixed animation. Dynamic child rigidbodies retain physics ownership and feed their pose back after stepping. IK helpers can raycast along gravity; all native physics operations use the public Scene world facade. No Jolt headers enter animation public APIs.

RenderAssets groups imported model parts by ModelInstance UUID. The glTF animator is materialized after resource load and before releaseSourceData. Per-instance skinning synchronizes native joint transforms from the ECS bones, then updates bone matrices before presentation. Independent model instances never share pose state. Non-skinned node animation uses the ordinary mesh transform path. Animated skinned renderables disable rest-pose frustum culling so deformations cannot disappear outside stale bounds. CPU scene triangle queries still use imported geometry; precise deformed triangle picking requires a future skinned query representation.

The Animation panel has a read-only imported key timeline, transactional scene preview and editable .banim graph with shared QUndoStack, widgets, theme/localization, asset pickers and automatic save. Preview snapshots transforms and optional Animator settings, restores before save/play/project replacement, and cannot run during gameplay. Keep preview changes out of editor scene undo history and persistence.

Tests: BazzaltAnimationTests covers interpolation, FK, layers, IK, retarget lengths, state transitions, unwrapped root motion, actual Jolt kinematic movement, glTF ingestion and serialization. --gpu additionally reads back actual skinned triangles at two animation times. Editor/tests/test_animation.py covers graph validation/history, timeline dispatch, preview restoration and native inspector authoring. Keep public manuals, C++/Lua references and What's New synchronized.

Format and renderer contracts were checked against the [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) and the pinned Filament gltfio Animator/FilamentInstance headers.
