# Animation pipeline

Public contracts are Animation.h, Animator.h, IKConstraint.h and AnimationSystem.h. Scene automatically owns the system. The animation math/import/runtime code has no Filament types. Engine loop and presentation remain private. C++ and Lua share the same runtime; user code never initializes animation infrastructure.

AnimationRig loads bounded glTF/GLB node TRS tracks and buffer accessors from imported cache paths. Dense and sparse STEP, LINEAR and CUBICSPLINE samplers, including meshopt-compressed buffer views, are validated once; immutable rigs are weak-cached by UUID/path/timestamp. Private SampleAnimationClip bypasses repeated full key validation during playback. Quaternions use slerp for linear tracks and normalized Hermite cubic interpolation. Scalar glTF morph-weight channels are split by target, including cubic tangents, then blended with TRS in BoneTransform.Weights. Skeleton bind weights and optional targetNames drive morph remapping. Assets/GltfDocument is the bounded shared decoder for animation and geometry; it supports normalized components, sparse zero bases, aligned matrices, URI decoding and EXT/KHR meshopt modes/filters. It calls the existing Filament meshoptimizer library, without a second codec dependency. Malformed tracks fail explicitly.

Controller assets (.banim, version 1) hold state machines, phase-synchronized 1D/2D freeform trees, numeric conditions and transitions. Timers are per Animator. Time-zero markers fire once on entry; blend-tree markers follow the strongest sample (stable sample order breaks ties), with phase-mapped times. Non-looping clip and blend states both complete. Crossfades continue the outgoing state; only one automatic transition starts per evaluation. Layers are lexical-order override/additive blends; constraints follow layers. Retargeting can resolve a separate SourceModel, map generic bone names or explicit indices, correct bind rotations and preserve target bone lengths. Imported clips remain immutable. Controller.Clips stores validated authored overrides/additional clips; Configure creates a private immutable playback catalog and preserves the original rig. AnimationClip.FromSource/ToSource serialize keys, tangents and markers as version-one JSON. Graph layout positions are editor-only data ignored by the runtime parser. HumanoidAvatar detects standard semantic aliases (including fingers); explicit profiles validate unique semantics, unique bones and ancestor topology. MapHumanoid maps shared semantics and copies hips displacement while preserving bind-pose length/rotation correction.

Root motion computes unwrapped clip deltas, including loop displacement, before removing root translation/rotation from the visual skeleton. Physics mode submits kinematic movement during fixed animation. Dynamic child rigidbodies retain physics ownership and feed their pose back after stepping. IK helpers can raycast along gravity; all native physics operations use the public Scene world facade. No Jolt headers enter animation public APIs.

RenderAssets groups imported model parts by ModelInstance UUID. The glTF animator is materialized after resource load and before releaseSourceData. Per-instance skinning synchronizes native joint transforms from the ECS bones, then updates bone matrices before presentation. Independent model instances never share pose state. Non-skinned node animation uses the ordinary mesh transform path. Geometry imports skin influences, inverse binds and morph position deltas. Render bounds use conservative per-joint influence clusters plus signed morph envelopes; culling follows deformation without scanning every triangle. Editor picking/bounds use lazily deformed per-instance triangle/BVH caches keyed by exact palettes and morph weights. Refit preserves BVH topology and avoids sorting on every pose. Shared rest geometry is immutable. Public explicit SceneQueryBounds and physics colliders retain their independent contracts; editor deformation does not silently replace physics collision geometry.

The Animation panel has an imported key timeline and an Authored Clips tab with copy/new/delete, channel/interpolation/target controls, editable time/value/tangent tables and marker editing, transactional scene preview and editable .banim graph with shared QUndoStack, widgets, theme/localization, asset pickers and automatic save. AnimationInfo exposes lightweight key times; full key/tangent JSON is exported lazily through AnimationClipSource only for Copy Imported Clip, avoiding serialization on ordinary selection. Preview snapshots transforms and optional Animator settings, restores before save/play/project replacement, and cannot run during gameplay. Keep preview changes out of editor scene undo history and persistence.

Tests: BazzaltAnimationTests covers interpolation, FK, layers, IK, retarget lengths, state transitions, unwrapped root motion, actual Jolt kinematic movement, glTF ingestion and serialization. --gpu additionally reads back actual skinned triangles at two animation times. Editor/tests/test_animation.py covers graph validation/history, timeline dispatch, preview restoration and native inspector authoring. Keep public manuals, C++/Lua references and What's New synchronized.

Format and renderer contracts were checked against the [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) and the pinned Filament gltfio Animator/FilamentInstance headers.
