# Editor Lua tools and preview overrides

Editor/editor_tools.py is the capability dispatcher and transaction owner shared by macros and Extends.Scene. Editor/macros.py stores bounded UTF-8 source bundles under DataPaths.Root()/Macros, using atomic JSON. The Macros panel binds project assets, snapshots a single entry plus explicitly selected modules, and records editor-only source UUIDs under .bazzalt/Editor/MacroSources.json. Compiler.content excludes these even for keep-all packaging and rejects runtime dependency references. No macro bundle is copied to game output.

src/EditorBridge/EditorLua.cpp is a private bridge-only Lua VM, linked to the existing shared Lua library. It exposes only scalar/table data and the Editor dispatcher, not Bazzalt/gameplay/private native APIs. Callbacks run protected with instruction/memory/table limits. Native callbacks return errors as data to a trusted Lua wrapper: do not longjmp directly across C++/Python RAII frames. Raw callback lookup avoids unprotected __index execution. Finalizers/protected-call escape paths are excluded. Modules come from the captured dictionary, never Lua package paths. VM close must reject editor callbacks.

Transactions start lazily on the first mutation. Explicit BeginUndo holds a group across input events; EndUndo commits, CancelUndo/errors restore it. SceneHistory file snapshots include source plus meta, verify external modifications before undo, use atomic replacement and reimport before scene restoration. Keep normal scene history limits, play gating and entity locks. Tool guides have per-owner storage and an independent engine guide layer; never reuse manipulation trails or game entities. All sessions/dialogs are released at project changes/shutdown. Reinitialize checked extension controls for the new project; macros stay opt-in.

Game preview selection lives only in EditorHost/RenderBackend, outside serialized Camera state. Normal composition remains the default. Selected views temporarily receive a full output viewport/projection and presentation target, restored on success or exception. None clears the actual swapchain and suppresses GUI; do not clear only a stale GUI input target. Fixed device sizes use captured presentation rather than oversized viewports on a native swapchain. Input coordinates scale to simulated pixels. Keep native Free Aspect as the cheap default.

Tests: test_editor_tools (native VM isolation, errors/budgets, storage, controls/UI, file history); extension manifest/packaging tests; Compiler content filtering; test_captured_viewport for actual GPU presentation and camera overrides. Never rebuild large dependencies locally.
