# Baked lighting implementation

## Public boundary and ownership

Lighting, LightBakeHandle and LightBakeSettings expose scene operations without native renderer handles. LightProbe, Lightmap and ReflectionProbe are serializable, enableable components. C++ and Lua share validation and behavior. BeginBake snapshots on the owner thread; jobs trace detached data. Apply verifies thread, scene UUID and source fingerprint, prepares output allocations before mutation, and publishes all results. Cancel and stale results retain previous data. Editor mutations use normal undo/dirty/save; authoring is rejected during Play.

## Transport

Lighting.cpp builds a median BVH over enabled visible static Mesh/PrimitiveObject contributors. Lightmaps can receive without contributing. Imported nodes retain model hierarchy transforms; geometry is the authoring pose. Baked lights contribute direct and indirect diffuse; Mixed contributes indirect and keeps direct realtime. Realtime lights are excluded from diffuse baking but included in frozen reflection captures. Visibility uses opaque two-sided triangles. Diffuse albedo is a constant material/primitive color; unknown imported colors use DefaultAlbedo. Texture sampling, alpha transmission, emissive mesh sources, directional lightmaps, shadowmasks and animated bake geometry are not implemented. These are transport boundaries, not restrictions on displaying the original textured glTF material.

Diffuse probes store nine cosine-convolved world SH coefficients. Lightmaps generate equal-sized nonoverlapping triangle charts with dilated gutters, preserving source UV0/UV1. Geometry triples permit runtime barycentric chart reconstruction in world coordinates. TransformSignature prevents stale receiver sampling. Reflection captures trace contributing geometry, lights and cached HDR environment; GGX importance sampling creates roughness mips. Box projection uses world-oriented half extents; moved captures are excluded. LightingSky strictly bounds and decodes KTX1 RGB/RGBA float, half, byte, R11G11B10F and RGB9E5 without a fatal GPU parser. Reflection geometry uses the same constant diffuse transport approximation.

## GPU atlas and materials

BakedLightingAtlas packs a shared RGBA32F atlas. Header records describe SH counts, triangle chart counts, reflection counts, offsets and grid bounds. Ten records encode each diffuse probe; five encode a chart; four encode a reflection. Payloads contain irradiance texels and six cubemap faces per mip. A 16/32 cubed spatial grid retains every overlapping influence. List budget overflow selects exact global lookup; nothing is silently truncated. Four strongest overlapping probes/captures are evaluated. Capacity is min(hardware texture limit,4096)^2 and float-addressable. MaxProbes is an explicit 65536 budget. Metadata samplers require HIGH precision, including on Metal. Uploads occur only when a metadata fingerprint changes; scalar fields, enable state, transforms, allocation pointers/sizes and revision participate. In-place payload edits require Lighting.Invalidate. Old textures retire after rebinding live instances.

Canonical shaders live in runtime/resources/shaders/baked_lighting.glsl and baked_reflections.glsl. CMake embeds them for glTF JIT. scripts/sync_lighting_sources.py produces the Python copy used by editor and standalone content compiler; --check detects drift. Private contract v2 is bazzaltLightingData plus bazzaltLightingEnabled. Old opaque filamat packages do not claim compatibility. Surface-source compilation wraps the user's material function so early returns still receive diffuse GI, without exposing private fields in material reflection. Unlit/postprocess domains are unchanged.

LightingMaterialProvider.cpp is a modified pinned Filament v1.77.0 JitShaderProvider; preserve its Apache header and upstream glTF feature generation when updating. It injects the same shader into original lit glTF materials and binds all created instances. Imported textures and texture coordinates are unchanged. The reflection hook wraps only native IBL sampling through a marker overload: native DFG/BRDF, AO, SSR composition, clearcoat and sheen remain in Filament. World positions/directions are converted out of camera-relative/internal IBL space. Physical diffuse emission and reflected radiance respect camera exposure. Without a real environment, a zero-SH black cube enables native IBL evaluation without introducing ambient illumination. GUI/unlit materials are unaffected.

## Persistence and budgets

Light v2 defaults legacy data to Realtime; Mesh v4/PrimitiveObject v3 default legacy ContributeGI false. LightProbe, Lightmap and ReflectionProbe use version-one descriptors. Float vector arrays use lossless little-endian base64 (12 bytes per Vec3, no padding required), bounded/nonfinite-safe transactional decode. Scene read/write budget is 256 MiB. Scene saving writes a sibling temporary file and atomically replaces the original only after successful serialization/flush/close. The temporary is removed on failure. Baked payloads travel through normal scene cooking and streaming.

Default MaxBakeTexels is 1048576, maximum 8388608; reflection mips count toward it. MaxTriangles defaults one million, caps four million; model cache reads cap 128 MiB. Snapshot/revalidation remain synchronous and expensive authoring operations. Large streamed worlds should partition baked data, and dense receivers should be split or use appropriately sized atlases. Huge overlap may degrade shader performance; exact fallback prioritizes correctness.

## Validation

LightingTests covers diffuse modes/occlusion, >64 probes, exact overlap fallback, atlas/cache invalidation, lightmap/reflection baking, stale transforms/results, payload codecs, HDR cache bounds, cancellation and persistence. --gpu exercises real Vulkan output and teardown. Native editor tests cover inspectors and authoring validation; Python material tests verify lowering and hidden parameters. Run serialization/material/rendering regressions after changing this contract. No third-party dependency builds are required for these checks.
