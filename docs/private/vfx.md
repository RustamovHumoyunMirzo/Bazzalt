# VFX implementation

Public contracts live in VFX.h, Components/ParticleEmitter.h and Systems/ParticleSystem.h. The engine automatically owns a ParticleSystem for its active scene. No loop or Filament API is public. StopScripts replaces the system to release play state. Rendering never advances simulation.

VFXGraph uses bounded rapidyaml parsing of versioned JSON/YAML data, then compiles a single connected flow into immutable stage settings. Imports are UUID-only, checked by depth, expanded-node budget and an active import set; stages cannot execute scripts. The importer performs structural/local validation before copying the source to cache. Runtime Load resolves transitive imports; FromSource shares the compiler. Missing or cyclic imports invalidate the handle. Disconnected authoring blocks do not execute. The asset dependency scanner and compiler retain .vfx, imported graphs, output materials/textures and ParticleEmitter references.

Simulation uses a double-precision accumulator with a 1/120 second step (never use a float accumulator step: it loses boundary steps when batching intervals). Per-emitter xorshift state and stable UUID iteration avoid global RNG coupling. Position sampling is uniform inside boxes/spheres; cone directions sample cosine uniformly. Gravity, exponential drag, bounded sinusoidal turbulence and normalized-age curves update private state. Events are capped snapshots, not callbacks, so script/module teardown retains no particle code.

GraphicsAccess invokes VFXAccess::Render during per-camera preparation. It builds sorted camera-facing quad batches using reusable GraphicsMesh handles, tags commands with the owner and camera/viewport, and keeps Source zero: particles must not hide or deform the owner's normal mesh. Render resources are allocated before GPU render passes. The private transparent particle shader depth-tests without depth writes, supports circular falloff or image alpha, and consumes vertex color/UVs. Optional authored materials use the normal material pipeline. LOD and editor visibility use command Owner; transparent sorting is per emitter. Scene/view limits cap simulation and upload work. Mesh histories are bounded to 64 camera keys per emitter.

The Visual Effects panel reuses ShaderGraphPanel's configurable Model and shared canvas/history. Shader model conversion remains separate. Palettes start collapsed and expand during search. VFX node fields use existing themed widgets and project asset pickers; no native file paths are imports. Native preview_vfx simulates a scratch scene and returns bounded particle snapshots to the small schematic preview, without replacing global rendering state or running scripts. Full material previews are the actual Scene/Game renderer.

Checks: BazzaltVFXTests covers fixed-step batching, seed replay, capacity, pause/stop, space, imports/cycles, dependency identity and scene serialization. --gpu performs real Vulkan readback. Python VFX tests cover graph validation, history, panel registration, preview and components. LuaRuntimeTests exercises native binding operations.
