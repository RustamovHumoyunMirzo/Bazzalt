# Advanced LOD renderer

HLOD, LODTransition and Impostor are separate public components. Existing LOD binary layout and v1 scene data remain unchanged. AdvancedLODSerialization registers v1 descriptors with normal Component enabled-state persistence. HLOD source/proxy UUID keys are entity references for prefab remapping; impostor Atlas is an asset reference in the dependency graph.

LODVisibility evaluates ancestor groups before descendants, tracks logical selection and reversible two-way transition progress per view, and builds per-entity coverage contributions. Full hidden nested groups reset their history. Coverage is an interval over the same ordered 8x8 screen pattern; nested constraints intersect. Unsupported groups replace all their contributions with hard-selected visibility. Material capability checks ignore entities already excluded by an independent hard constraint. No authored transform/visibility/physics state changes.

Engine shaders and generated bshader surface packages reserve float4 bazzaltLodFade: x/y are minimum/maximum coverage; z enables clipping. Zero-initialized parameters leave normal materials untouched. Public shader reflection hides this uniform. The material translator injects it only into engine-translated surface shaders; raw Filament packages and gltfio provider shaders need compatible authored overrides or use a whole-group hard cut. Debug materials also fall back. LODFadeSwaps prepares per-view uniform/state instances before beginFrame, restores renderable slots after each view, and retires the frame pool after endFrame and leaves shared source instances unmodified. Graphics draws and soft-body overrides follow the same policy. Keep CPU and all shader coverage functions identical.

ImpostorRenderer owns shared quad buffers, atlas-frame/tint/mask material sharing and per-entity renderables. Prepare runs before beginFrame, so buffer/texture creation and fade/selection material instance allocation never happen inside a GPU pass. BeginView only assigns camera-facing matrices, scoped materials and visibility. EndView removes temporary renderables. Texture retirement invalidates every borrower before surface destruction; invalidation is safe inside atlas preparation and does not delete the renderer object. Selection mask copies keep alpha cutoff and LOD coverage and restore original slots. Atlas tile selection is azimuth-only; texture borders require authored padding/mips. Runtime atlas producers join the world capture dependency graph, preserving shared-feed SCC history behavior.

Tests: BazzaltLODTests (headless math, hierarchy, serialization, reversal, coverage and fallback); --gpu validates two cameras, actual red/blue coverage and green alpha-clipped impostors, resizing and destruction on a real backend. Linux CI runs the GPU path under Xvfb/Vulkan. Editor LOD tests validate root pickers, duplication, enums, fields and enable states. Lua runtime tests exercise all new component operations. Do not build third-party libraries locally.
