# Global Event runtime and authoring

Public contracts are in include/Bazzalt/GlobalEvent.h. The core owns definitions, the FIFO and callback leases; Lua binds the same API. No solver/renderer/editor dependency is added. The strict rapidyaml importer validates Version/Name/Arguments, size and type bounds, then copies YAML to the normal UUID cache. Cooked asset indexes retain the Bazzalt.GlobalEvent importer and original event UUID. Compiler serialized-dependency scanning includes .event files. Dynamic UUID loads still require explicit inclusion when packaging filters exclude assets.

Dispatch is single engine-thread, ordered by monotonically increasing subscription ID, with per-invocation snapshots. A removed ID is skipped; a new ID cannot run in the current snapshot. Nested emissions are copied into FIFO nodes with causal depth. Root Fire drains synchronously; exceptions clear pending work through RAII. Finite values, string length, schema and all budgets are validated. Time.GetFrameCount resets shared root fire/delivery budgets at the next frame. Callback failures disable that subscriber; subsystem failures feed ApplicationEventsAccess.Fail. C++ callback module leases outlive callback destruction. Entity owners are resolved by scene/entity UUID rather than a dangling Scene pointer. ApplicationEventsAccess.DisconnectOwner now disconnects global-event subscriptions, including native behaviors, subsystems and Lua VM shutdown.

Subscriptions capture module, script owner, subsystem level, asset permission and extension caller. CallbackScope restores these even on exceptions. Never inherit the emitter's privileges. Asset Access is opt-in registration data, defaults false for older projects, survives cooked subsystem UUID remapping, and is restored around application lifecycle, physics, graphics and global-event callbacks. DisconnectOwner also removes graphics callbacks owned by a subsystem; callback destruction happens outside listener-map iteration. Lua close marks its owner as closing so finalizers cannot retain a new callback into a dead VM. AssetManager path lookups are forbidden in subsystem contexts; service initialization guards continue to apply. This is a service contract for trusted native code, not a C++ security sandbox.

Authoring uses Editor/global_events.py and the shared StringInput/EnumInput widgets. Save validates before an atomic write; editing is disabled in Play. GlobalEvent is reflected as an event-only project picker in both C++ generated wrappers and Lua PROPERTY declarations. Do not export engine loop or persistence internals to game code.

Regression: BazzaltGlobalEventTests exercises schema import, exact argument validation, FIFO/reentrant subscription mutations, recursion and frame budget recovery, owner destruction, module-scope disconnection, foreign-thread rejection, permission capture, Lua property/callback cleanup and cooked UUID loading. Editor tests cover schema validation, inspector edits/play locking, reflection and subsystem persistence. No large dependencies should be built locally for these checks.

NativeScriptRuntime catches property setter exceptions, including GlobalEvent.Load failures, records the property/type in the error, and tears down the partial instance. An invalid event assignment must not leak the partially constructed behavior or leave startup subsystems running. NativeScriptRuntimeTests covers a throwing GlobalEvent setter; GlobalEventTests exercises a real C++ behavior firing its assigned event. The packaged-game subsystem probe verifies UUID loading/fire through the packaged content and the denied-permission error path. Non-subsystem callback failures log to stderr when no editor console is available.

Lua receives owned invocation copies, with owned typed values and argument records. Scripts may retain the invocation/table past callback return; never push a borrowed pointer into a stack-local queue node. The Lua integration regression retains a snapshot and its argument/value tables and reads them in a later Update.
