# Cross builds, workers and Wayland presentation

Compiler.cross owns tool discovery, exact SDK toolchain contracts, argument arrays and a ContextVar scoped to one build. Never infer ABI compatibility from PE machine type or the ability to read an import library. Native SDKs are MSVC/libc++; GNU/Zig C++ builds require an explicitly toolchain-built SDK. Content-only builds reject source C++ and may use shipped foreign runtimes. Host cookers always execute on the host; target players are verified offline when they cannot execute there. Portable Zstd avoids Windows XPRESS data leaking into POSIX games. LIEF changes only the resource tree before sealing. WSL maps source/output paths and forwards cancellation over stdin; it never runs engine CMake.

SSH profiles live in per-user app-data, not project metadata. Password/passphrase fields never enter profile JSON, command lines, request JSON or logs. Only native OS-vault backends may save credentials; do not enable plaintext fallbacks. Paramiko RejectPolicy and verified known_hosts are mandatory. POSIX commands use shlex argument quoting; Windows uses encoded PowerShell with literal arguments. A remote worker is a trusted native build account, not a sandbox for hostile C++ or importer inputs.

The client creates bounded ZIP input snapshots, skips caches/bin/Git and credential globs, and checks artifact hashes before local publication. The compiler worker validates request/path/ZIP limits and owns only dedicated project/job subtrees. Transfer manifests remove stale uploaded files without deleting unrelated files. Keep cancellation checks in package/transfer phases and before publication. Remote macOS verification must not provision the builder's player Keychain. Account-scoped DPAPI must not silently bind downloaded games to worker credentials.

Wayland must never pass a Qt WId to the X11 Filament swapchain. Captured viewports reuse the normal scene/game render paths with a headless GPU swapchain. One asynchronous RGBA transfer may be pending; completed but unconsumed frames stop further transfers. Callback state is shared and mutex-protected independently of viewport lifetime. Destruction/resize flushes outstanding work before releasing swapchains. Python polls sequence-tagged snapshots, flips bottom-origin rows into QImage, and composes a regular Qt child widget. SDL owns standalone Wayland windows and dispatches their events. A private wl_shm presenter uses three release-tracked buffers for captured pixels; it never asks SDL to create an extra OpenGL renderer. Busy compositor buffers are never overwritten. Public game APIs receive no Qt/SDL/Filament surface types. X11, Windows and Metal presentation stay direct.

Run test_captured_viewport on a real Vulkan device and test_wayland_native under Weston with DISPLAY unset. Keep native game verification/render tests under both X11 and Wayland. ARM64 renderer dependency builds belong only on native GitHub runners; scripts refuse local large builds. Cache completed SDKs before engine checks, because engine failures must not force an expensive dependency rebuild.
