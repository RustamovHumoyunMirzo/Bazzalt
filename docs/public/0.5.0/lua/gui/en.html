GUI in Lua

Lua uses the same scene entities, layout, styles, and interaction state as C++. There is no separate Lua or editor renderer.

Create a GUI hierarchy

local B = Bazzalt
local Behavior = {}
function Behavior:OnCreate()
    local scene = self.Entity:GetScene()
    local hud = scene:CreateEntity("HUD")
    hud:AddComponent("Frame")
    self.Button = scene:CreateEntity("Continue")
    self.Button:SetParent(hud, false)
    local layout = self.Button:AddComponent("RectTransform")
    layout.Position = B.Vec2.new(24, 24)
    layout.Size = B.Vec2.new(180, 40)
    self.Button:SetComponent("RectTransform", layout)
    self.Button:AddComponent("Rectangle")
    self.Button:AddComponent("GuiButton")
    local text = self.Button:AddComponent("GuiText")
    text.Value = "Continue"
    self.Button:SetComponent("GuiText", text)
end
function Behavior:OnUpdate(dt)
    if B.GUI.GetInteraction(self.Button).Clicked then
        -- Apply your gameplay action here.
    end
end
return Behavior

GetComponent/AddComponent return component values: modify your copy and write it back with SetComponent. Layout and widgets belong on Frame descendants, not the Frame entity itself. The engine handles updates and drawing. A missing Frame or RectTransform leaves widgets unrendered.

Types, fields, and enums

Constructors use Bazzalt.Type.new(). Frame, RectTransform, Rectangle, GuiImage, GuiText, GuiButton, GuiTextInput, and CameraRenderTarget expose exactly the fields listed in the complete GUI reference, with the same defaults and validation. GuiStyle is a value object used by Rectangle.Style. Every component supports Enabled/IsEnabled/SetEnabled and the normal entity component add/get/set/remove/enable APIs.

FrameMode exposes Viewport, CameraBound, and Spatial. GuiScaleMode exposes ConstantPixels and ScaleWithViewport. Camera/Texture fields accept Bazzalt UUID values; Camera means an entity UUID, Texture means an asset UUID. Vec2/Vec4 fields use Bazzalt math values.

GUI method reference

B.GUI.GetInteraction(entity) returns GuiInteraction with Hovered, Pressed, Focused, PointerEntered, PointerExited, Clicked, ValueChanged, and Submitted. The first three are states; the rest last one gameplay update. B.GUI.GetBounds(entity) returns GuiBounds.Position/Size; bounds:Contains(point) tests its half-open rectangle. B.GUI.GetFrame(entity) returns the nearest ancestor render root. B.GUI.Focus(entity) returns success, B.GUI.ClearFocus(scene) releases keyboard focus, and B.GUI.IsPointerOverUI(scene) helps gate world interaction. B.Input.GetTextInput() returns current committed UTF-8 input.

Editable text

local input = entity:AddComponent("GuiTextInput")
input.Placeholder = "Player name"
input.MaxLength = 32
entity:SetComponent("GuiTextInput", input)
-- In OnUpdate, after input has been focused/clicked:
local state = Bazzalt.GUI.GetInteraction(entity)
if state.Submitted then
    local value = entity:GetComponent("GuiTextInput").Value
    -- Use value in your game.
end

Add RectTransform and parent it beneath a Frame; add Rectangle for a visible background. MaxLength counts code points, and Backspace removes a whole code point. Password masks display but is not encryption. ReadOnly prevents editing. See the C++ reference for keyboard traversal, pointer capture, focus loss, and current text/font limitations.

Split-screen and camera feeds

local frame = hud:GetComponent("Frame")
frame.Mode = Bazzalt.FrameMode.CameraBound
frame.Camera = playerCamera:GetUUID()
hud:SetComponent("Frame", frame)
local target = feedCamera:AddComponent("CameraRenderTarget")
target.Width = 512; target.Height = 512
feedCamera:SetComponent("CameraRenderTarget", target)
local image = imageEntity:AddComponent("GuiImage")
image.Camera = feedCamera:GetUUID()
imageEntity:SetComponent("GuiImage", image)

CameraBound follows the active camera's viewport, including split-screen rectangles. CameraRenderTarget makes a camera render offscreen for a GuiImage feed. No low-level texture handle or render API enters Lua. Read the shared reference's foundation boundaries before using spatial picking or expecting complete text-editing/stylesheet support.
