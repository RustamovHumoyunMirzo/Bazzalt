Input

Static, read-only main-thread gameplay input. Inactive focus returns neutral values. It does not pump OS events or bind editor navigation controls.

Underlying public header: Bazzalt/Input.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

if Bazzalt.Input.GetKeyDown(Bazzalt.KeyCode.Space) then
    -- Perform a one-shot gameplay action.
end
