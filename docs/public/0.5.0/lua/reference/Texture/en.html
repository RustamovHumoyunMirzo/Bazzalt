Texture

Lua uses the same independent texture resources and producer/consumer rules as C++. No native engine loop or GPU object is exposed.

Create and share a camera texture

local B = Bazzalt
local settings = B.TextureDescriptor.new()
settings.Width = 1024; settings.Height = 512
settings.Samples = 4; settings.Mipmaps = true
settings.ColorFormat = B.TextureColorFormat.RGBA16F
local texture = B.Texture.Create(settings)
local camera = cameraEntity:GetComponent("Camera")
camera:SetRenderTarget(texture)
cameraEntity:SetComponent("Camera", camera)
local image = imageEntity:GetComponent("GuiImage")
image:SetTexture(texture)
imageEntity:SetComponent("GuiImage", image)
material:SetTexture("baseColorTexture", texture)
-- For project assets: B.Texture.Load(assetUUID)

Method reference

MethodContract
B.Texture.new()Empty handle.
B.Texture.Load(UUID)Non-owning asset/resource reference.
B.Texture.Create([descriptor])Transient writable texture; default settings if omitted. Invalid settings raise an error.
GetAssetUUID()Stable resource UUID shared by all consumers.
IsValid()Valid writable descriptor or ready ordinary image asset.
IsRenderTarget()True only for writable .btexture/transient resources.
IsRuntime()True for transient runtime descriptors.
GetDescriptor()Copy of writable settings; ordinary image assets do not expose a writable descriptor.
SetDescriptor(descriptor)Runtime override; never writes asset files.
ResetDescriptor()Restores source/original descriptor.
Resize(width,height)Validates dimensions, constrains explicit mip counts and preserves resource identity.
Destroy()Destroys transient resources only; returns false for assets/already-destroyed handles.

Components and materials

Camera:SetRenderTarget(texture), Camera:GetRenderTarget(), GuiImage:SetTexture(texture or UUID), Material:SetTexture(name, texture or UUID), and MaterialBuilder:SetTexture(name, texture or UUID) share this resource. Lua entity components are copies: call SetComponent after editing a Camera or GuiImage. Texture setters modify their resource directly.

Lifetime and history

Disabled/inactive/removed producers restore ClearColor. Conflicting active writers are suppressed, not raced. Chained GUI captures use producer-first scheduling; cycles/shared world feeds use completed history. Runtime textures/overrides are reset on Stop. CameraRenderTarget remains a legacy transient configuration; new scenes use the Camera picker. Shared C++ contract
