MathFunctions

Free functions, constants and free arithmetic operators in namespace Bazzalt. Angles use radians unless a function explicitly converts degrees.

Underlying public header: Bazzalt/Math.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local angle = Bazzalt.ToRadians(90)

Clamp

Bazzalt.Clamp(value, minimum, maximum)

Returns a value constrained to minimum/maximum. Supply minimum ≤ maximum.

Returns: number.

ArgumentMeaning
float valueValue whose type must match the declaration. Numeric values must be finite where validated.
float minimumInclusive lower limit.
float maximumInclusive upper limit.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.

Underlying C++ declaration / default values

Lerp

Bazzalt.Lerp(from, to, amount)

Linear interpolation from the first value to the second by amount. Amount is not clamped: 0 selects from, 1 selects to, other values can extrapolate.

Returns: number.

ArgumentMeaning
float fromInterpolation starting value.
float toInterpolation target value.
float amountInterpolation factor; 0 starts and 1 ends, not automatically clamped.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.
