Transform

Local position, quaternion rotation and scale. GetWorldTransform/SetWorldTransform on Entity convert between this local data and composed world placement.

Underlying public header: Bazzalt/Components/Transform.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

Construction

Bazzalt.Transform.new()

Each line is an accepted construction form. The argument names stand for values you supply; an empty call uses default values. Plain data types construct with their declared default fields.

Component values returned by Entity are copies. After changing fields or methods, call entity:SetComponent(typeName, value). Derived components inherit Component.Enabled, IsEnabled and SetEnabled; core Identity, Hierarchy, Name and Transform have entity-level restrictions.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local world = self.Entity:GetWorldTransform()
world.Position = world.Position + Bazzalt.Vec3.new(0, 1, 0)
self.Entity:SetWorldTransform(world)

Rotate

value:Rotate(axis, radians)

For Transform, applies an axis-angle quaternion (angle in radians) before the current rotation and normalizes. For Quaternion, returns the rotated input vector; use a unit quaternion.

Returns: no value.

ArgumentMeaning
Vec3 axisRotation axis; use a nonzero direction.
float radiansAngle in radians, not degrees.

Scale

value.Scale

Local component-wise scale; one on each axis by default. Zero scale can make world-to-local/inverse operations impossible.

Underlying C++ declaration / default values
Vec3 Scale{1.0f}

Translate

value:Translate(translation)

Adds the supplied vector to Position in its current coordinate space. A local Transform does not automatically translate in camera-relative coordinates.

Returns: no value.

ArgumentMeaning
