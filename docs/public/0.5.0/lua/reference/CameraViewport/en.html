CameraViewport

A normalized rectangle on a presentation surface. The origin is bottom-left. A half-width viewport has Width 0.5, not a width in pixels.

Underlying public header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

Grid

Bazzalt.CameraViewport.Grid(column, row, columns, rows)

Returns a normalized cell for zero-based column/row in columns×rows. Invalid dimensions/indices return an empty viewport, not an exception.

Returns: CameraViewport.

ArgumentMeaning

std::uint32_t rowZero-based row index.
std::uint32_t columnsNumber of grid columns; must be positive.
