EntityReference

A UUID-based non-owning reference that resolves against the active scene each time, rather than retaining registry storage.

Underlying public header: Bazzalt/EntityReference.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

Construction

Bazzalt.EntityReference.new()
Bazzalt.EntityReference.new(id)

GetUUID

value:GetUUID()

Returns the stable UUID identifying this value/entity/scene. It is not a filename or display name.

Returns: UUID.

SetWorldTransform

value:SetWorldTransform(value)

Commits world placement by converting it into local Transform data under the parent. Returns false for a rejected/non-decomposable placement.

Returns: boolean.

reference:TryGetWorldTransform()

Returns success and fills a world Transform if the active-scene reference resolves. Lua returns (success, transform); do not use the transform when false.
