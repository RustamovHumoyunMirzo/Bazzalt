Behavior

A returned Lua table with optional lifecycle callbacks. Each attachment receives self.Entity and its authored property overrides in an isolated VM.

Underlying public header: Bazzalt/Script.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

    local entity = self.Entity
end

OnCreate

function Behavior:OnCreate()

Host callback called after an instance is created and initial properties are applied. Initialize runtime state here; do not initialize the engine.

Returns: no required return value.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.

OnUpdate

function Behavior:OnUpdate(deltaTime)

Host callback for enabled frame updates. deltaTime is scaled seconds, not an FPS count. Multiply rates by it for time-based behavior.

Returns: no required return value.

ArgumentMeaning
float deltaTimeScaled frame duration in seconds.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.

OnFixedUpdate

function Behavior:OnFixedUpdate(fixedDeltaTime)

Host callback for enabled fixed-step work. The supplied step is in seconds; the host owns scheduling.

Returns: no required return value.

ArgumentMeaning
float fixedDeltaTimeScaled fixed-step duration in seconds.

OnDestroy

function Behavior:OnDestroy()

Host cleanup callback. Release owned transient resources; do not destroy shared assets or take over host shutdown.

Returns: no required return value.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.

Entity

self.Entity

Host-supplied owning entity handle. Do not replace it or reuse it after the host destroys the scene.
