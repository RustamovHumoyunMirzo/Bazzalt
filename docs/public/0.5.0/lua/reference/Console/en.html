Console

Bazzalt.Console is available to scripts but active only in the editor. Use dots for all Console calls.

Standalone behavior

IsAvailable() returns false in exported games. Logging and clearing silently do nothing. GetCount, GetMessages, GetMessageAt and FindMessage return nil. In the editor, GetMessages returns an ordinary 1-based table of copied ConsoleMessage records, including an empty table for an empty console; GetCount returns a number. Invalid indices/IDs return nil. Using a nil result without checking it can still fail in your own code: the API deliberately does not invent game-runtime data.

Write

local B = Bazzalt
B.Console.Info("Player ready", "Movement")
B.Console.Warning("Optional target missing", "AI", false)
B.Console.Error("Required asset missing", "Assets")
B.Console.Log("Details", B.ConsoleLevel.Info, "Gameplay", false)

Info/Warning/Error(text, source="Script", showIcon=true) and Log(text, level=Info, source="Script", showIcon=true) append to the same Console as editor messages. ShowIcon=false is supported. The store retains up to 10,000 entries and 16 MiB of text/source payloads and limits text to 65,536 UTF-8 bytes and sources to 256 bytes; oversized entries are discarded. Logging does not write to stdout/stderr in games.

Filters and read operations

local filter = B.ConsoleFilter.new()
filter.Levels = 2 | 4 -- Warning and Error
filter.Source = "Physics"
filter.Contains = "collision"
local messages = B.Console.GetMessages(filter)
if messages then
    for _, message in ipairs(messages) do
        B.Console.ClearMessage(message.Id)
    end
end

ConsoleFilter fields: Levels (bitmask, default 7: Info=1, Warning=2, Error=4), Source and Contains (default empty). Matching is case-sensitive; Source is exact, Contains is a UTF-8 substring of Text. GetMessages(filter=nil) and GetCount(filter=nil) read matching entries. These filters are independent of the panel's visible filter settings.

GetMessageAt(index) uses a 1-based index in the unfiltered store, matching Lua table conventions. FindMessage(id) uses a stable ID. ConsoleMessage fields are Id, Text, Level, Source, ShowIcon and Timestamp (Unix seconds). Results are detached copies; editing them does not change the Console.

Clearing

Clear(filter=nil) removes matches or all messages if omitted. ClearAt(index) removes a 1-based unfiltered entry; nonpositive/out-of-range indices do nothing. ClearMessage(id) removes a stable ID. ClearMessages({id1, id2}) removes a batch. Missing IDs are harmless. Indices shift after removals or retention eviction, so use IDs when retaining references.

Keep console reads out of gameplay decisions

local count = B.Console.GetCount()
if count ~= nil then
    -- Editor-only diagnostic behavior.
end

The console is a diagnostic/editor facility, not persistent storage or a gameplay event channel. No project console data is saved or shipped with a game.
