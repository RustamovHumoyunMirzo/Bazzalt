Camera

A game camera component. Requires an entity Transform. Both component Enabled and camera Active must permit rendering. The editor navigation camera is separate.

Underlying public header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

Construction

Bazzalt.Camera.new()

Each line is an accepted construction form. The argument names stand for values you supply; an empty call uses default values. Plain data types construct with their declared default fields.

Component values returned by Entity are copies. After changing fields or methods, call entity:SetComponent(typeName, value). Derived components inherit Component.Enabled, IsEnabled and SetEnabled; core Identity, Hierarchy, Name and Transform have entity-level restrictions.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local camera = self.Entity:GetComponent("Camera")
camera.VerticalFieldOfView = Bazzalt.ToRadians(60)
self.Entity:SetComponent("Camera", camera)

Active

value.Active

Camera participation flag, independent of component Enabled. Both must allow rendering.

Underlying C++ declaration / default values
bool Active = true

AspectMode

value.AspectMode

Automatic follows viewport dimensions; Fixed uses AspectRatio.

Underlying C++ declaration / default values
CameraAspectMode AspectMode = CameraAspectMode::Automatic

AspectRatio

value.AspectRatio

Fixed width/height ratio, default 16/9; used with Fixed AspectMode.

Underlying C++ declaration / default values
float AspectRatio = 16.0f / 9.0f

ClearColor

value.ClearColor

Camera background/clear RGBA color.

Underlying C++ declaration / default values
Vec4 ClearColor{0.02f, 0.02f, 0.025f, 1.0f}

FarPlane

value.FarPlane

Far clipping distance, default 1000. Geometry beyond it is clipped.

Underlying C++ declaration / default values
float FarPlane = 1000.0f

NearPlane

value.NearPlane

Near clipping distance, default 0.1. Geometry closer than it is clipped.

Underlying C++ declaration / default values
float NearPlane = 0.1f

OrthographicSize

value.OrthographicSize

Vertical orthographic extent setting; only used in Orthographic projection.

Underlying C++ declaration / default values
float OrthographicSize = 10.0f

PostProcessing

value.PostProcessing

Nested CameraPostProcessing settings for this camera image.

Underlying C++ declaration / default values
CameraPostProcessing PostProcessing{}

Priority

value.Priority

Lower priorities render first; equal priorities use UUID order.

Underlying C++ declaration / default values
int Priority = 0

Projection

value.Projection

Perspective or Orthographic projection.

Underlying C++ declaration / default values
CameraProjection Projection = CameraProjection::Perspective

VerticalFieldOfView

value.VerticalFieldOfView

Perspective vertical FOV in radians; default 60 degrees converted to radians.

Underlying C++ declaration / default values
float VerticalFieldOfView = ToRadians(60.0f)

Viewport

value.Viewport

Normalized target rectangle, full screen by default.

Underlying C++ declaration / default values
