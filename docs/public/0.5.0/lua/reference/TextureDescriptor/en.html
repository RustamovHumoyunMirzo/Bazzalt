TextureDescriptor

Bazzalt.TextureDescriptor.new() creates writable 2D settings. Every C++ field is available in Lua with the same PascalCase name and default.

Fields

Width=512, Height=512, Samples=1, Mipmaps=false, MipLevels=0, ColorFormat=TextureColorFormat.RGBA8, DepthFormat=TextureDepthFormat.Depth32F, Filter=TextureFilter.Linear, Wrap=TextureWrap.Clamp, ClearColor=Vec4(0,0,0,1).

Enums

TextureColorFormat: RGBA8/RGBA16F/RGBA32F. TextureDepthFormat: None/Depth16/Depth24/Depth32F. TextureFilter: Point/Linear/Trilinear. TextureWrap: Clamp/Repeat/Mirror. All are under Bazzalt.

IsValid()

Checks dimensions (1–4096), sample counts (1/2/4/8), enum ranges, finite color and valid mip counts. Invalid values raise an error when passed to Create or SetDescriptor; no partial update occurs.

GetMipLevelCount()

Returns one without mipmaps, or the explicit/computed full pyramid count when enabled. A zero MipLevels means automatic.

Editing

GetDescriptor returns a copy. Change its fields and call texture:SetDescriptor(settings) to apply it. Calling texture:Resize modifies the resource directly. Field meanings, sample resolving and memory considerations
