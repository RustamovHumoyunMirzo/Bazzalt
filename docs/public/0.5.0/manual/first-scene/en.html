Your first scene

Create a cube, place a camera, and check the result in Game output. This guide assumes you have opened a project through the Hub.

Choose the scene you are editing

The Hierarchy groups objects under scene headers. The active scene header is shown in bold. Scene view and Game output display that active scene. If you have loaded several scenes, right-click the scene you want and choose Activate scene before continuing.

A new project may already contain a starter scene, camera, and light. Check the Hierarchy first so you do not create duplicates.

Create a cube

  1. Right-click in the Hierarchy and use Add new → Primitives → Cube.
  2. Select the cube. The Inspector shows its components.
  3. Set its Transform position to (0, 0, 0) and scale to (1, 1, 1).
  4. Press F with Scene view active to frame the selection.

The Primitive Object component creates geometry inside the engine; it does not require an imported model. Its Shape and shape-specific fields control the generated geometry. Transform controls where that geometry appears.

Position a game camera

If the scene has no camera, create a Camera from the Hierarchy's Add new menu. Select it and make sure its Camera component is enabled. To start with a cube at the origin, try a camera position of (0, 0, 5), rotation of (0, 0, 0), and a perspective projection. An unrotated camera looks along its local negative Z axis, toward the origin from that position.

Switch to Output Game to see the camera's result. If the cube is missing, check the active scene, camera direction, component enable checkboxes, and near/far clipping distances. A clipping distance defines the nearest or farthest point the camera can render.

Add light if needed

A lit surface needs illumination. Keep the starter light or add a light and adjust its direction, intensity, and type. An environment map can also supply lighting when image-based lighting is enabled in the scene's environment settings.

The visible sky and the light it supplies are separate settings. Hiding the skybox does not, by itself, turn off image-based lighting. To diagnose unexpected brightness, select the scene header and inspect its environment as well as the scene's Light components.

Move the cube and save

Choose Translate (2) and drag a gizmo axis to move the cube. A gizmo is an editor manipulation handle, not an object included in the game. You can also type Transform values in the Inspector.

An asterisk beside a scene name means it has unsaved changes. Use File → Save or Ctrl S, then check that the asterisk disappears. Saving your scene stores the authored objects and components; it does not turn temporary runtime-created materials into reusable material assets.

Try Play

Play runs attached behaviors. A static scene does not need a script to appear in Game output. If you want the cube to move, continue with the Lua behavior guide or the C++ behavior guide. Click Game output when testing movement so gameplay input has focus. Stop returns you to editing; do not rely on Play-mode changes as a way to save authored scene values.
