Panels and scene controls

Use the Hierarchy to choose objects, Scene view to place them, and the Inspector to change their data.

The main panels

A panel is a titled area of the editor window. Several panels can share an area as tabs: click the tab name to switch between them. If one is missing, show it through Window. Its title is more reliable than a fixed left/right position because layouts can be rearranged.

PanelUse it for
HierarchyLoaded scenes, entity parent-child relationships, selection, and object creation.
InspectorFields on the selected entity's components, scene environment settings, or selected asset.
SceneEditing through a separate scene camera. Grid, gizmos, outlines, and object guides belong here.
Output GameThe active scene rendered through enabled game cameras, without editor overlays.
Asset BrowserProject folders, assets, previews, creation, renaming, and drag-and-drop assignment.
ConsoleIndividual log entries, script compilation errors, and filters by level and source.

Read one panel at a time: Hierarchy, Inspector, Scene view, Game output, Asset Browser, and Console. Each guide explains how to find it, what clicking changes, and common mistakes.

Drag panel tabs to rearrange the workspace. Layout changes are saved by the editor. The Window menu lets you show panels that are closed. Preferences are editor-wide settings; Project Settings belong to the current project.

Navigate Scene view

  • Right mouse drag looks around using the editor's focus-point navigation.
  • Hold the right mouse button and use W A S D Q E to fly. During flight, looking around follows the camera's own position rather than orbiting a focus point.
  • Shift with right mouse drag moves the camera.
  • Press F to frame selected objects. View also contains camera presets and Frame All.

These are editor controls. They do not move an entity or become gameplay input while you are typing into an Inspector field.

Selection and transform tools

Click an object to select it, or drag a selection rectangle in Scene view to select several objects. Selection is synchronized with the Hierarchy. The toolbar's high-level selection option chooses a model's top-level object instead of each internal part.

KeyTool
1Select
2Translate
3Rotate
4Scale

Local aligns manipulation axes with the active object's rotation; when it is off, the axes use the world directions. In Center mode, a multi-selection rotates or scales around a shared center. In Pivot mode, each selected object rotates or scales around its own origin. Translation still moves the selection together.

Visibility and locking

Grid, Gizmos, and Statistics are independent Scene toolbar toggles. They are editing aids, not effects added to Game output. Camera and light guides are shown for selected objects.

An entity's editor visibility toggle hides it in Scene view without changing game visibility. A lock prevents selection and editing through editor tools. The lock icon indicates a locked entity. Unlock or show an entity through the Hierarchy when you need to edit it again.

Component options and undo

Click a component header to expand its fields. Non-default components have an enable checkbox on the header and an options menu for supported operations such as removing the component or copying fields. Required identity, name, hierarchy, and transform data are not removable in the same way.

Use Edit's Undo and Redo commands for authoring changes. Preferences includes history limits. Saving editor preferences or layout is separate from saving a scene.
