Start here

BAZZALT is an editor-first game engine. You build a project in the editor, then attach C++ or Lua behaviors to the objects that need gameplay.

What you work with

A project contains your game's assets, settings, and scenes. A scene contains objects such as cameras, lights, and models. An object is called an entity in the programming API. Each entity has components: pieces of data that describe its position, appearance, or behavior.

For example, a cube can have a Transform component that places it in the world, a Primitive Object component that gives it a shape, and a script component that moves it. You do not need to write a window or an engine loop to make that script run. The runtime calls it when the game is playing.

Open a project

  1. Open BAZZALT Hub. The Hub manages projects and installed editor versions.
  2. Create a project, or choose an existing project. Select a compatible installed editor version.
  3. Open the project. The editor scans its assets before displaying the workspace.

The editor is not a separate project-management application. Use the Hub to create and choose projects. A project descriptor has the .bproject extension. Keep it with the project's asset directory rather than moving it by itself.

The editor requires a 64-bit machine. Support for 32-bit game-runtime builds does not mean that the editor can run on 32-bit Windows.

Scene view and Game output are different

The Scene panel is your editing view. Its camera is controlled by you, and its grid, icons, and manipulation handles are editing tools. The Output Game panel shows the active scene through an enabled game Camera component. Moving the editor camera does not move the game camera.

If Game output is black and reports that no camera is available, add or enable a Camera in the active scene. The editor does not create a hidden game camera to replace a missing one.

Choose a guide

If you have never used a game editor, read these in order. You do not need to read API reference pages to create your first scene.

  • Open your first project: start at the Hub, with no panel or programming knowledge assumed.
  • Find your way around: identify the panels by their titles, then open their detailed guides.
  • Your first scene: create an object and check it through a game camera.
  • Panels and scene controls: find the tools and navigate the world.
  • C++ behaviors or Lua behaviors: add movement to an entity.

These are starter guides for version 0.5.0, not a promise that every planned engine feature is available. Public gameplay headers live under include/Bazzalt; private runtime and editor headers are not part of the supported gameplay API.
