Open your first project

You do not need to know C++, Lua, or the editor panels to complete this guide. It takes you from the Hub to an open project.

There are two applications

BAZZALT Hub is the application you open first. It keeps a list of projects and installed editor versions. A project is a folder holding the files for one game. BAZZALT Editor opens that project and lets you change its scenes and objects.

An editor version is an installed engine release, not a separate game project. Several projects can use the same version. This documentation covers editor/core 0.5.0; Hub has its own version number.

Create a project in the Hub

  1. Open BAZZALT Hub and choose its Projects page.
  2. Click New Project…. A separate dialog asks for a name, location, and editor version.
  3. Enter a short name, such as MyFirstGame. The location is the folder where your files will live; the usual default is your Documents folder under BazzaltProjects.
  4. Choose an installed compatible editor. If the version list is empty, check the Hub's editor installations before trying to create the project.
  5. Click Create Project. The project is added to the Projects list.
  6. Select it and click Open Project. Wait for project scanning to finish; the editor window should then open.

Creating a project is not the same as creating a scene or object. You only need a new project for a separate game/workspace, not for each cube.

Open an existing project

Use Add Project… to choose an existing .bproject descriptor, then Open Project. The descriptor is a small file identifying project settings and paths. Keep it with the project's assets rather than copying only that file to another folder.

Recognize the editor window

The row at the top contains menus such as File, Edit, Object, View, and Window. The row underneath contains Play/Stop and object manipulation controls. Below those rows are titled rectangular areas called panels. A panel can also share space with others as tabs; click the tab name to show its content.

Find the tabs named Hierarchy, Scene, Output Game, Properties, Asset Browser, and Console. Do not worry about their contents yet. Their locations can change when you rearrange the workspace; the title is the reliable way to identify a panel.

If a panel is missing, open the Window menu and choose that panel. If the whole layout is confusing, use the workspace reset command to return to the default arrangement. Read Find your way around before trying to use every tool.

Know when work is saved

An asterisk beside a scene's name means changes are not saved yet. Use File's Save command or Ctrl S while editing, and check that the asterisk clears. Closing without saving can discard your work. A layout/preference being saved automatically does not mean the scene is saved.

If opening fails

  • No editor version available: choose/install a compatible editor in the Hub.
  • Missing native runtime error: the editor installation must include its matching engine libraries; a Python-only folder is not a complete installed editor.
  • Asset import error: read the path/error, then inspect Console when the project opens. A failed asset is not necessarily a corrupt whole project.
  • Black Game output: this is not necessarily an opening failure. It needs an enabled game camera; the Scene editor camera is separate.
