Scene view

Scene view is where you look around and place objects. Its editing camera is not your game's camera.

What movement changes

Looking around moves the editor camera only; it does not change a selected Camera entity. The grid gives a spatial reference. Camera/light icons let you find non-mesh entities. An outline shows hovered/selected geometry, and a gizmo supplies manipulation handles for the active tool.

The panel displays the active scene. If you select an entity in an inactive loaded scene, activate that scene to view it here. Hidden/locked objects and hidden overlays can explain a missing icon or handle.

Navigate step by step

  1. Click Scene view so its controls are active.
  2. Select an object and press F to frame it. This centers the editor camera on the selection; it does not teleport the object.
  3. Hold right mouse and drag to look around with focus-point navigation.
  4. Hold right mouse and use W/A/S/D/Q/E to fly: forward, left, back, right, down, up. Looking around during flight rotates around the camera position.
  5. Release the right button to leave navigation. Shift with right-drag pans/moves the camera.

Do not use a letter shortcut while typing in an Properties field and expect camera movement. Menu shortcuts and flight movement are gated to the appropriate interaction.

Choose a manipulation tool

1 selects; 2 translates; 3 rotates; 4 scales. You can also use the toolbar. Click/drag a gizmo axis, not arbitrary nearby geometry, to manipulate a selected object. A selection rectangle selects multiple objects and updates selection while dragging.

Translate changes position. Rotate changes orientation around the chosen pivot. Scale changes size. Local aligns the axes to the active object's orientation; when off, the axes align with the world. These modes do not change the stored component type.

Pivot versus Center

With one selected object the gizmo is at its origin. With a group, Pivot rotates/scales objects around their own origins, whereas Center rotates/scales around a shared center. Translation moves the group in either mode. Choose the mode before a group operation so objects do not unexpectedly orbit a point.

Visibility and guides

Grid, Gizmos, and Statistics are independent toolbar toggles. Top-level selection chooses the highest model object instead of each internal part. Camera and light guide lines belong to selected objects; they help inspect frusta, ranges, and cones and are not game geometry.

The orientation widget in the top corner indicates world axis directions relative to the editor camera. Clicking a direction changes the view. Preferences can hide it. View also contains preset angles, focus/frame actions, and debug shading modes.

Why this is not Game output

Game output uses enabled scene Camera components, their viewports and post-processing. Scene view has editor overlays, its own camera, and editor grid fog. Do not diagnose game camera depth of field by looking only at the editor camera. Read Game output next.
