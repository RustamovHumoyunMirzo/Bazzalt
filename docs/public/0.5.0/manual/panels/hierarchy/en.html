Hierarchy

The Hierarchy is the list of scenes and objects you can edit. It is not a list of files on disk.

Find and read the panel

Click the Hierarchy tab, or open it from Window if it is closed. A scene header sits above its objects. The bold scene header is the active scene displayed in Scene view and Game output. An asterisk on the header means unsaved changes.

An arrow beside an object means it has children. Click the arrow to expand or collapse them. Click the object's name to select it, rather than the arrow. Selecting an object shows its editable components in the Inspector.

Create an object

  1. Right-click in the Hierarchy to open its context menu.
  2. Choose Add new, then the object you need. Primitives contains Cube, Sphere, Cylinder, Capsule, Plane, Cone, and Torus.
  3. Click the newly created object. Look at the Inspector to confirm its name, Transform, and shape/rendering component.

A primitive is built-in geometry and does not require a downloaded 3D model. A Camera or Light is also an entity, even though its Scene view representation can be an icon rather than a solid model.

Parents and children

Drag an object onto another to make it a child. The drop highlight tells you the intended parent. Reparenting keeps the child's world placement by default. Moving the parent afterward also moves the child because their transforms are composed.

Children can have their own components. Adding a Light to a parent does not add a Light to every child. Imported models often have a parent and many nested parts; collapse them when you want a simpler list. Detaching returns an object to its scene root while preserving its world placement.

Objects belong to their scene. This is not a general file tree: do not expect a hierarchy object drag to move a disk file or arbitrarily move an object into another scene's storage.

Search and selection

Type in the search field to find objects without scrolling through every model part. Clear the field to restore the full tree. The three-dot menu beside it contains expand/collapse and reveal helpers. New groups normally start collapsed; Preferences can change that.

Scene view selection and Hierarchy selection are synchronized. A multi-selection means several objects are selected together. The Inspector may show shared editing instead of one object's complete unique components; clear the selection and select one object if you need its exact fields.

Rename, delete, hide, and lock

Right-click an object for supported rename, copy/paste, duplicate, and delete actions. A name is a label, not identity. Deleting a parent also removes its descendants; check the expanded children before deleting a large model group.

Editor visibility hides an object in Scene view and grays its row without changing game visibility. A lock prevents editor selection/manipulation. The lock icon only appears when locked. Use the Hierarchy action to unlock it before editing again.

Scene-header actions

Right-click a scene header to activate, rename, or unload it where allowed. Loading another scene does not activate it automatically. The active scene cannot be unloaded; choose another active scene first. Select the scene header to edit its environment rather than adding object components.
