Editor preferences

Open Edit → Preferences to change this computer's editor settings. These preferences are saved separately from your project and scenes. Changing a navigation or snapping increment does not rewrite an object's transform until you use the relevant tool.

Transform Units

Translation increment is measured in world units (default 0.5), rotation increment in degrees (default 15), and scale increment as a factor (default 0.1). These values are shared by Scene gizmos and Object → Snapping. They do not change the engine's coordinate system. Positive finite values from 0.0001 to 10000 are accepted; invalid saved values fall back to safe defaults.

Enable Snap transform drags for persistent snapping, or hold Ctrl temporarily while dragging a gizmo. Without snapping, movement is continuous. Snapping uses the entire drag displacement, so many small mouse movements still reach the next increment. Drag multipliers change translation, rotation, and scaling sensitivity independently; their default is 1.

Placement and snapping shortcuts

CommandShortcutBehavior
Place Selection at Scene CursorCtrl+Shift+PUses the last pointer position inside Scene, raycasts against other geometry, or falls back to the chosen grid plane. Moving to the menu does not lose the position.
Place at View CenterCtrl+Shift+VMoves selection to the editor camera's focus point.
Align to ViewCtrl+Shift+AAligns object orientation with the editor camera.
Snap Pivots to GridCtrl+Shift+GRounds world positions using the translation increment.
Project onto Grid PlaneCtrl+Shift+JPlaces selection on the chosen grid plane.
Snap Rotation to IncrementCtrl+Alt+RRounds Euler rotation angles using the rotation increment.
Snap Scale to IncrementCtrl+Alt+SRounds scale values using the scale increment.

These commands participate in undo/redo. Parent/child selections are reduced to root objects for placement so descendants do not move twice. Shortcuts yield to text entry, modal dialogs, fly navigation and active Game input. The numeric 1–4 shortcuts select Select, Translate, Rotate and Scale modes.

Scene Statistics

The Statistics chip shows or hides small text at Scene's top right, beside the orientation helper. It is rendered as a native editor overlay, not a floating OS window or Game object. It never appears in Game output. Preferences → Scene Statistics selects the individual lines; FPS and active-scene object count are enabled initially.

Available lines include editor FPS, frame interval, native tick CPU time, selected objects, component instances, enabled cameras/lights, runtime renderables, primitive slots, native viewports, allocated camera targets and runtime GUI batches. Counters update once per second while visible. Frame interval is not a GPU timing measurement; primitive slots are not measured GPU draw calls. Unsupported GPU/VRAM metrics are not fabricated.

Selection and translated labels

The top-level selection chip chooses the model parent instead of an internal child. Its icon follows the current theme. Component titles and Add Component entries use localized display names; GUI field labels contain normal spaces, such as Font Size and Reference Size. The C++/Lua component identifiers and saved property keys remain unchanged.

Storage and compatibility

Apply saves the settings using the existing per-user editor settings store. Toolbar changes continue to save automatically. Older settings files acquire defaults for the new sections. Restore Defaults resets editor preferences; it does not delete assets, scenes, or project metadata.
