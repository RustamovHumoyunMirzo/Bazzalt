Name

Human-readable entity label. Names may repeat and change; use UUID for stable identity.

C++ header: Bazzalt/Components/Name.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Name.h>
struct Name : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Value

std::string Value

Display label, initially empty. It is not required to be unique and is not stable identity.

Name

Name() = default
explicit Name(std::string value) : Value(std::move(value))

Constructs a value using the shown defaults/arguments, or destroys it when its lifetime ends. A value/handle is not ownership of the active host.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
std::string valueValue whose type must match the declaration. Numeric values must be finite where validated.
