Transform

Local position, quaternion rotation and scale. GetWorldTransform/SetWorldTransform on Entity convert between this local data and composed world placement.

C++ header: Bazzalt/Components/Transform.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Transform.h>
struct Transform : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto world = GetEntity().GetWorldTransform();
world.Position.Y += 1.0f;
GetEntity().SetWorldTransform(world);

Position

Vec3 Position{}

Local translation relative to the parent; zero by default.

Rotation

Quaternion Rotation{}

Local quaternion rotation; identity by default. Use radians in quaternion helper constructors.

Scale

Vec3 Scale{1.0f}

Local component-wise scale; one on each axis by default. Zero scale can make world-to-local/inverse operations impossible.

GetMatrix

Mat4 GetMatrix() const

Returns this local Transform as a translation×rotation×scale matrix. This alone does not compose ancestors.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetForward

Vec3 GetForward() const

Returns rotation-applied local negative Z direction.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetRight

Vec3 GetRight() const

Returns rotation-applied local positive X direction.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetUp

Vec3 GetUp() const

Returns rotation-applied local positive Y direction.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

Translate

void Translate(Vec3 translation)

Adds the supplied vector to Position in its current coordinate space. A local Transform does not automatically translate in camera-relative coordinates.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
Vec3 translationTranslation vector in the current Transform/local space.

Rotate

void Rotate(Vec3 axis, float radians)

For Transform, applies an axis-angle quaternion (angle in radians) before the current rotation and normalizes. For Quaternion, returns the rotated input vector; use a unit quaternion.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
Vec3 axisRotation axis; use a nonzero direction.
float radiansAngle in radians, not degrees.
