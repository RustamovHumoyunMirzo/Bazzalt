AssetState

The import state of a registered asset. Ready means runtime data is available; a UUID alone does not prove an import succeeded.

C++ header: Bazzalt/Asset.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Asset.h>
enum class AssetState : std::uint8_t

Unknown

Unknown

No established import state.

Ready

Ready

Imported runtime data is available.

NeedsImport

NeedsImport

Source/cache state requires importing.

Missing

Missing

Expected source asset is missing.

Failed

Failed

Import failed; inspect AssetInfo.LastError.
