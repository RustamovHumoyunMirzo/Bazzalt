CameraPostProcessing

Effects on this camera image, independent of other cameras. Nested values belong to the Camera component and must be committed with it in Lua.

C++ header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Camera.h>
struct CameraPostProcessing

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto& camera = GetEntity().GetComponent<Bazzalt::Camera>();
camera.PostProcessing.Enabled = true;
camera.PostProcessing.DepthOfField.Enabled = true;
camera.PostProcessing.DepthOfField.FocusDistance = 5.0f;
