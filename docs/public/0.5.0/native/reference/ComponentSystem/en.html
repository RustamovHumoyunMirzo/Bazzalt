ComponentSystem

System helper template for processing component views. It exposes protected helpers for derived systems, not a concrete engine-owned update service.

C++ header: Bazzalt/System.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/System.h>
template<typename ... Components> class ComponentSystem : public System

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

class TurnSystem : public Bazzalt::ComponentSystem<Bazzalt::Transform> {
protected:
    void OnUpdate(Bazzalt::Scene& scene, float dt) override {
        auto view = GetView(scene.GetRegistry());
        for (auto id : view) {
            if (scene.GetEntity(static_cast<Bazzalt::Entity::Id>(id)).GetUUID().IsRoot()) continue;
            if (AreComponentsEnabled(view, id))
                view.get<Bazzalt::Transform>(id).Rotate({0,1,0}, dt);
        }
    }
};

GetView

static auto GetView(entt::registry & registry)
static auto GetView(const entt::registry & registry)

Protected derived-system helper returning an EnTT view for its component template types. Do not destroy required storage while iterating.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
const entt::registry & registryAdvanced live EnTT component registry owned by the scene.

AreComponentsEnabled

template<typename View, typename EntityType> static bool AreComponentsEnabled(const View & view, EntityType entity)

Protected helper tests that all selected view components on the entity are enabled. Derived systems must choose to use this check.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
const View & viewEnTT component view used by a derived system.
EntityType entityEntity in the relevant live scene; must not outlive that scene.
