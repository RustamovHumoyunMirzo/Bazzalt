SceneEnvironment

Scene-owned environment settings. Visible background and image-based lighting are independent. Zero asset IDs do not import or create a default sun.

C++ header: Bazzalt/SceneEnvironment.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/SceneEnvironment.h>
struct SceneEnvironment

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto environment = scene->GetEnvironment();
environment.ImageBasedLighting = false;
scene->SetEnvironment(environment);

Mode

SceneEnvironmentMode Mode = SceneEnvironmentMode::Map

Map or Material mode selects which source field applies.

SourceAsset

UUID SourceAsset{}

Environment map asset UUID.

MaterialAsset

UUID MaterialAsset{}

Environment background material asset UUID.

ClearColor

Vec4 ClearColor{0.055f, 0.065f, 0.085f, 1.0f}

Fallback linear RGBA color when no visible skybox applies.

Rotation

Vec3 Rotation{}

Environment IBL rotation in radians; not an entity Transform.

Intensity

float Intensity = 30000.0f

Environment illumination intensity in lux, default 30000.

ImageBasedLighting

bool ImageBasedLighting = true

Whether an environment map supplies illumination; independent of sky visibility.

SkyboxVisible

bool SkyboxVisible = true

Whether the environment background is visible; hiding it does not turn off IBL.

ShowSun

bool ShowSun = false

Environment skybox sun display option, default false.

IsValid

bool IsValid() const

Validates supported mode, finite nonnegative intensity, finite rotations/colors, nonnegative color channels and alpha in [0,1]. Does not validate asset import readiness.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
