SceneSerializer

Host-owned scene serializer. Save/Load and construction are private. Public methods only inspect the registry/error through an authorized host-owned instance.

C++ header: Bazzalt/Serialization.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Serialization.h>
class SceneSerializer final

CurrentFormatVersion

static constexpr std::uint32_t CurrentFormatVersion = 1

Current persistence schema version constant. Do not assume changing it automatically migrates stored data.

GetComponents

ComponentSerializationRegistry & GetComponents()
const ComponentSerializationRegistry & GetComponents() const

Returns the host serializer component-codec registry; this does not expose scene saving/loading.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetLastError

const std::string & GetLastError() const

Returns diagnostic text for the latest failed service operation. A previous successful request does not guarantee another operation cannot fail.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
