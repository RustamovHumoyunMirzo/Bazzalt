AssetInfo

A read-only description of an asset in the active project database. Paths describe source, metadata and generated cache files; this value does not own them.

C++ header: Bazzalt/Asset.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Asset.h>
struct AssetInfo

Id

UUID Id{}

Persistent UUID of the asset/model, not a filesystem path or scene registry integer.

SourcePath

std::filesystem::path SourcePath

Source asset filesystem path; Lua exposes UTF-8 text.

MetaPath

std::filesystem::path MetaPath

Matching .meta sidecar path.

CachePath

std::filesystem::path CachePath

Generated runtime/import cache path.

Importer

std::string Importer

Importer name used for this asset.

ImporterVersion

std::uint32_t ImporterVersion = 0

Version of the importer output schema, used for cache invalidation.

State

AssetState State = AssetState::Unknown

AssetState describing import readiness.

LastError

std::string LastError

Diagnostic text for a failed import; inspect State before using cached data.
