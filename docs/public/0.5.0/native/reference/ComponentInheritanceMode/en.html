ComponentInheritanceMode

Declares how a component is resolved through a parent hierarchy. Adding a component to a parent never automatically copies it onto children.

C++ header: Bazzalt/Component.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Component.h>
enum class ComponentInheritanceMode : std::uint8_t

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.
