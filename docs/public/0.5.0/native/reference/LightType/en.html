LightType

Light geometry/illumination mode. Type determines which intensity units and guide settings apply.

C++ header: Bazzalt/Components/Light.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Light.h>
enum class LightType

Directional

Directional

Distant direction-only light; intensity in lux.

Sun

Sun

Directional sun light with sun disk/halo controls; intensity in lux.

Point

Point

Omnidirectional local light; intensity in lumens and Range in world units.

Spot

Spot

Local cone light; intensity in lumens, Range and cone half-angles apply.
