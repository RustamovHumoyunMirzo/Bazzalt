Console

Include Bazzalt/Console.h. All methods are static and thread-safe. The editor host enables this service; standalone games never enable it.

Runtime contract

bool IsAvailable() noexcept reports whether an editor host exists. Outside the editor, writes and clearing do nothing, produce no stdout/stderr output, and reads return std::nullopt. Inside the editor an empty console returns an engaged optional containing zero or an empty vector. Invalid message indices/IDs return nullopt. Methods suppress service failures rather than throwing.

Do not use console contents as gameplay state. Dereferencing a missing optional remains a caller error: the engine deliberately does not fabricate a value in exported games.

Write messages

Console::Info("Movement started", "Movement");
Console::Warning("Missing optional target", "AI", false);
Console::Error("Cannot find player", "AI");
Console::Log("Details", ConsoleLevel::Info, "Gameplay", false);

Log(text, level=Info, source="Script", showIcon=true) adds a message. Info, Warning and Error take text, source="Script" and showIcon=true. Invalid levels are ignored. Empty source becomes Script. The message store retains up to 10,000 entries and 16 MiB of text/source payloads; text over 65,536 UTF-8 bytes or source over 256 bytes is discarded. Scripts can log from worker threads; Qt updates occur on editor ticks.

ConsoleFilter and ConsoleLevel

ConsoleLevel values are Info=1, Warning=2 and Error=4. ConsoleFilter is a value type with Levels (uint8 bitmask, default 7), Source (string, empty means all), and Contains (string, empty means all). Source matches exactly; Contains searches message text. Both are case-sensitive UTF-8 byte matches; filters do not change the Console panel's visible filter settings.

ConsoleFilter filter;
filter.Levels = 2 | 4;
filter.Source = "Physics";
filter.Contains = "collision";
Console::Clear(filter);

Read snapshots

GetCount(filter={}) returns optional<size_t>. GetMessages(filter={}) returns optional<vector<ConsoleMessage>>. GetMessageAt(size_t index) reads a zero-based index in the unfiltered store; FindMessage(uint64_t id) reads a stable ID. The latter two return optional<ConsoleMessage>. All results are copies, not live references; modifying them does not edit the Console.

ConsoleMessage fields: Id (uint64 stable until removed), Text (string), Level (ConsoleLevel), Source (string), ShowIcon (bool), Timestamp (double Unix seconds). Indices shift after clearing or eviction; retain Id instead.

if (auto messages = Console::GetMessages()) {
    for (const auto& message : *messages) {
        if (message.Source == "AI") Console::ClearMessage(message.Id);
    }
}

Clear operations

Clear(filter={}) removes matching entries; default removes all. ClearAt(size_t index) removes a zero-based unfiltered entry. ClearMessage(uint64_t id) removes one ID. ClearMessages(const vector<uint64_t>& ids) removes IDs in one batch. Missing indices/IDs are harmless no-ops. These operations affect the same store displayed in the editor, not only script-originated messages.
