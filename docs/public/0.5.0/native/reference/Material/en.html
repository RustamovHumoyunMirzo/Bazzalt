Material

A handle to shared imported or owned transient material state. Runtime property edits affect rendering without writing the source asset.

C++ header: Bazzalt/Material.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Material.h>
class Material final

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto material = Bazzalt::Material::Create();
material.SetFloat("roughness", 0.4f);
material.ApplyTo(GetEntity());
// Retain the handle; Destroy it during owned-resource cleanup.

AllSlots

static constexpr std::size_t AllSlots = std::numeric_limits<std::size_t>::max()

Marker for assignment to every slot: maximum size_t in C++, -1 in Lua. Actual slot indices are zero-based.

ApplyTo

std::size_t ApplyTo(Entity entity, std::size_t slot = AllSlots, bool includeChildren = false) const

Assigns existing Mesh/PrimitiveObject components on an entity. AllSlots is default; descendants are opt-in. Returns entities changed. Invalid handles/slots throw; primitive slots other than 0/AllSlots are rejected.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
Entity entityEntity in the relevant live scene; must not outlive that scene.
std::size_t slot = AllSlotsZero-based material slot; AllSlots/-1 selects all slots.
bool includeChildren = falseApply through descendants only when true; default false.

SetRenderTexture

void SetRenderTexture(const std::string& name, RenderTexture value) binds live camera output to a Texture2D parameter. Built-in Unlit/UnlitTransparent expose baseColorTexture. Wrong parameter names/types throw invalid_argument. Empty handles remove the live binding. These are runtime overrides, not asset-file edits. See RenderTexture for ownership and feedback rules.

GetRenderTexture

RenderTexture GetRenderTexture(const std::string& name) const returns a bound camera reference or an empty handle when the parameter uses an asset source. Wrong parameter names/types throw invalid_argument. SetTexture and resets clear camera bindings; compatible cloning/copying preserves them.
