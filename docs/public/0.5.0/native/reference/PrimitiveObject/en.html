PrimitiveObject

Procedural renderable geometry. Shape decides which dimension fields are used. Entity Transform still controls placement, orientation and overall scaling.

C++ header: Bazzalt/Components/PrimitiveObject.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/PrimitiveObject.h>
struct PrimitiveObject : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto& primitive = GetEntity().GetComponent<Bazzalt::PrimitiveObject>();
primitive.Shape = Bazzalt::PrimitiveShape::Sphere;
primitive.Radius = 0.75f;

Shape

PrimitiveShape Shape = PrimitiveShape::Cube

Selects which procedural dimensions apply.

Size

Vec3 Size{1.0f, 1.0f, 1.0f}

Cube X/Y/Z geometry size before entity Transform scale.

Radius

float Radius = 0.5f

Sphere/Cylinder/Capsule/Cone radius before Transform scale.

Height

float Height = 2.0f

Cylinder/Capsule/Cone height setting.

Width

float Width = 1.0f

Plane width.

Depth

float Depth = 1.0f

Plane depth.

MajorRadius

float MajorRadius = 0.75f

Torus ring center radius.

MinorRadius

float MinorRadius = 0.25f

Torus tube radius.

Segments

std::uint32_t Segments = 32

Circumferential geometry subdivisions, default 32.

Rings

std::uint32_t Rings = 16

Latitudinal/tube subdivisions, default 16.

Color

Vec4 Color{0.72f, 0.72f, 0.75f, 1.0f}

Linear RGBA fallback surface color; a material override supplies its own parameters.

MaterialAsset

UUID MaterialAsset{}

Global material override UUID; zero preserves imported/built-in material.

LayerMask

std::uint8_t LayerMask = 0 xff

Renderable layer bits, default 0xff. Not a physics collision-layer setting.

Visible

bool Visible = true

Game render visibility; separate from the editor-only hidden flag.

CastShadows

bool CastShadows = true

Whether this geometry casts shadows from shadow-capable lights.

ReceiveShadows

bool ReceiveShadows = true

Whether this geometry receives rendered shadows.

SetMaterial

void SetMaterial(Material material)

Assigns a material UUID override. The Mesh slot overload targets a zero-based slot (0–4095); the single-argument overload overrides all slots. PrimitiveObject has only one slot.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
Material materialOperand/value of the type shown in the declaration; see this method's behavior and coordinate-space description.

GetMaterial

Material GetMaterial() const

Returns the assigned material handle. A missing override can be invalid even if the imported original surface is rendering normally.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ClearMaterial

void ClearMaterial()

Removes the material override, restoring the imported/built-in surface on an ensuing update. The slot overload clears only that zero-based slot.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
