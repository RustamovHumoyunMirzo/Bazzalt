AntiAliasing

Camera anti-aliasing mode. Anti-aliasing reduces stair-stepped edges; temporal modes also use previous frames.

C++ header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.
