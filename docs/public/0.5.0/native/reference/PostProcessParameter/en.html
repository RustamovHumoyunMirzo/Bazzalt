PostProcessParameter

One named custom post-process value. Use factory methods to populate the appropriate typed storage field.

C++ header: Bazzalt/PostProcessing.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/PostProcessing.h>
struct PostProcessParameter

Name

std::string Name

Shader parameter name.

Type

PostProcessParameterType Type = PostProcessParameterType::Float

Value storage kind.

Value

Vec4 Value{}

Float/Vec2/Vec3/Vec4 value packed into Vec4.

IntegerValue

std::int32_t IntegerValue = 0

Integer payload when Type is Integer.

BooleanValue

bool BooleanValue = false

Boolean payload when Type is Boolean.

TextureAsset

UUID TextureAsset{}

Texture asset UUID when Type is Texture.

Float

static PostProcessParameter Float(std::string name, float value)

Returns a named Float parameter with the correct Type and typed payload. The effect shader must declare a compatible parameter.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
std::string nameDisplay label or declared parameter/type name as specified by this method; names are not UUID identity.
float valueValue whose type must match the declaration. Numeric values must be finite where validated.
