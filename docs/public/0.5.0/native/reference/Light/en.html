Light

Illumination emitted from the owning entity. Transform determines its position/direction. Range and cone fields only apply to the corresponding light types.

C++ header: Bazzalt/Components/Light.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Light.h>
struct Light : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto& light = GetEntity().GetComponent<Bazzalt::Light>();
light.Type = Bazzalt::LightType::Point;
light.Range = 6.0f;

Type

LightType Type = LightType::Point

Directional, Sun, Point or Spot.

Color

Vec3 Color{1.0f}

Linear RGB light color, white by default.

Intensity

float Intensity = 1000.0f

Lux for Directional/Sun; lumens for Point/Spot. Default 1000.

Range

float Range = 10.0f

World-space spherical falloff radius for Point/Spot, default 10; ignored for Directional/Sun.

InnerConeAngle

float InnerConeAngle = ToRadians(20.0f)

Spot inner cone half-angle in radians, default 20 degrees.

OuterConeAngle

float OuterConeAngle = ToRadians(30.0f)

Spot outer cone half-angle in radians, default 30 degrees; keep it ≥ inner.

SunAngularRadius

float SunAngularRadius = 0.00935f

Sun disk angular radius in radians, default 0.00935; Sun only.

SunHaloSize

float SunHaloSize = 10.0f

Sun halo size factor, default 10; Sun only.

SunHaloFalloff

float SunHaloFalloff = 80.0f

Sun halo falloff factor, default 80; Sun only.

CastShadows

bool CastShadows = true

Enables shadow casting from this light, where the renderer supports the chosen light configuration.
