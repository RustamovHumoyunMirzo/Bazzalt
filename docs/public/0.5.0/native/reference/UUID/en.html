UUID

128-bit stable identifier. Zero represents the scene root but is not a valid nonzero asset identifier. A UUID does not own an entity or asset.

C++ header: Bazzalt/UUID.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/UUID.h>
class UUID final

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

Bazzalt::UUID id;
bool valid = Bazzalt::UUID::TryParse(savedText, id);
if (valid) { /* Resolve through Scene or AssetManager. */ }
