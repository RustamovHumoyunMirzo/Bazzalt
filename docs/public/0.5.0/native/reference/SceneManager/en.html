SceneManager

Small static gameplay facade for active-scene lookup and deferred loading. It intentionally does not expose project loading, authoring saves or engine initialization.

C++ header: Bazzalt/SceneManager.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/SceneManager.h>
class SceneManager final

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto* scene = Bazzalt::SceneManager::GetActiveScene();
// Loading is deferred, not immediate:
bool accepted = Bazzalt::SceneManager::LoadScene(sceneAssetUUID);
