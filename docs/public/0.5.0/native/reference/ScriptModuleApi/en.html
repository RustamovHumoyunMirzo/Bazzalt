ScriptModuleApi

Versioned native module C-ABI callback record. Generated module entry points supply this; ordinary COMPONENT authors should not manually construct it.

C++ header: Bazzalt/Script.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Script.h>
struct ScriptModuleApi

AbiVersion

std::uint32_t AbiVersion

Module ABI version; must match ScriptAbiVersion supported by the host.

TypeName

const char * TypeName

Declared behavior type name.

Create

void *(* Create)(const char * entityUUID)

ABI callback allocating an instance for entity UUID text; returns opaque instance pointer.

Destroy

void(* Destroy)(void *)

ABI callback releasing an instance allocation after lifecycle cleanup.

OnCreate

void(* OnCreate)(void *)

ABI callback forwarding creation lifecycle for an opaque instance.

OnUpdate

void(* OnUpdate)(void *, float)

ABI callback forwarding frame delta seconds for an opaque instance.

OnDestroy

void(* OnDestroy)(void *)

ABI callback forwarding gameplay cleanup before allocation destruction.

SetProperty

bool(* SetProperty)(void *, const char *, const char *)

ABI callback (instance, property name, serialized value) returning successful assignment.
