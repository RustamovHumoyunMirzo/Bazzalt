Vec2

Two floating-point coordinates. Useful for screen positions and 2D directions. Arithmetic returns values; zero normalization returns zero.

C++ header: Bazzalt/Math.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Math.h>
struct Vec2

Lerp

static constexpr Vec2 Lerp(Vec2 from, Vec2 to, float amount)

Linear interpolation from the first value to the second by amount. Amount is not clamped: 0 selects from, 1 selects to, other values can extrapolate.
