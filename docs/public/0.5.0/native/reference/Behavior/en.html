Behavior

Attachable gameplay lifecycle base. The editor/runtime constructs instances, binds their entity, supplies property values and calls callbacks.

C++ header: Bazzalt/Script.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Script.h>
class Behavior : public Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

COMPONENT(Example) {
public:
    PROPERTY(float, Speed, 4.0f)
    void OnUpdate(float deltaTime) override { (void)deltaTime; }
};

OnCreate

virtual void OnCreate()

Host callback called after an instance is created and initial properties are applied. Initialize runtime state here; do not initialize the engine.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

OnUpdate

virtual void OnUpdate(float deltaTime)

Host callback for enabled frame updates. deltaTime is scaled seconds, not an FPS count. Multiply rates by it for time-based behavior.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
float deltaTimeScaled frame duration in seconds.

OnFixedUpdate

virtual void OnFixedUpdate(float fixedDeltaTime)

Host callback for enabled fixed-step work. The supplied step is in seconds; the host owns scheduling.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
float fixedDeltaTimeScaled fixed-step duration in seconds.

OnDestroy

virtual void OnDestroy()

Host cleanup callback. Release owned transient resources; do not destroy shared assets or take over host shutdown.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetEntityUUID

const std::string & GetEntityUUID() const

Returns the UUID text bound to this behavior by the runtime, not the entity display name.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetEntity

Entity GetEntity() const

Resolves a UUID or transient registry ID in this scene. Returns an invalid Entity when it cannot resolve; registry IDs are not persistent asset IDs.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
