ScriptRuntimeAccess

Host/compiled-module bridge declared in a public header for ABI plumbing. Do not call its binding methods to take over the application loop.

C++ header: Bazzalt/Script.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Script.h>
class ScriptRuntimeAccess final

Bind

static void Bind(Behavior & behavior, const char * entity)

ABI bridge sets the behavior entity UUID string. Generated host glue calls it; not an application/gameplay initialization entry point.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
Behavior & behaviorBehavior instance owned by the host/module glue.
const char * entityEntity in the relevant live scene; must not outlive that scene.

BindTime

static void BindTime(Detail::TimeState * state)
