SceneQueryBounds

Optional local selection/query geometry for an entity. Center and Extents/Radius are in local space and are transformed with the entity.

C++ header: Bazzalt/Components/SceneQueryBounds.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/SceneQueryBounds.h>
struct SceneQueryBounds : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Shape

SceneQueryShape Shape = SceneQueryShape::Box

Box or Sphere query geometry.

Center

Vec3 Center{}

Local-space center offset.

Extents

Vec3 Extents{0.5f}

Local box half-size, default 0.5 per axis.

Radius

float Radius = 0.5f

Local sphere radius, default 0.5.

LayerMask

std::uint32_t LayerMask = 0 xffffffffu

Query layer bits, default all bits set.
