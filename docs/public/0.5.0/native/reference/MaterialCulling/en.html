MaterialCulling

Which triangle faces are culled (not drawn). FrontAndBack intentionally removes all faces from that pass.

C++ header: Bazzalt/Material.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Material.h>
enum class MaterialCulling : std::uint8_t

None

None

Render front and back faces.

Front

Front

Cull front faces.

Back

Back

Cull back faces.

FrontAndBack

FrontAndBack

Cull both faces; normally no visible geometry.
