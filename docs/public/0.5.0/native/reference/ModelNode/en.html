ModelNode

Import identity of a model child. StablePath allows the model structure to be matched across import changes. A grouping node need not contain a mesh.

C++ header: Bazzalt/Components/ModelNode.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/ModelNode.h>
struct ModelNode : Component

Component-derived types also inherit Enabled, IsEnabled and SetEnabled. Entity APIs protect required default components. References into scene storage must not outlive their entity/scene.

Boolean import flag indicating this child contains renderable mesh geometry.
