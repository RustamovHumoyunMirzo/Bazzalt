InputAxis

Named keyboard or mouse axes. Horizontal/Vertical are keyboard axes, not analog controller bindings.

C++ header: Bazzalt/Input.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Input.h>
enum class InputAxis : std::uint8_t

Horizontal

Horizontal

D/right minus A/left keyboard axis.

Vertical

Vertical

W/up minus S/down keyboard axis.

MouseX

MouseX

Current horizontal mouse delta.

MouseY

MouseY

Current vertical mouse delta.

ScrollX

ScrollX

Current horizontal scroll delta.

ScrollY

ScrollY

Current vertical scroll delta.
