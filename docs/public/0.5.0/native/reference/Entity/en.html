Entity

A non-owning scene object handle. Default construction is invalid. Do not retain or call handles after their scene has been destroyed.

C++ header: Bazzalt/Entity.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Entity.h>
class Entity final

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto entity = GetEntity();
if (auto* light = entity.TryGetComponent<Bazzalt::Light>())
    light->Intensity = 1200.0f;

Id

using Id = std::uint32_t

C++ alias for the 32-bit transient registry ID. It is not the 128-bit persistent UUID.

GetComponent

template<typename Component> Component & GetComponent() const

Returns the existing component. Missing/invalid entity fails. C++ returns a reference; Lua returns a copy.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

TryGetComponent

template<typename Component> Component * TryGetComponent() const

Returns a component pointer in C++ or copied value in Lua, and null/nil if absent. Unknown Lua type strings are errors rather than absence.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

RemoveComponent

template<typename Component> void RemoveComponent() const

Removes an optional component. Identity/Hierarchy/Name/Transform cannot be removed; C++ enforces those restrictions at compile time.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

IsComponentEnabled

template<typename ComponentType> bool IsComponentEnabled() const

Reports an existing optional component enable state. Required defaults are always enabled in the editor/Lua; C++ prevents those queries through this template.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

SetComponentEnabled

template<typename ComponentType> void SetComponentEnabled(bool enabled) const

Changes an existing optional component enable flag, preserving its values. Required defaults cannot be disabled.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
bool enabledNew enable state; false preserves values rather than removing them.

IsValid

bool IsValid() const

Returns whether the handle currently names a live registry entity. The registry itself must still be alive; this is not a lifetime-safe pointer after scene destruction.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

operatorbool

explicit operator bool() const

Tests handle/hit validity or nonzero UUID. This does not make a non-owning entity safe after its scene lifetime ends.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

Id GetId() const

Returns the transient registry entity ID, not the persistent UUID. Do not save it as a cross-scene identifier.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

Returns direct children, not all descendants. Returned handles do not own those entities.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

Returns the composed parent-to-child world transformation matrix, not just the local Transform matrix.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

GetWorldTransform

Transform GetWorldTransform() const

Returns a world-space Transform value. Edit the returned copy and call SetWorldTransform to commit it.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

SetWorldTransform

bool SetWorldTransform(const Transform & transform) const

Commits world placement by converting it into local Transform data under the parent. Returns false for a rejected/non-decomposable placement.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.

ArgumentMeaning
const Transform & transformComplete Transform value in the coordinate space named by the method.
