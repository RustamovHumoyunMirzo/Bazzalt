ModelAssetNode

One node in an imported model description. Node children and root entries are source/node indices; no scene entity is created until instantiation.

C++ header: Bazzalt/ModelAsset.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/ModelAsset.h>
struct ModelAssetNode

NoMesh

static constexpr std::uint32_t NoMesh = std::numeric_limits<std::uint32_t>::max()

Sentinel uint32 maximum indicating this imported node has no mesh.

Name

std::string Name

Node display name from the imported model.

StablePath

std::string StablePath

Importer path identifying a model node across hierarchy changes.

SourceIndex

std::uint32_t SourceIndex = 0

Stable source glTF node index.

MeshIndex

std::uint32_t MeshIndex = NoMesh

Imported mesh index or no-mesh sentinel.

Position

Vec3 Position{}

Local translation relative to the parent; zero by default.

Rotation

Quaternion Rotation{}

Local quaternion rotation; identity by default. Use radians in quaternion helper constructors.

Scale

Vec3 Scale{1.0f}

Local component-wise scale; one on each axis by default. Zero scale can make world-to-local/inverse operations impossible.

Children

std::vector<std::uint32_t> Children

Zero-based node indices for direct children.

MaterialNames

std::vector<std::string> MaterialNames

Imported material labels, not runtime Material handles.

HasMesh

bool HasMesh() const

Reports whether this node contains a mesh rather than only grouping/transform data.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
