MaterialBuilder

Queues typed values against a precompiled shader, then creates a validated transient Material. It does not compile shader source or introduce undeclared uniforms.

C++ header: Bazzalt/MaterialBuilder.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/MaterialBuilder.h>
class MaterialBuilder final

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto material = Bazzalt::MaterialBuilder()
    .SetColor("baseColor", {0.2f, 0.4f, 0.8f, 1.0f})
    .Build();
