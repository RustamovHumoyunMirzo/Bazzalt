Bshader diagnostics and limits

Translation validates the language. Filament compilation validates GPU types and stages. A successful translation alone does not prove a shader is renderable.

Reading errors

The translator provides severity, source line, column, and message for each diagnostic. Some semantic diagnostics identify the line with column 1 rather than an exact token column. Error diagnostics prevent output. Fix the first meaningful error, then rebuild; syntax recovery can produce follow-up errors. Filament errors refer to generated material source, which is available beside the cache for inspection.

A shader compiles but looks wrong

Check the material assignment, camera, light/environment, UV/tangent data, texture binding, and Console. A lit surface without lights is not an unlit surface. Opacity needs transparent blending. Set normal as a tangent-space direction; do not assign worldNormal directly. A five-tap texture blur is not Depth of Field. Shader vertex offsets do not change hierarchy transforms or picking. A material parameter must have the exact declared name/type, and editing one shared material changes all its users.

Current boundaries

Source size is limited to 4 MiB, token count to 100,000, nested expressions/blocks to 128, and individual loop execution to 1,024 iterations. Property names are limited to 200 characters. These are guardrails, not guarantees that adversarial shaders are safe or cheap. Nested loops can multiply work. The compiler is an authoring tool for trusted project sources, not a sandbox for untrusted input.

There are no user-defined functions, structs, array declarations, custom varyings, compute/geometry stages, includes, preprocessor macros, or source-level render-pass definitions. GLSL calls are passed through and checked by matc. Camera-relative coordinates, render time, and GPU-deformed picking need explicit care. Use lower-level .mat source for Filament features outside this language, and public camera post-processing for fullscreen effects.

Reporting an issue

Include the smallest source that reproduces it, editor/version/backend, full Console diagnostics, and the generated translated material if the problem occurs in matc. Do not report only that the translator returned success. Avoid sending unrelated project assets or private data.
