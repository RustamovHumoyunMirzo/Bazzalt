Bshader compiler C API

This separate authoring library is for engine/tool developers. Gameplay uses the material API, not compiler contexts.

Context and result ownership

#include "shader_translator.h"
ShaderContext* context = ShaderContextCreate();
if (!context) { /* allocation failed */ }
else {
    ShaderCompilationResult* result = ShaderTranslatorCompileString(context,
        "shader Red { material { color=vec4(1.0,0.0,0.0,1.0); } }");
    if (result && ShaderResultIsSuccess(result)) {
        // Copy/process annotated material source; this is not a GPU binary.
        const char* source = ShaderResultGetOutput(result);
        (void)source;
    }
    ShaderCompilationResultFree(result);
    ShaderContextDestroy(context);
}

A context owns parser/transform temporary memory and registrations. It is not thread-safe; serialize access or use one per worker. Results own independent copies, remain valid after context reset/destruction, and must each be freed. Reset between repeated compilations to release arena allocations. Registration strings are copied; userData is borrowed and must outlive callbacks.

Lifecycle and compilation functions

FunctionContract
ShaderContextCreate()Create a context with built-in transforms; NULL if context allocation fails.
ShaderContextDestroy(ctx)Free context, arena, and registrations; NULL accepted.
ShaderContextReset(ctx)Reset temporary arena, preserve transforms/helpers; NULL accepted.
ShaderTranslatorCompile(ctx, source, size)Translate exact byte length, without requiring a terminator. Returns an owned diagnostic result; NULL if result allocation fails.
ShaderTranslatorCompileString(ctx, source)Convenience for a NUL-terminated string.
ShaderCompilationResultFree(result)Release owned strings/diagnostics; NULL accepted.

Result inspection

ShaderResultIsSuccess checks success. ShaderResultGetOutput returns a borrowed NUL-terminated source pointer, or NULL on failure; ShaderResultGetOutputSize is its byte length excluding the terminator. ShaderResultGetError returns the borrowed error summary, or NULL on success. ShaderResultGetDiagnosticCount gives the entry count; ShaderResultGetDiagnostic(result, index) returns severity, line, column, and borrowed message. An out-of-range entry has a NULL message. All borrowed result strings expire when the result is freed.

The output contains editor defaults and native Filament parameter references. Extract reflection, strip default metadata, then run matc to produce .filamat. The supported Bazzalt implementation is Editor/materials.py, which also handles legacy flat references; do not hand the translator's text to a runtime material loader. BSHADER_VERSION_MAJOR, MINOR, and PATCH identify the C library version, not the documentation folder.

Registering a high-level function

ShaderContextRegisterTransform(ctx, name, callback, userData) registers or replaces a call transform, including a built-in with the same name. The callback receives ShaderTransformNode*, ShaderTransformBuilder*, and userData. Node and builder are valid only during that callback; do not retain them. Registrations survive Reset and disappear with Destroy.

static void DoubleLiteral(ShaderTransformNode* node,
                          ShaderTransformBuilder* builder, void* userData) {
    (void)userData;
    // This extension intentionally accepts only a numeric literal.
    char text[64];
    snprintf(text, sizeof(text), "%.9f",
             ShaderTransformNodeGetArgAsNumber(node, 0) * 2.0);
    ShaderTransformBuilderSetReplacementExpr(builder, text);
}
// Called once for a newly created context:
// ShaderContextRegisterTransform(context, "doubleLiteral", DoubleLiteral, NULL);

Include stdio.h for snprintf. The resulting source can use float value = doubleLiteral(0.25);. This accessor API is deliberately narrow: it does not type-check or evaluate arbitrary argument expressions. The built-in blur path handles arbitrary UV/radius expressions internally; copying the literal callback does not provide that ability for a custom function.

Argument accessors

FunctionBehavior
ShaderTransformNodeGetArgCount(node)Number of call arguments.
ShaderTransformNodeGetArgAsIdentifier(node, index)Borrowed name only for a bare identifier; otherwise NULL.
ShaderTransformNodeGetArgAsNumber(node, index)Numeric literal or unary-negative literal; unsupported/missing argument returns 0.0, indistinguishable from a real zero.
ShaderTransformNodeArgIsProperty(node, index)True only for a bare identifier declared as a property.
ShaderTransformNodeResolveIdentifier(node, name)Maps properties to generated parameter names; other names unchanged. Returned scratch text expires on the next resolution on that node; copy it before resolving again.

ResolveIdentifier does not lower built-in aliases, validate locals, or serialize compound expressions. Treat callback output as target code, not Bshader source. Do not silently guess a caller's argument intent; document an extension's allowed inputs.

Builder and helper functions

ShaderTransformBuilderSetReplacementExpr(builder, text) supplies the replacement target-language expression. Call it once for every invocation. Missing replacement is a compilation error. ShaderTransformBuilderEmitLine(builder, code) emits target code before the containing statement; take special care with branches and conditions, because this is not an expression-local execution model. Avoid side effects.

ShaderContextRegisterHelperSource(ctx, name, source) stores a named target-language helper. ShaderTransformBuilderRequireHelper(builder, name) requests it; the compiler inserts it once per stage in which it is used. An unregistered helper is an error. Helpers must be valid for their stage and avoid collisions with Filament/generated identifiers. Registered replacement/helper source is trusted code and is validated by matc, not sandboxed.

Building and testing the library

cmake -S Bshader -B build/bshader-tests -DBSHADER_BUILD_TESTS=ON
cmake --build build/bshader-tests --config Release
ctest --test-dir build/bshader-tests -C Release --output-on-failure

This builds the small C11 translator without downloading renderer dependencies. Native tests cover parsing, defaults, validation, scope, loops, and callbacks. Editor material tests also compile real GPU packages using the installed Filament SDK; run them when changing generated code. A string-output assertion is not a substitute for that compiler check.
