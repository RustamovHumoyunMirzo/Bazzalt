Bshader examples

Save a complete example as .bshader or .shad, create a Material asset, and assign it to a renderable object. Texture examples also need an assigned image.

Solid color

shader SolidColor {
    properties { tint: vec4 = vec4(1.0, 0.0, 0.0, 1.0); }
    material { color = tint; roughness = 0.5; }
}

This is lit: it needs scene lighting to look bright. Edit tint on the material, not by recompiling for every color change.

Unlit textured mesh

shader UnlitTextured {
    options { shading: unlit; }
    properties { albedo: texture2d; }
    material { color = texture(albedo, UV); }
}

This selects real unlit shading; adding emissive to a lit shader is not equivalent. For translucent textures also choose blending: transparent;.

Pulsing emission

shader PulsingGlow {
    properties {
        glowColor: vec4 = vec4(1.0, 0.3, 0.1, 1.0);
        pulseSpeed: float = 2.0;
    }
    material {
        float pulse = sin(time * pulseSpeed) * 0.5 + 0.5;
        color = glowColor;
        emissive = vec4(glowColor.rgb * pulse, 1.0);
    }
}

pulseSpeed is radians per second. Emission brightness and bloom depend on the camera's exposure/post-processing settings. For simulation-paused animation, replace time with an application-controlled property.

Property-driven blur

shader BlurToggle {
    properties {
        albedo: texture2d;
        useBlur: bool = false;
        blurRadius: float = 2.0;
    }
    material {
        if (useBlur) { color = blur(albedo, UV, blurRadius); }
        else { color = texture(albedo, UV); }
        roughness = 0.5;
    }
}

This blurs the object's texture, not objects behind it. Toggle useBlur on the material and adjust radius in texture texels.

Vertex wave

shader VertexWave {
    properties { amplitude: float = 0.05; tint: vec4 = vec4(0.2, 0.6, 1.0, 1.0); }
    vertex { position = position + vec3(0.0, sin(time) * amplitude, 0.0); }
    material { color = tint; roughness = 0.5; }
}

This offsets vertices along render-world Y. It does not move the entity Transform or deform CPU picking bounds. A detailed mesh is needed for spatial waves; moving all vertices by the same value simply moves its rendered surface.

Camera-dependent surface

shader Facing {
    properties { tint: vec4 = vec4(1.0); }
    material {
        vec3 direction = normalize(cameraPosition - worldPosition);
        float facing = max(dot(worldNormal, direction), 0.0);
        color = vec4(tint.rgb * facing, tint.a);
        roughness = 0.5;
    }
}

Camera and surface position use matching render coordinates. The result changes with the camera; it is not a replacement for physical lighting.
