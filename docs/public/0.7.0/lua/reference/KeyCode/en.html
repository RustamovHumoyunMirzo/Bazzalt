KeyCode

Physical keyboard identifiers, independent of operating-system virtual-key values. Use these constants with Input rather than hard-coded platform key numbers.

Underlying public header: Bazzalt/Input.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Lua members and signatures

Use Bazzalt.KeyCode. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.KeyCode.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
