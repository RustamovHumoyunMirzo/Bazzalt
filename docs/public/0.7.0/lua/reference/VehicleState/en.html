VehicleState

Read-only runtime snapshot from PhysicsScene.GetVehicleState. Speed is signed forward m/s, EngineRPM is RPM, Clutch is normalized friction, Gear is -1 reverse/0 neutral/positive forward, and GroundedWheels/WheelCount summarize registered contacts. Absent outside running simulation.

Lua members and signatures

Use Bazzalt.VehicleState. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VehicleState.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
