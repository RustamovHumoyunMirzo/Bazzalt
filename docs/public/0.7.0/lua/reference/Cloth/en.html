Cloth

Cloth deforms the attached PrimitiveObject or Mesh/model subtree. It uses the existing shape and primary UV coordinates; an empty MaterialAsset preserves source material slots. PinEdges refers to source-boundary edges. Width, Height, SegmentsX and SegmentsY remain only for older scene data and no longer generate a plane. PhysicsScene returns welded solver-particle positions and exposes zero-based particle controls.

Lua members and signatures

Use Bazzalt.Cloth. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Cloth.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
