RenderTexture

A non-owning reference to a camera's live output, available as Bazzalt.RenderTexture. Lua uses the same rendering, resize, and lifetime rules as C++.

Display a camera feed

local B = Bazzalt
local camera = scene:CreateEntity("Security camera")
camera:AddComponent("Camera")
local target = camera:AddComponent("CameraRenderTarget")
target.Width = 512
target.Height = 256
camera:SetComponent("CameraRenderTarget", target)
local feed = B.RenderTexture.FromCamera(camera)
local material = B.Material.Create(B.ShaderPreset.Unlit)
material:SetRenderTexture("baseColorTexture", feed)
material:ApplyTo(monitor)
local image = imageEntity:GetComponent("GuiImage")
image:SetRenderTexture(feed)
imageEntity:SetComponent("GuiImage", image)

Construction

B.RenderTexture.new() creates an empty handle. The handle holds a camera UUID, never a scene pointer or native rendering object.

FromCamera(camera)

Static factory requiring a valid entity with Camera and CameraRenderTarget. Invalid input raises a Lua error. It does not add or enable components.

FromCameraUUID(id)

Static factory accepting a UUID without validation; zero creates an empty handle.

GetCameraUUID()

Returns the producer entity UUID, not an asset UUID.

Resolve(scene)

Returns the entity in the supplied Scene, or an invalid Entity if absent.

IsValid(scene)

Checks that the camera is enabled and Active and has an enabled target. This is not a GPU-completion check.

GetSize(scene)

Returns effective requested dimensions as a Vec2, bounded to 1–4096 pixels per axis, or zero for a missing target. Works for a disabled producer.

Resize(scene, width, height)

Updates target dimensions for the next render tick. Returns false if the target is absent; invalid dimensions raise an error. Unlike copied Lua components, this method changes the actual scene target directly.

Materials, builders, and images

material:SetRenderTexture(name, feed) requires a Texture2D parameter. Built-in Unlit and UnlitTransparent use baseColorTexture. Custom shader samplers also work. material:GetRenderTexture(name) returns an empty handle for an asset source. Cloning/copying preserves compatible bindings; SetTexture and parameter resets clear them. builder:SetRenderTexture(name, feed) validates when Build is called.

image:SetRenderTexture(feed) clears its asset source; image:SetTexture(asset) clears its camera source. image:GetRenderTexture() returns its camera reference. GUI components obtained from entities are copies: call SetComponent after editing them.

Rendering and limitations

Feeds render automatically once per engine tick, independently of Game panel visibility. Camera-Bound Frames are drawn into the output after 3D rendering. Missing GUI feeds draw nothing; missing material feeds become black. Target disabling restores direct camera presentation; camera disabling stops output.

Chained captures render producers before consumers. Cycles and self-recursion read the previous completed tick through double-buffered color textures; each cycle publishes together. The first tick after creation/resize has no completed history. World-material dependencies are conservative, so some feeds may have one tick of latency even when a monitor is outside a camera's frustum. Recursion uses bounded temporal history, not unlimited nested renders. Material feed bindings are runtime overrides; recreate them in OnCreate rather than expecting material asset files to save them.

C++ contract and rendering details

Lua members and signatures

Use Bazzalt.RenderTexture. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.RenderTexture.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
