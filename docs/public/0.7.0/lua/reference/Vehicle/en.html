Vehicle

Chassis-level wheeled-vehicle solver. Requires an enabled dynamic Rigidbody and chassis collider. Local Up/Forward define its axes; CollisionTest selects ray, sphere or cylinder ground tests. Distances use metres and MaxPitchRollAngle uses degrees. Descendant VehicleWheel entities supply the wheels. No automatic input capture occurs.

Lua members and signatures

Use Bazzalt.Vehicle. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Vehicle.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
