WheelSuspension

Wheel-local suspension configuration. Direction is a unit vector in chassis space. MinLength/MaxLength/PreloadLength use metres; Frequency is Hz and Damping is a damping ratio. ForcePoint is chassis-local and is used only when UseForcePoint is true. Disabling this component disconnects the wheel from the vehicle solver.

Lua members and signatures

Use Bazzalt.WheelSuspension. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.WheelSuspension.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
