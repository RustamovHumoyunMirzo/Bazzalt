Bazzalt.require

Loads an installed extension SDK module by its registered public name and returns its table.

Signature

local module = Bazzalt.require(name)
-- Bazzalt:require(name) is equivalent.

Behavior and errors

The argument is a module-name string. SelfContained modules use ModuleName; other public modules use ExtensionId.ModuleName. The result is cached per VM. Private helpers are accessible only to their owning extension. Missing/private names, dependency cycles, invalid bytecode, incompatible native modules and module initialization errors produce a Lua error. A Lua SDK file must return a table. The package must be installed and pinned to the project; built games use their packaged ext modules instead of the editor store.

Related APIs

Use Bazzalt.Extensions to list/test modules, resolve runtime asset IDs or dispatch a function dynamically. See SDK usage and the separate extension creation documentation.
