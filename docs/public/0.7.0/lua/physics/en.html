Physics in Lua

Physics uses the same Rigidbody, ShapeCollider and MeshCollider data as C++. The engine loads its sibling physics library and owns simulation. No require of Jolt, driver setup or custom game loop is needed.

A physical behavior

local B = Bazzalt
local Body = COMPONENT("BouncingBox")

function Body:OnCreate()
    if not self.Entity:HasComponent("Rigidbody") then
        self.Entity:AddComponent("Rigidbody")
    end
    if not self.Entity:HasComponent("ShapeCollider") then
        self.Entity:AddComponent("ShapeCollider")
    end
    self.Entity:GetScene():GetPhysics():ApplyImpulse(self.Entity, B.Vec3(0, 5, 0))
end

function Body:OnCollisionEnter(event)
    B.Console.Info("Contact points: " .. #event.Contacts)
end
return Body

Use component names without spaces in scripts: Rigidbody, ShapeCollider and MeshCollider. Inspector labels may contain spaces. Component Get returns a copy; after editing it, call Entity:SetComponent(typeName, value). For example:

local body = self.Entity:GetComponent("Rigidbody")
body.Mass = 2
body.GravityFactor = 0.5
self.Entity:SetComponent("Rigidbody", body)
local physics = self.Entity:GetScene():GetPhysics()
physics:SetGravity(self.Entity, Bazzalt.Vec3(0, -3, 0))
physics:SetGravity(self.Entity, nil) -- Use scene gravity again.
physics:ApplyForce(self.Entity, Bazzalt.Vec3(10, 0, 0))
physics:SetLinearVelocity(self.Entity, Bazzalt.Vec3(2, 0, 0))

Raycasts and casts

local B = Bazzalt
local scene = self.Entity:GetScene()
local options = B.PhysicsQueryOptions()
options.IncludeTriggers = false
options.ExcludedEntities = { self.Entity:GetUUID() }
local hit = scene:Raycast(B.Vec3(0, 10, 0), B.Vec3(0, -1, 0), 30, options)
if hit:IsValid() then
    B.Console.Info(hit.Object:GetUUID():ToString())
end
local shape = B.PhysicsShape()
shape.Shape = B.ColliderShape.Sphere
shape.Radius = 0.5
local transform = B.Transform()
transform.Position = B.Vec3(0, 5, 0)
local sweep = scene:ShapeCast(shape, transform, B.Vec3(1, 0, 0), 10, options)
local overlapping = scene:OverlapShape(shape, transform, options)

The Vec3-origin Raycast overload queries the physics world. Passing a SceneRay instead keeps the existing visual geometry query. A miss returns an invalid PhysicsHit, not nil; use IsValid(). Result arrays are ordinary Lua tables indexed from one. Distances are world metres. PhysicsScene also exposes ShapeCastAll, SphereCast/SphereCastAll, RaycastAll, OverlapSphere, OverlapBox, CheckSphere and CheckBox.

Events and lifetime

OnCollisionEnter/Stay/Exit and OnTriggerEnter/Stay/Exit receive CollisionEvent. Its normal points from A toward B; relative velocity is B minus A. Contacts contains world PointA, PointB and Penetration values. Body and Collider UUIDs remain useful in Exit events even if one entity no longer exists.

Explicit listeners use physics:Subscribe(B.PhysicsEventType.CollisionEnter, function(event) ... end, optionalEntity). Save its ID to unsubscribe manually. Lua-owned listeners are also disconnected before their VM is destroyed. All callbacks run on the main thread with an instruction budget; edits/forces made after a step affect the next step. Do not call Simulate recursively from a contact callback.

Scene settings and manual simulation

local physics = self.Entity:GetScene():GetPhysics()
local settings = physics:GetSettings()
settings.Gravity = Bazzalt.Vec3(0, -4, 0)
assert(physics:SetSettings(settings))
physics:SetLayerCollision(0, 1, false)

Automatic stepping follows scaled Time fixed updates. To simulate manually, set AutoSimulation=false and call physics:Simulate(fixedDeltaTime) during Play. Ordinary editing never runs the solver. Keep delta finite and between zero (exclusive) and one second (inclusive); use a small fixed interval. Stop Play before changing capacity limits.

PhysicsScene is scene-scoped and detects unload. Reacquire it from the new scene rather than retaining references across scene replacement. Global application initialization/step events remain C++ Subsystem Script listeners; Lua behaviors use their fixed/contact callbacks and the full physics facade.

Leave MeshCollider.MeshAsset at its zero/default UUID to use the entity's own mesh node or primitive. A grouping entity uses mesh descendants in its own Rigidbody domain; sibling model branches are not included. An empty component can await geometry assignment without blocking simulation. Explicit asset overrides remain supported.

Complete API

See PhysicsScene, Rigidbody, PhysicsSettings, ShapeCollider, MeshCollider and CollisionEvent. The editor guide explains fields, compounds, layers and visual collider guides.

Joints, cloth and rope

A joint connects the Rigidbody on its own entity to another Rigidbody, or to the world when Connected Body is empty. Add Joint for a configurable type, or Distance Joint, Hinge Joint, Slider Joint, Ball And Socket Joint or Fixed Joint. Anchors use entity-local coordinates; a manual world anchor uses world coordinates. Auto Configure Connected Anchor captures the owner anchor when the constraint is created. Angles and motor angular speeds use radians and radians per second.

Distance limits are nonnegative. Hinge limits include zero and stay within −π to π. Slider limits also include zero. Hinge and slider support velocity and position motors, force/torque limits, friction and spring settings. Zero Break Force/Break Torque means unbreakable. PhysicsScene.BreakJoint, RepairJoint and IsJointBroken address all joints of the specified type on an entity. Changing properties resynchronizes the constraint; removing a body safely detaches its connections. A missing connected entity leaves the joint inactive rather than connecting it to the world.

Cloth deforms the entity’s existing Primitive Object or Mesh. A cube stays a deforming cube; an imported model uses its mesh or the attached model subtree. Cloth does not add a plane. Source topology and Subdivision Level control resolution; the Primitive Plane exposes Segments and Rings for a denser cloth surface. Pin Edges selects source-boundary left, right, top and bottom edges (flat XZ surfaces use Z for top/bottom). Rope generates a soft tube down the local Y axis, with independently pinned start/end rings. Use separate entities from rigidbodies/colliders. For Cloth, an empty Material Asset preserves the source mesh’s material slots and primary UV coordinates; an assigned material overrides them. Disabling or removing Cloth restores the original surface. Rope uses its own Material Asset. Positive entity scale is baked into the rest mesh. Both expose mass, compliance, bending, damping, gravity factor, wind acceleration, solver iterations, collision layer, friction, restitution, speed limit, sleeping and shadows. Cloth additionally exposes shear compliance.

GetSoftBodyVertices returns current world positions. ApplySoftBodyImpulse applies a total impulse across free vertices, or to one zero-based vertex index. SetSoftBodyVertexPinned freezes/releases a vertex at its current position. Runtime pin changes are transient; save authoring pin settings on the component instead. Simulation deforms the rendered mesh, not the entity transform. Disabled components stop simulating and rendering. Restarting restores the authored topology and pins. Rope is a triangulated tube, not a rigid chain. Cloth source geometry is limited to 16,384 welded particles; it is never silently simplified. Width, Height and Segments X/Y on older Cloth data are retained for compatibility and no longer generate geometry. Soft-body self-collision, tearing and rigid-body contact callbacks for soft-body contacts are not supplied.

local plane = entity:AddComponent("PrimitiveObject")
plane.Shape = Bazzalt.PrimitiveShape.Plane
plane.Width = 3; plane.Depth = 2
entity:SetComponent("PrimitiveObject", plane)
local cloth = entity:AddComponent("Cloth")
cloth.PinEdges = 4
entity:SetComponent("Cloth", cloth)
local physics = entity:GetScene():GetPhysics()
physics:ApplySoftBodyImpulse(entity, Bazzalt.Vec3.new(0, 0, 2))
local positions = physics:GetSoftBodyVertices(entity) -- Lua array, vertices use zero-based indices in control calls

Cloth gravity and pins

Cloth starts with its top edge pinned. Pinned particles stay anchored even when gravity is enabled, so the complete object does not fall. Choose Pin Edges → None to release every edge and let the cloth fall freely. Selecting an edge again turns that constraint back on. Gravity Factor 1 uses scene gravity; 0 removes gravity acceleration without clearing existing velocity. In scripts, set Cloth.PinEdges = 0 and Cloth.GravityFactor = 1. Cloth simulation moves its mesh particles; the entity’s authoring Transform is not its simulated center.

Flexible cloth and inflated shells

Cloth uses Jolt soft-body particles and constraints. It does not use a Rigidbody disguised as cloth. The defaults use nonzero stretch/shear compliance and Bend Mode None, allowing the mesh to fold. Zero compliance makes an edge effectively inextensible; increasing compliance makes it softer. Distance and Dihedral bending are optional ways to add bending resistance. The inspector preserves eight decimal places for these small coefficients.

Subdivision Level is a maximum number of midpoint-refinement passes on the existing surface: 0 uses the source triangles directly; the default 2 adds detail to coarse shapes such as a cube. Refinement stops before the particle budget is exceeded. This preserves the original shape, material slots and primary UVs and never adds an unrelated plane.

Pressure 0 gives an uninflated cloth shell. Positive Pressure gives a closed mesh a balloon-like response, like Jolt’s sphere-pressure example. Pressure is Jolt’s nRT parameter, not a value in Pascals; the resulting pressure depends on enclosed volume. Start with small values for a small, light object. Open sheets or inconsistently wound meshes cannot use pressure; the editor reports an error instead of applying an unstable force. Pressure changes apply live without resetting the deformed mesh. Collision Radius adds particle contact thickness; it defaults to 0.01 world units.

To let a shell fall freely, choose Pin Edges None. Uniform free-fall alone does not make a soft object wobble: impacts, obstacles, anchors, wind or pressure create deformation. A sheet drapes over obstacles; an unpressurized closed shell can crumple; an inflated shell resists collapse. Older scenes using the previous stiff default material migrate automatically. Customized coefficients remain intact.

local mesh = entity:AddComponent("PrimitiveObject")
mesh.Shape = Bazzalt.PrimitiveShape.Sphere
entity:SetComponent("PrimitiveObject", mesh)
local cloth = entity:AddComponent("Cloth")
cloth.PinEdges = 0
cloth.BendMode = Bazzalt.ClothBendMode.None
cloth.Pressure = 20 -- Closed mesh only.
entity:SetComponent("Cloth", cloth)
