Lua audio

Lua uses the same native Audio Clips, source/listener components and mixer as C++. No Lua audio loop or separate decoder is needed. Import an Audio Clip, create an enabled listener, and assign the clip in the inspector.

Create and play a source

local B = Bazzalt
local Behavior = COMPONENT("SoundEffect")
Behavior.Clip = PROPERTY("AudioClip", B.AudioClip.new())
function Behavior:OnCreate()
    local source
    if self.Entity:HasComponent("AudioSource") then
        source = self.Entity:GetComponent("AudioSource")
    else
        source = self.Entity:AddComponent("AudioSource")
    end
    source.Clip = self.Clip
    source.PlayOnAwake = false
    source.SpatialBlend = 1
    source.MinDistance = 1
    source.MaxDistance = 20
    source.OutputBus = B.AudioMixer.GetSFXBus()
    self.Entity:SetComponent("AudioSource", source)
    self.Voice = B.Audio.Play(self.Entity)
end
function Behavior:OnDestroy()
    if self.Voice then self.Voice:Stop() end
end
return Behavior

Component getters return copies. Assign changes with SetComponent; editing the returned Lua value alone does not update the scene. Source/listener component type names in Lua are AudioSource and AudioListener, without spaces. The editor displays readable names with spaces.

Transport and one-shots

local shot = B.Audio.PlayOneShot(clip, B.Vec3.new(0, 1, 0),
    0.8, B.AudioMixer.GetSFXBus(), 1)
if shot:IsValid() then
    shot:SetPitch(1.1)
    shot:Pause()
    shot:Seek(0.25)
    shot:Resume()
    shot:FadeTo(0, 0.5)
end
B.AudioMixer.GetMusicBus():SetVolumeDecibels(-12)
B.Audio.SetMaxVoices(96)

PlayOneShot defaults to position (0,0,0), volume 1, Master bus and Spatial Blend 0. A voice may become invalid after completion, stealing, source removal or Stop. Call IsValid/GetState before using it; invalid voice operations return false, zero or Stopped. Time is in seconds; pitch is a multiplier independent of B.Time scale.

Custom attenuation

local source = self.Entity:GetComponent("AudioSource")
source.RolloffCurve = B.AudioRolloff.Custom
source.CustomRolloff = {
    B.Vec2.new(0, 1), B.Vec2.new(0.3, 0.8), B.Vec2.new(1, 0)
}
assert(source:IsValid())
self.Entity:SetComponent("AudioSource", source)

Curve X is normalized distance from Min Distance to Max Distance. Y is gain. Keep points strictly increasing in X, between 0 and 1; include endpoints X=0 and X=1. Source volume is 0–1, pitch 0.5–2, and priority 0 (highest)–256 (lowest).

Reference and lifecycle

All public C++ audio operations are bound in Lua. Use a dot for service/static calls (B.Audio.Play), a colon for value methods (voice:Pause), and .new() for constructors. Read the Lua audio API reference and the editor audio guide for fields, listener rules, mixer buses, supported formats and limits.
