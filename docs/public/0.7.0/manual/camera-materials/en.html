Camera material passes

Select an entity with a Camera and expand its component in Properties. The Post Process Materials list applies custom canvas materials to that camera's image in order, from top to bottom. Each pass reads the previous pass output through its source texture.

Edit the list

Click Add Material Pass, then choose a project .matinst asset or drag it from Asset Browser. The checkbox enables that pass. The up/down arrows move it earlier or later; the remove button deletes the entry. Empty and disabled entries do not run. Changes use normal scene dirty tracking, undo/redo and scene serialization.

Compatible materials

A camera pass requires a canvas-compatible unlit surface material with a source sampler and sourceRect Vec4 parameter. Use the Canvas shader preset or a compatible custom shader. A lit mesh material is not a post-processing material. Invalid compiled materials produce a diagnostic and are skipped instead of exposing low-level renderer objects.

Camera and viewport behavior

Disabling the Camera, marking it inactive or disabling its Post Processing stops its material passes. The list also applies to render-target textures and camera-bound output, and respects each camera's split-screen region. GUI overlays are composed afterward. Old scenes with one Post Process Material preserve that pass as the first entry when edited.

Pass limit

A camera supports up to 32 material entries. Every pass adds rendering work and intermediate textures; use as few passes as the effect needs. A scene uses the shared effect-target budget, so excessive nested UI effects or high-resolution pass chains can produce a resource-limit diagnostic.
