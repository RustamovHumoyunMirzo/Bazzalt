Subsystem

Base class for a registered C++ project-wide service. It has no entity or Transform. Implement OnRegister to subscribe to global lifecycle events; OnUnregister is optional.

Lifecycle and scene access

OnRegister() is called once when the configured startup level is reached. Override it to install listeners and allocate service state. OnUnregister() runs during reverse-order unloading; listeners are removed before the object and its module are destroyed. Neither hook has an owning entity.

The protected GetScene() returns a reference to the active scene. It throws when scene services are not ready or there is no active scene. Call it inside a sufficiently late listener, not a static initializer. Do not retain entities across scene replacement.

#include <Bazzalt/Subsystem.h>
SUBSYSTEM(GameService) {
public:
    void OnRegister() override {
        Bazzalt::Application::OnPlay([this] {
            auto player = GetScene().FindEntityByName("Player");
            // Check player.IsValid() before using its components.
        });
    }
};

Register this source in Window > Global Subsystems. See the subsystem programming guide for service readiness and error propagation.
