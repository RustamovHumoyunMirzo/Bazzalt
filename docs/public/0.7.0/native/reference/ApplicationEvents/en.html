ApplicationEvents

ApplicationEvents declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Subscriptions and errors

Subscribe(type, callback) returns an opaque uint64 subscription token. Registration is allowed only in registered C++ subsystem scopes and only for events at or above the owner's load level. An invalid registration throws a descriptive exception. Unsubscribe(token) returns whether a matching listener was removed. GetName(type) returns the event's named identifier.

Callbacks execute on the host main thread in registration order. An emission snapshots listener IDs: newly added listeners wait for the next emission; removed listeners are skipped. Subscriptions are automatically removed before their subsystem/module unloads. Callback exceptions stop the failed Play session in the editor; standalone games report a fatal native error dialog. There is no public Emit function.

Event arguments and timing

Event(s)Named listener arguments / generic payload
OnBoot, OnBeforeWindowCreate, OnInit, OnLoad, OnPostWindowCreateNo arguments; successive startup boundaries. Boot occurs after package verification and native module setup.
OnPreUpdate, OnUpdate, OnLateUpdatefloat deltaTime / DeltaTime, scaled gameplay seconds. Pre-update follows input preparation; late update follows game logic.
OnFixedUpdatefloat fixedDeltaTime / DeltaTime, fixed simulation seconds.
OnPreRender, OnRender, OnPostRenderNo arguments; CPU rendering boundaries, not GPU completion.
OnWindowResizeuint32 width, height / Width, Height, drawable pixels.
OnWindowFocusChangedbool isFocused / IsFocused.
OnWindowCloseRequestedNo arguments; notification, not a cancellable request.
OnSceneLoadconst string& path / ScenePath; before deferred scene loading.
OnSceneLoaded, OnSceneUnload, OnSceneUnloadedconst string& sceneUUID / SceneUUID. Unload runs before teardown, Unloaded after.
OnPlay, OnStopNo arguments; gameplay session boundaries.
OnPreShutdown, OnShutdownNo arguments; before/after service teardown. Service access at OnShutdown is restricted. OS kills/native faults cannot guarantee these callbacks.

See SubsystemLevel for subscription levels and Application for the named convenience listeners.
