MaterialRenderState

Optional abstract render-state override. SetRenderState enables it; ResetRenderState restores compiled shader defaults. No Filament handle crosses this API.

C++ header: Bazzalt/Material.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Material.h>
struct MaterialRenderState

Override

bool Override = false

Whether instance state overrides are active. SetRenderState forces true; ResetRenderState restores false.

DoubleSided

bool DoubleSided = false

Double-sided lighting override. The shader must compile this capability; culling is a separate setting.

DepthTest

bool DepthTest = true

Enable depth testing for this surface.

DepthWrite

bool DepthWrite = true

Allow this surface to write depth. Does not enable transparent blending.

ColorWrite

bool ColorWrite = true

Allow color writes to the target.

Culling

MaterialCulling Culling = MaterialCulling::Back

Faces to exclude from rendering.

DepthFunction

MaterialDepthFunction DepthFunction = MaterialDepthFunction::LessEqual

Depth comparison function, default LessEqual in the override value.
