Physics in C++

Include Bazzalt/Scene.h for scene physics queries and the PhysicsScene facade. The header includes the engine's physics value types and components. No Jolt header, native physics world, allocator, driver or engine-loop initialization belongs in game code.

Create bodies and colliders

#include <Bazzalt/Script.h>
#include <Bazzalt/Console.h>

COMPONENT(BouncingBox) {
public:
    void OnCreate() override {
        auto entity = GetEntity();
        if (!entity.HasComponent<Bazzalt::Rigidbody>()) entity.AddComponent<Bazzalt::Rigidbody>();
        if (!entity.HasComponent<Bazzalt::ShapeCollider>()) entity.AddComponent<Bazzalt::ShapeCollider>();
        entity.GetScene()->GetPhysics().ApplyImpulse(entity, {0, 5, 0});
    }
    void OnCollisionEnter(const Bazzalt::CollisionEvent& event) override {
        Bazzalt::Console::Info("Contact points: " + std::to_string(event.Contacts.size()));
    }
};

Collider-only entities are static. Rigidbody motion defaults to Dynamic. Child colliders attach to the nearest enabled Rigidbody; nested rigidbodies are independent. Disabling that Rigidbody removes its attached colliders from the world until re-enabled. A collider-less Rigidbody uses a non-colliding body and still responds to gravity.

Control a body

auto entity = GetEntity();
auto physics = entity.GetScene()->GetPhysics();
physics.ApplyForce(entity, {10, 0, 0});            // Newtons, applied for the next step.
physics.ApplyImpulse(entity, {0, 5, 0});          // Immediate momentum change.
physics.ApplyForceAtPosition(entity, {0, 20, 0}, entity.GetWorldTransform().Position);
physics.ApplyTorque(entity, {0, 1, 0});
physics.ApplyAngularImpulse(entity, {0, 0.5f, 0});
physics.SetLinearVelocity(entity, {2, 0, 0});
physics.SetAngularVelocity(entity, {0, 1, 0});
physics.SetGravity(entity, Bazzalt::Vec3{0, -3, 0});
physics.SetGravity(entity, std::nullopt);           // Restore scene gravity.
physics.Teleport(entity, {0, 4, 0}, Bazzalt::Quaternion{});
physics.WakeUp(entity);

Force/impulse/torque operations require a dynamic body. MoveKinematic takes a world position, Quaternion and time interval for a kinematic body. Teleport changes the pose immediately and resets interpolation history. Controls return false for absent/inapplicable bodies; non-finite inputs are rejected. Runtime controls require an active simulation, so call them during script lifecycle callbacks or later.

Linear vectors use world metres/second; angular vectors use world radians/second. The optional Rigidbody.Gravity is null by default; GravityFactor multiplies the scene vector or the override. Component edits are synchronized at safe boundaries. Do not use body handles or retain engine internals.

Scene raycasts and shape queries

auto* scene = GetEntity().GetScene();
Bazzalt::PhysicsQueryOptions options;
options.IncludeTriggers = false;
options.LayerMask = 1u << 0;
options.ExcludedEntities = {GetEntity().GetUUID()};
auto hit = scene->Raycast(Bazzalt::Vec3{0, 10, 0}, Bazzalt::Vec3{0, -1, 0}, 30, options);
if (hit) {
    auto body = hit.Object;
    auto collider = hit.Collider;
    auto point = hit.Point;
}
Bazzalt::PhysicsShape shape;
shape.Shape = Bazzalt::ColliderShape::Sphere;
shape.Radius = 0.5f;
Bazzalt::Transform origin;
origin.Position = {0, 5, 0};
auto sweep = scene->ShapeCast(shape, origin, {1, 0, 0}, 10, options);
auto overlaps = scene->OverlapShape(shape, origin, options);
auto allHits = scene->RaycastAll(Bazzalt::Vec3{0, 10, 0}, Bazzalt::Vec3{0, -1, 0}, 30, options);

The Vec3-origin Scene.Raycast/RaycastAll overloads query actual colliders. The older SceneRay overloads remain visual scene-geometry queries for picking; they do not change meaning. Physics queries also see invisible colliders and collider-only entities. Direction is normalized internally, Distance is in world units, and invalid/no hit returns an invalid PhysicsHit. Results include the body owner and the actual collider entity.

PhysicsScene adds ShapeCastAll, SphereCast/SphereCastAll, OverlapSphere, OverlapBox, CheckSphere and CheckBox. Shape queries support finite Box, Sphere, Capsule and Cylinder shapes with a query Transform. LayerMask, trigger inclusion, back-face handling, excluded entity UUIDs and MaxResults control each query. Ray/cast results are nearest-first; overlaps return collider hits. Queries never advance simulation. During Play they read the current physics world; call Synchronize after direct Transform/component edits if an immediate query must see those edits. Editing synchronizes collider previews automatically.

Contact callbacks and subscriptions

Behavior supplies OnCollisionEnter/Stay/Exit and OnTriggerEnter/Stay/Exit. For explicit scene listeners, PhysicsScene.Subscribe takes PhysicsEventType, a callback and an optional entity filter; it returns a subscription ID. Unsubscribe removes it. Runtime-owned script/subsystem subscriptions are disconnected on teardown.

CollisionEvent has BodyA/BodyB and ColliderA/ColliderB entities plus their UUIDs, DeltaTime, a normal from A toward B, relative linear velocity B minus A, and up to 64 ContactPoint values. PointA/PointB are world positions. Penetration can be negative for speculative contacts. Determine which side belongs to your object before choosing a normal direction. Exit events retain UUIDs even when an entity was destroyed.

Callbacks execute on the main thread after pose writeback. Duplicate triangle manifolds are combined per collider pair. Sleeping bodies need not receive Stay every tick. Forces/edits in callbacks affect the next step. Recursive simulation is rejected. Do not retain Entity references past scene unload; reacquire by UUID. A retained PhysicsScene facade detects an unloaded scene and throws instead of accessing freed storage.

Settings, stepping and lifecycle

GetSettings returns a value copy; SetSettings validates and applies a complete PhysicsSettings value. SetGravity changes scene gravity. SetLayerCollision updates both directions of the 32-layer matrix. Capacity edits are rejected during simulation; stop Play first.

The engine steps automatically after scene/native/Lua fixed callbacks and before ordinary updates. Scaled fixed time, pause, single stepping and catch-up limits use the existing Time scheduler. Disable AutoSimulation before calling Simulate(fixedDeltaTime) manually; a simulation must already be running. Simulate accepts a finite interval greater than zero and at most one second. Use a normal fixed interval, not a variable render delta.

Global C++ subsystem events include OnBeforePhysicsInit, OnPhysicsInit, OnAfterPhysicsInit, OnBeforePhysicsStep, OnAfterPhysicsStep, OnBeforePhysicsShutdown and OnAfterPhysicsShutdown. Input and Audio have before/init/after events and subsystem load levels too. Ready loads after initialized services/content. Persisted legacy level IDs are preserved; numeric ID order is not lifecycle order. Lower levels may listen to later events; premature service use is an error.

Leave MeshCollider.MeshAsset at its zero/default UUID to use the entity's own mesh node or primitive. A grouping entity uses mesh descendants in its own Rigidbody domain; sibling model branches are not included. An empty component can await geometry assignment without blocking simulation. Explicit asset overrides remain supported.

Reference and practical restrictions

See PhysicsScene, PhysicsSettings, Rigidbody, ShapeCollider, MeshCollider and CollisionEvent for every declaration and default.

Use positive, non-singular collider scale. Dynamic mesh bodies must be convex; infinite planes are static. Shape creation failures and exhausted body/contact capacities report errors. This rigid-body API does not expose Jolt soft bodies, vehicles, character controllers or joints. Keep engine scenes/assets in their versioned YAML formats; no Jolt objects are serialized into game-facing data.
