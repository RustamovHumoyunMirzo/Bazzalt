What's new in 0.7.0

This release extends the 0.6.0 engine to Linux and makes game build targets explicit. Existing Windows projects and the public C++/Lua APIs remain compatible.

Linux x64

Hub, Editor, core SDK, game compiler, content cooker and standalone player now have Linux build and release paths. The editor and player use X11; Wayland desktops can run them through XWayland. Vulkan and OpenGL remain selectable. Linux games include native runtime libraries and cooked content, with no Python or editor dependency.

The Linux player includes window modes, keyboard/mouse/text input, the startup logo, frame limiting and application lifecycle events. Content protection uses OpenSSL for the same AES-GCM, HKDF, SHA-256 and ECDSA scheme as Windows. Linux packages use Zstandard compression. See the Linux installation and development guide.

Platform-aware build settings

Build Settings now includes Windows and Linux platform choices. A warning explains unsupported host/architecture/security combinations. Build and Build and Launch reject these combinations through the editor Console before cooking or launching anything. Build on the target OS using a matching runtime SDK. Windows x64/x86 output remains supported; Linux output currently targets x64.

CI and releases

A Linux badge and workflow cover native builds, editor and Hub tests, compiler tests, encrypted-package verification and GPU smoke tests under Xvfb. Release packaging creates separate Linux Core, Compiler, Editor and Hub ZIP archives and combines Windows/Linux entries into the Hub download catalog. ELF architecture and executable permissions are validated during installation.

Platform differences

Native Wayland surfaces, Linux x86 and cross-OS game compilation are not supported in this release. Windows account-bound DPAPI keys remain Windows-only; choose embedded, file or environment key delivery on Linux. POSIX file leases are advisory and do not provide Windows deny-write semantics. Client-side content protection does not prevent an owner from patching their executable. Linux binaries require the libraries and baseline distribution listed in the Linux guide.

Previous release

Read the 0.6.0 documentation for the previous version. Its audio, GUI, stylesheet, material, scene, scripting and editor workflows continue in 0.7.0.
