VFX in C++

Include Bazzalt/VFX.h. A ParticleEmitter belongs to one entity and holds authored settings. VFX is an engine-thread facade for its temporary simulation state. Engine scenes receive ParticleSystem automatically; custom standalone Scene owners can add Bazzalt/Systems/ParticleSystem.h with Scene::AddSystem<ParticleSystem>.

Start and control an effect

#include <Bazzalt/VFX.h>
// entity is a live entity in the active engine scene.
auto& emitter = entity.AddComponent<Bazzalt::ParticleEmitter>();
emitter.Graph = effectAssetId; // UUID of an imported .vfx asset
emitter.Space = Bazzalt::ParticleSimulationSpace::World;
Bazzalt::VFX::Play(entity);
Bazzalt::VFX::Emit(entity, 12);
Bazzalt::VFX::Pause(entity);
Bazzalt::VFX::Resume(entity);
Bazzalt::VFX::Stop(entity, false); // stop births; let existing particles die
Bazzalt::VFX::Restart(entity);    // clear state and restart the seeded sequence

Graph handles and errors

VFXGraph::Load(UUID) resolves an imported .vfx asset and its UUID imports. FromSource(string) accepts a version-1 data document for procedural tools. Both return an invalid handle with GetError on failure; check IsValid. GetAssetUUID returns the source UUID, while FromSource has zero. GetDependencies returns unique transitive imports plus configured output materials/textures. No local filesystem import paths are accepted.

auto graph = Bazzalt::VFXGraph::Load(effectAssetId);
if (!graph.IsValid()) throw std::runtime_error(graph.GetError());
Bazzalt::VFX::SetGraph(entity, graph);
Bazzalt::VFX::Simulate(entity, 0.5f);
auto stats = Bazzalt::VFX::GetStatistics(entity);

Operation contracts

MethodContract
PlayEnable births and unpause; a completed effect begins again.
RestartDiscard particles, counters and time; restart the graph with the component seed.
Pause / ResumeFreeze/resume emission and existing particles.
Stop(entity, clear=true)Disable births and optionally remove existing particles immediately.
ClearRemove particles/events; retain playback/time and spawn counters.
Emit(entity, count)Manual births, even when regular emission is stopped, within capacity.
SetGraphReplace the runtime definition and reset simulation. This does not write the scene's Graph asset field; changing that field later selects the new asset.
Simulate(entity, seconds, restart=false)Advance manually without rendering or running scripts. It adds to normal engine stepping, respects pause and SimulationSpeed, and retains sub-step remainder. To run manual-only, disable the ParticleSystem before engine updates.
GetStatisticsReturn Alive, Capacity, Spawned, Dropped, simulation Time, Playing and Paused snapshots.
GetParticles / GetEventsCopies; modifying them does not change simulation. Events are Born, Died and Completed snapshots, with particle ID and simulation-space position.

All entity operations require a valid entity, ParticleEmitter, valid settings and a ParticleSystem in its scene. Invalid operations throw standard exceptions. Play/Emit require a valid graph; Simulate validates finite bounded duration. No callback or module reference is retained by particle event snapshots.

Rendering and authoring

Camera-facing geometry, buffers, sorting and renderer materials are private. Particles participate in camera layer rendering and ancestor LOD/editor visibility. Their world entity transforms are never modified by camera-facing work. Read the authoring guide for graph blocks, ranges, limits, material requirements and the current CPU-renderer boundaries.
