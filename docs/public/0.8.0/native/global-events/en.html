C++ Global Events

Include Bazzalt/GlobalEvent.h. GlobalEvent is a lightweight UUID channel handle. EventValue is a variant; each alternative corresponds to EventArgumentType in declaration order. Number uses double and Integer uses std::int64_t. Get<T> returns the named value and throws for an unknown name or mismatched type.

Behavior property

#include <Bazzalt/GlobalEvent.h>
COMPONENT(DamageReceiver) {
    PROPERTY(Bazzalt::GlobalEvent, Damage, {});
public:
    void OnCreate() override {
        Damage.Subscribe([this](const Bazzalt::EventInvocation& event) {
            const double amount = event.Get<double>("Amount");
            // Update this behavior using amount.
        }, GetEntity());
    }
    void SendDamage(double amount) {
        Damage.Fire({amount, std::string("hit")});
    }
};

Create a schema named Damage with Amount: Number and Label: String, then assign it to the property. Subscribe returns a token; call Damage.Unsubscribe(token) to disconnect manually. Native behavior callbacks are also scoped to the script instance. Passing GetEntity additionally prevents delivery after that entity is destroyed.

Load directly by UUID

Bazzalt::UUID id;
if (!Bazzalt::UUID::TryParse("12345678-1234-4234-8234-123456789abc", id))
    throw std::invalid_argument("Bad event UUID");
auto signal = Bazzalt::GlobalEvent::Load(id);
auto schema = signal.GetDefinition();
signal.Fire({2.0, std::string("hit")});

Use the actual UUID from the asset metadata. Load(root/zero UUID) returns an empty handle for unassigned properties; loading a non-event, missing or failed UUID throws. Subscribe/GetDefinition/Fire require a valid loaded handle. Fire uses positional arguments in schema order. Copy values you need after the callback returns; do not retain references to its invocation.

Arguments and delivery

An event is an asset UUID, not its display name or file path. Two assets with the same name remain separate channels. A schema has at most 32 arguments with unique identifiers (letters, digits and underscore, starting with a letter or underscore). Boolean, Integer (signed 64-bit), Number (finite double), String (up to 64 KiB), Vec2, Vec3, Vec4, Quaternion and UUID are supported. Vector/quaternion coordinates must be finite. A UUID can identify an entity or asset; it is a value, not an owning pointer.

Callbacks receive an immutable-by-contract invocation snapshot. Fires validate the complete argument list before delivering anything. All operations run on the engine thread. Delivery is synchronous for the root Fire: it drains a FIFO queue before returning. A Fire inside a callback queues another invocation after the current invocation's listeners. Repeated fires in one frame are distinct; they are not coalesced.

Listeners run in subscription order. Unsubscribed listeners are skipped immediately. Listeners added during an invocation start with the next invocation, including an already queued nested fire. Invalid entity owners are pruned. Script/module shutdown disconnects scoped listeners before releasing code or a Lua VM. A faulting listener is disabled; other listeners continue. Subsystem callback failures use the existing fatal subsystem error path.

Safety limits

The engine enforces 8,192 subscriptions, 1,024 loaded definitions, 1,024 pending invocations (8 MiB total payload, 256 KiB per invocation), causal depth 32, 4,096 fires and 65,536 callback deliveries per frame. These are safety limits, not recommended operating targets. Exceeding a limit raises an error; no unbounded recursion or recursive stack growth occurs. A root drain that fails clears its pending queue. Lua callbacks have an instruction budget. Unsubscribe or correct an accidental feedback loop instead of increasing these limits.

Global Subsystems

Enable Asset Access in the registry, choose the load level, and replace this example UUID with the event asset UUID. A Boot-level subsystem can defer loading until OnPlay:

#include <Bazzalt/Subsystem.h>
#include <Bazzalt/GlobalEvent.h>
SUBSYSTEM(GameSignals) {
    Bazzalt::GlobalEvent Signal;
    Bazzalt::GlobalEvent::Subscription Token=0;
public:
    void OnRegister() override {
        Bazzalt::Application::OnPlay([this] {
            Bazzalt::UUID id;
            Bazzalt::UUID::TryParse("12345678-1234-4234-8234-123456789abc", id);
            Signal=Bazzalt::GlobalEvent::Load(id);
            Token=Signal.Subscribe([](const Bazzalt::EventInvocation& event) {
                const double amount=event.Get<double>("Amount");
                // React globally; no entity attachment is needed.
            });
            Signal.Fire({1.0, std::string("hit")});
        });
    }
};

In Window > Global Subsystems, enable Asset Access for a subsystem that loads events or other assets directly. It defaults off, including older registrations without the field. Permissions follow each subscriber when callbacks run, rather than inheriting the emitter's permission. This option does not initialize assets early: a Boot subsystem should subscribe to a later application event, such as OnPlay, then load the event by UUID. Path-based AssetManager lookups are rejected for subsystem scripts. Package builds retain the permission setting and event UUIDs. If you restrict build content, explicitly include assets loaded dynamically by UUID.

Asset Access is an engine service permission for trusted project code; native C++ is not an operating-system sandbox. Global Events are project gameplay messages, separate from the engine's application lifecycle events.
