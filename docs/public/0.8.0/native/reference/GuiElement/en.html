GuiElement

GuiElement declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

See the GUI guide for layout, rendering, component write-back and input examples.

Selectors and scope

Stylesheet is an optional CSS asset UUID scoped to this entity and its GUI descendants. The nearest Frame isolates the scope; rules do not cross nested Frames. ID is an exact selector identifier; an empty value uses the entity name. Classes and Tags are whitespace-separated tokens. Classes match .name and Tags are exposed through [tags~=name]. Attributes accepts presence or exact-value entries, for example [disabled] [state="active"]. Metadata strings are bounded to 256/4096/4096/8192 bytes respectively. Disabled/checked/selected attributes also provide widget states.

This component stores metadata, not visible geometry. Add RectTransform and a drawing/control component under a Frame. A root Frame cannot draw its own widgets. CSS modifies computed copies, leaving component fields and undo history intact. See the stylesheet guide.
