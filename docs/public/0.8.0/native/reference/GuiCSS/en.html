GuiCSS

GuiCSS declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

See the GUI guide for layout, rendering, component write-back and input examples.

Obtain this non-owning handle with GUI.GetCSSStyle(entity). Set/Get/Remove operate on inline declarations; Replace/Append/GetText operate on the private runtime sheet. GetBaseText reads the directly assigned shared asset. SetRule/RemoveRule and SetKeyframes/RemoveKeyframes edit top-level definitions in the private sheet. Writes return false on invalid input without replacing the last valid styles. Changes are temporary and apply on the next GUI layout. See runtime CSS and motion examples for C++/Lua syntax, lifetime and limits.
