TextureDescriptor

Writable 2D texture settings shared by assets and runtime Texture.Create/SetDescriptor. Include Bazzalt/Texture.h. These are resource settings, not an entity component.

Fields and defaults

FieldDefaultMeaning
Width / Height512 / 512Pixel dimensions, 1–4096 per axis.
Samples1Requested MSAA: 1, 2, 4 or 8. Rendering resolves into a single-sample texture for ordinary sampling; device/backend limits may constrain MSAA.
MipmapsfalseAllocates and regenerates a mip pyramid after producer rendering, before later consumers.
MipLevels0Zero selects the full pyramid when enabled. Explicit counts cannot exceed floor(log2(max(width,height)))+1. With mipmaps disabled, only zero/one are valid.
ColorFormatRGBA8TextureColorFormat: RGBA8, RGBA16F (HDR), RGBA32F. Unsupported backend formats produce a diagnostic rather than silently changing format.
DepthFormatDepth32FTextureDepthFormat: None, Depth16, Depth24, Depth32F. Controls the target's depth attachment.
FilterLinearTextureFilter: Point, Linear, Trilinear. Mipmapped point/bilinear select the nearest mip; trilinear interpolates between mips. Without mipmaps, trilinear uses ordinary linear sampling.
WrapClampTextureWrap: Clamp, Repeat, Mirror. Applies to GUI and material consumers.
ClearColor(0,0,0,1)Initial/idle color, restored when the producer is disabled or removed. Floating-point formats preserve HDR values; RGBA8 clamps to normalized bytes. Camera/environment configuration controls rendered scene backgrounds.

IsValid()

Checks dimensions, sample counts, enum ranges, finite clear color and legal mip counts. This is CPU validation, not a GPU capability query. Invalid descriptors do not partially modify a Texture.

GetMipLevelCount()

Returns one when mipmaps are disabled; otherwise the explicit count or the computed full pyramid. Call IsValid before allocating from user-provided values.

Memory and scope

Camera history uses two color attachments; depth is shared by sequential captures. HDR, large dimensions, MSAA and mipmaps increase GPU memory. A 2D texture is sampleable without a camera and starts at ClearColor. Array/cubemap targets, compute/UAV access and raw native handles are not part of this API.

Public declarations

Header: Bazzalt/Texture.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted.
