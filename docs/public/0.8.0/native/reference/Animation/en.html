Animation

Engine-thread animation service. Controls Animator playback, numeric parameters/triggers, layers, IK and copied poses/events. Pure Blend/Additive, FK, IK and Retarget operations are renderer independent. See the animation guides for spaces, errors, root motion and physics ownership.
