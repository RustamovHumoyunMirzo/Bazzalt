GUI

Read GUI bounds and per-frame interaction state, control keyboard focus, and test whether UI consumes the pointer. Read interaction pulses during gameplay update.

See the GUI guide for layout, rendering, component write-back and input examples.

ResolveStyle

ResolveStyle(entity) returns a GuiStyle copy containing effective Rectangle style values. Inherit flags resolve per property through enabled ancestor Rectangles within the nearest Frame. Without a Rectangle or valid entity, it returns default GuiStyle values. It does not modify the scene and works before any layout/render tick.

ResolveText

ResolveText(entity) returns a GuiText copy with effective Color, FontSize and Wrap when their inheritance flags are enabled. Value remains the child's own text. A missing component or invalid entity returns a default GuiText. Do not commit effective snapshots if the goal is to preserve authored fallbacks.

ResolveImage

ResolveImage(entity) returns a GuiImage copy with its effective inherited Color. Texture and Camera remain local. Missing components/invalid entities return a default GuiImage. All resolve operations reflect live reparenting and ancestor edits, are main-thread scene reads, and retain no pointers. See the layout/inheritance contract for exact fallback and frame boundaries.
