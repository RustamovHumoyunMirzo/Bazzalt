Scripts

Find a live native entity behavior or obtain its checked shared C++ interface. Instances may exist before OnCreate has run; references expire on script or scene teardown. This typed interface API is C++ only.

Lookup and lifetime

Find(entity, typeName) returns the live native Behavior* matching the entity and type name, or null. The entity must belong to the active gameplay scene. Get<T>(entity, typeName) returns a checked shared-interface reference or throws std::logic_error for missing/incompatible instances. Returned instances are runtime-owned. Never delete them. Resolve them again after script removal, scene unload or a new Play session.

Put the common interface in a project header included by both scripts. This is native C++ interoperability, not arbitrary Lua-to-native invocation. Construction of another behavior does not imply its OnCreate has finished.

Public declarations

Header: Bazzalt/Script.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.

class Scripts {
static Behavior* Find(Entity entity,const std::string& typeName);
template<class T> static T& Get(Entity entity,const std::string& typeName);
};
