Impostor

World-sized camera-facing alpha-cutout quad with an authored color atlas. Columns/Rows pack azimuth frames left-to-right and top-to-bottom; ViewCount is 1..256 and starts at local +Z toward +X. AzimuthOffset is in degrees. Pivot positions the local unit quad relative to Center. GetMatrix maps Pivot to the world center. Camera-facing state never writes the entity transform.
