ParticleEmitter

Serialized particle settings: Graph, MaterialOverride, MaxParticles (1..32768), Seed, SimulationSpeed (0..100), RateMultiplier (0..100), SizeMultiplier (0..10000), Tint, Space, PlayOnAwake and UseUnscaledTime. Disabling freezes simulation and hides rendering.
