AudioBus

Copyable mixer routing handle. UUID zero identifies the Master bus, not an absent bus. GetSettings returns a copy; apply changes with SetSettings or the individual setters.

See the audio reference for units, ranges, errors, effect parameters and playback/routing behavior.
