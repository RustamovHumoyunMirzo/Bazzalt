GaussianBlur

An image-wide Gaussian blur component on a camera entity. This is not depth of field: it blurs the whole image rather than choosing a focus distance.

C++ header: Bazzalt/Components/GaussianBlur.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

Size

float Size = 1.0f

Blur-radius multiplier in pixels; default 1. Zero leaves the image unchanged.
