GlobalEvent

UUID-backed project global event asset. Load validates a ready event, GetDefinition returns its typed contract, Subscribe returns a removable token, Fire validates values then drains bounded FIFO invocations, and Unsubscribe removes one listener. Script/module ownership is retained safely. See the global-events guide for argument types, lifecycle and limits.
