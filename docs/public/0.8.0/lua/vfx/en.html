VFX in Lua

The Lua API controls the same native particle system as C++. There is no separate Lua simulation. Use a project .vfx UUID in a ParticleEmitter, then call the global Bazzalt.VFX service.

Example behavior

local B = Bazzalt
local Effect = {}
function Effect:OnCreate()
    local emitter = self.Entity:HasComponent("ParticleEmitter")
        and self.Entity:GetComponent("ParticleEmitter")
        or self.Entity:AddComponent("ParticleEmitter")
    emitter.Graph = B.UUID.Parse("YOUR-VFX-ASSET-UUID")
    emitter.Space = B.ParticleSimulationSpace.World
    emitter.MaxParticles = 2048
    self.Entity:SetComponent("ParticleEmitter", emitter)
    B.VFX.Play(self.Entity)
    B.VFX.Emit(self.Entity, 24)
end
function Effect:OnUpdate()
    local state = B.VFX.GetStatistics(self.Entity)
    for _, event in ipairs(B.VFX.GetEvents(self.Entity)) do
        if event.Type == B.ParticleEventType.Completed then
            -- The non-looping effect and its remaining particles have finished.
        end
    end
end
return Effect

Loading graph handles

local graph = Bazzalt.VFXGraph.Load(effectUUID)
assert(graph:IsValid(), graph:GetError())
Bazzalt.VFX.SetGraph(entity, graph)
Bazzalt.VFX.Simulate(entity, 0.5)
local particles = Bazzalt.VFX.GetParticles(entity)

VFXGraph.FromSource accepts a version-1 data document; imports still resolve by project UUID. A graph is data, never evaluated Lua. GetDependencies returns a table of unique transitive asset UUIDs. GetAssetUUID returns zero for source-created graphs.

Controls and snapshots

VFX exposes Play, Restart, Pause, Resume, Stop(entity, clear=true), Clear, Emit(entity, count), SetGraph(entity, graph), Simulate(entity, seconds, restart=false), GetStatistics, GetParticles and GetEvents. Use dot calls on Bazzalt.VFX and colon calls on graph handles. GetComponent returns a settings copy: write it back with SetComponent. Particle snapshots are also copies.

Statistics contain Alive, Capacity, Spawned, Dropped, Time, Playing and Paused. Particle snapshots contain Id, Position, Velocity, Age, Lifetime, Size, Rotation and Color. Events contain Type, ParticleId and Position. Event types are Born, Died and Completed. Events describe the latest update/manual simulation, not a persistent queue; reading does not consume them. Pause freezes simulation. Stop(false) stops births while live particles drain. Restart restores the seeded sequence. Invalid entity/settings/graph operations raise Lua errors through the native binding.

Shared limits and materials

Read the VFX authoring guide for blocks, imports, coordinate spaces, CPU budgets, snapshot event limits and transparency requirements. The operation contracts apply equally to Lua.
