AnimationController

Version-one .banim state-machine data with clip/1D/2D states, ordered conditional transitions and optional SourceModel retargeting. Load/FromSource validate data. SetController additionally validates clip and bone mappings.

Lua members and signatures

Use Bazzalt.AnimationController. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AnimationController.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
