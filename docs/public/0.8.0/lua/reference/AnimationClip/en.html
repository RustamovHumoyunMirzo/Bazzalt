AnimationClip

Named position/rotation/scale tracks and event markers. Sample supports step, linear/slerp and normalized cubic Hermite interpolation, clamped or looped time. Keys are immutable during runtime playback.

Lua members and signatures

Use Bazzalt.AnimationClip. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AnimationClip.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
