PhysicsState

Immutable trusted physics checkpoint. IsValid means data exists, not that it matches the current scene. GetTick is the physics step index; GetByteSize is a conservative retained-memory estimate. GetHash is a 16-character hexadecimal non-cryptographic same-build state fingerprint, not a security checksum or portable network protocol. No native bytes can be supplied or deserialized through this API.

Lua members and signatures

Use Bazzalt.PhysicsState. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PhysicsState.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
