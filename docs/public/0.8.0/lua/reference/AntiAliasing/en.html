AntiAliasing

Camera anti-aliasing mode. Anti-aliasing reduces stair-stepped edges; temporal modes also use previous frames.

Underlying public header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Component values returned by Entity are copies. After changing fields or methods, call entity:SetComponent(typeName, value). Derived components inherit Component.Enabled, IsEnabled and SetEnabled; core Identity, Hierarchy, Name and Transform have entity-level restrictions.

Applying a mode

local B = Bazzalt
local camera = self.Entity:GetComponent("Camera")
camera.PostProcessing.Enabled = true
camera.PostProcessing.AntiAliasingMode = B.AntiAliasing.MSAA4xFXAA
self.Entity:SetComponent("Camera", camera)

The exposed MSAA presets stop at 4×. An 8× camera preset is not available because the current Vulkan path failed GPU validation at that level.

Write the modified component back to the entity. Settings apply to game cameras, split-screen views and camera texture captures, not the separate editor navigation camera. Turning PostProcessing.Enabled off disables the camera AA stages; turning it back on restores the mode. None=0, FXAA=1 and TAA=2 remain unchanged; TAA remains the default.

MSAA smooths geometry coverage; it does not eliminate all shader or texture shimmer. TAA uses frame history and may ghost or soften moving detail. FXAA and combined modes may also soften detail. TextureDescriptor.Samples controls destination attachments independently. With camera MSAA and a multisampled Texture, the internal stage requests the larger count (up to 4× for the view stage) and resolves to a single-sample output. Counts are not multiplied; use TextureDescriptor.Samples=1 when only the camera should choose the level. See the C++ reference for mode and resource behavior.

Lua members and signatures

Use Bazzalt.AntiAliasing. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AntiAliasing.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
