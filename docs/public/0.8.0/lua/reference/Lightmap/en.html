Lightmap

Static non-overlapping triangle-chart irradiance atlas. Resolution and Padding configure the next bake; BakedResolution, BakedPadding, ChartGrid, Geometry, Texels and TransformSignature describe the saved result. Moving the receiver invalidates its lighting until rebaked. Direct payload edits require Lighting.Invalidate.

Lua members and signatures

Use Bazzalt.Lightmap. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Lightmap.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
