PhysicsReplay

Scene-scoped physics checkpoints, deterministic fixed stepping and bounded in-memory recording/playback. Construct from a live Scene (Lua: ForScene). Checkpoints belong to one running world session and compatible physics topology/configuration. They capture solver state and physics-related poses, not scripts, game time, inputs or random generators. Playback requires AutoSimulation=false and explicit AdvancePlayback; seek does not emit collision callbacks.

Lua members and signatures

Use Bazzalt.PhysicsReplay. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PhysicsReplay.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
