SceneManager

Small static gameplay facade for active-scene lookup and deferred loading. It intentionally does not expose project loading, authoring saves or engine initialization.

Underlying public header: Bazzalt/SceneManager.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local scene = Bazzalt.SceneManager.GetActiveScene()
local accepted = Bazzalt.SceneManager.LoadScene(sceneAssetUUID)

Instance methods use value:Method(...); service/static calls use Bazzalt.SceneManager.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. Native declaration and binding adapter
api.create_named("SceneManager");

Binding source: src/Script/LuaScene.cpp. Inherited component operations use the Entity component APIs.

Asynchronous resources and world cells

LoadSceneAsync prepares a detached replacement; LoadWorldCellAsync adds a cell beneath a parent. UnloadWorldCell queues removal. RegisterStreamingCell, UnregisterStreamingCell and SetStreamingPosition provide distance-driven streaming with hysteresis. GetStreamingSettings and SetStreamingSettings control queue, memory and per-tick activation budgets.

See the streaming guide for examples and the complete ownership contract.
