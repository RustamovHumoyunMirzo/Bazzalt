Particle

Copy of one live particle: simulation-space Position/Velocity, Age/Lifetime in seconds, full Size diameter, Rotation in radians, RGBA Color and transient Id. Editing a snapshot does not apply it.

Lua members and signatures

Use Bazzalt.Particle. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Particle.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
