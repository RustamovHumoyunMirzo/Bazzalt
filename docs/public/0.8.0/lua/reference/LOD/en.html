LOD

Render-only level-of-detail group. Levels contain descending screen-height thresholds and distinct child subtree UUID roots. Center and Size define local bounds; Bias adjusts quality and Hysteresis prevents boundary flicker. ForcedLevel -1 is automatic, -2 culled, and nonnegative values force a level. Disabled groups show level 0. Cameras choose independently. Geometry/shadows change without toggling entity scripts or physics. See the LOD guide for setup and ownership rules.

Lua members and signatures

Use Bazzalt.LOD. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LOD.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
