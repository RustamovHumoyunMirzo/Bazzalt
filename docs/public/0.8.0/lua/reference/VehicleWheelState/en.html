VehicleWheelState

Read-only runtime snapshot from PhysicsScene.GetVehicleWheelState. Position, ContactPoint and ContactNormal are world-space. Contact values are meaningful only when Grounded. AngularVelocity is rad/s, SteerAngle and LateralSlip are degrees, SuspensionLength is metres and SuspensionForce is N. LongitudinalSlip is a ratio.

Lua members and signatures

Use Bazzalt.VehicleWheelState. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VehicleWheelState.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
