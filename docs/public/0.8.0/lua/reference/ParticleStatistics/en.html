ParticleStatistics

Copy of emitter counters and playback state. Dropped counts rejected capacity/budget births. Time is simulation seconds, independent per emitter.

Lua members and signatures

Use Bazzalt.ParticleStatistics. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.ParticleStatistics.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
