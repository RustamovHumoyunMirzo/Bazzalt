LODLevel

One LOD tier. ScreenHeight is a viewport-height fraction in [0,1]. Roots is a list of child subtree entity UUIDs, not assets. Thresholds must descend; duplicate or cross-level overlapping roots are invalid. Lua arrays are one-based, while SelectLevel and ForcedLevel use zero-based level numbers.

Lua members and signatures

Use Bazzalt.LODLevel. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LODLevel.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
