WheelTire

Piecewise-linear longitudinal and lateral tire grip curves. Longitudinal slip is a ratio; lateral angles are degrees. Peak values describe grip near adhesion limits and tail values describe sliding. These are contact friction curves, not a tire thermal or wear simulation.

Lua members and signatures

Use Bazzalt.WheelTire. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.WheelTire.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
