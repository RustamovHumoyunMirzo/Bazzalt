LightProbe

Scene-owned world-space, three-band cosine-convolved irradiance. Radius is world meters; Intensity scales a baked sample. Four strongest overlapping probes are interpolated per fragment by supported built-in lit materials. Coefficients remain world-oriented when the entity rotates.

Lua members and signatures

Use Bazzalt.LightProbe. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LightProbe.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error.
