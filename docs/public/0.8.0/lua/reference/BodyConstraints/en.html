BodyConstraints

BodyConstraints declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Lua members and signatures

Use Bazzalt.BodyConstraints. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.BodyConstraints.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.

Construction / enum values

Enum values: Bazzalt.BodyConstraints.None, Bazzalt.BodyConstraints.PositionX, Bazzalt.BodyConstraints.PositionY, Bazzalt.BodyConstraints.PositionZ, Bazzalt.BodyConstraints.RotationX, Bazzalt.BodyConstraints.RotationY, Bazzalt.BodyConstraints.RotationZ, Bazzalt.BodyConstraints.All.
