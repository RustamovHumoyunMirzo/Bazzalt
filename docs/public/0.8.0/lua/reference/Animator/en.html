Animator

Serialized model/controller playback settings. Model defaults to the owning ModelInstance. AnimatePhysics selects fixed stepping; RootMotion controls extraction/transform/kinematic movement. Dynamic bone rigidbodies retain physics ownership.

Lua members and signatures

Use Bazzalt.Animator. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Animator.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
