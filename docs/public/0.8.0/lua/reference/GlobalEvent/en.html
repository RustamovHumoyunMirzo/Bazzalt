GlobalEvent

UUID-backed project global event asset. Load validates a ready event, GetDefinition returns its typed contract, Subscribe returns a removable token, Fire validates values then drains bounded FIFO invocations, and Unsubscribe removes one listener. Script/module ownership is retained safely. See the global-events guide for argument types, lifecycle and limits.

Lua members and signatures

Use Bazzalt.GlobalEvent. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.GlobalEvent.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
