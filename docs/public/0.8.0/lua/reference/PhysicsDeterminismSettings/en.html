PhysicsDeterminismSettings

Runtime-only scene physics stepping policy. Enabled enforces FixedDeltaTime exactly; default is false to preserve existing variable manual stepping. FixedDeltaTime defaults to 1/60 second and must be finite, positive and at most one second. SingleThreaded defaults true and uses no solver worker threads when enabled. Global Time fixed step must match. IsSolverCrossPlatformDeterministic separately reports the loaded solver build flag.

Lua members and signatures

Use Bazzalt.PhysicsDeterminismSettings. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PhysicsDeterminismSettings.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
