AnimationRig

Shared imported target skeleton and named glTF/GLB clips. Load resolves a ready model UUID; FindClip returns -1 when absent. Procedural rigs can be installed through Animation.SetRig.

Lua members and signatures

Use Bazzalt.AnimationRig. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AnimationRig.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
