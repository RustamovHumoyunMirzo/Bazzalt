LOD in Lua

LOD and LODLevel are available through Bazzalt. Component reads return copies; write a modified value back with SetComponent.

Assign and control levels

local B = Bazzalt
-- group, high and low are existing entities; high/low are children of group.
local lod = group:AddComponent("LOD")
local detailed = B.LODLevel.new()
detailed.ScreenHeight = 0.5
detailed.Roots = {high:GetUUID()}
local simple = B.LODLevel.new()
simple.ScreenHeight = 0.08
simple.Roots = {low:GetUUID()}
lod.Size = 1
lod.Levels = {detailed, simple}
group:SetComponent("LOD", lod)

lod = group:GetComponent("LOD")
lod:ForceLevel(0)
group:SetComponent("LOD", lod)
-- Restore automatic selection:
lod:ForceLevel(-1)
group:SetComponent("LOD", lod)
-- Pure selection helper; result is zero-based, unlike Lua array indices:
local level = lod:SelectLevel(0.2)

Invalid values passed to SetComponent become a script error. IsValid, SelectLevel, GetScreenHeight and ForceLevel have the same semantics as C++. Read Levels and Roots as Lua arrays; assign changed arrays back to the value before committing it to the entity.

Group settings

SettingMeaning
CenterLocal center of the group bounds.
SizeLocal diameter of a sphere enclosing the complete model. World scale is applied automatically using the largest axis.
BiasMultiplies apparent screen height. Values above 1 retain more detail; values below 1 select simpler models sooner.
HysteresisBoundary margin from 0 to 0.5. It prevents rapid switching when the camera sits near a threshold.
CullHide all level geometry below the final threshold. Turn off to keep the last level at any distance.
Forced Level−1 is Automatic, −2 is Culled, and 0 or higher forces a specific level. Disabling the LOD component displays level 0.
Levels1–8 levels ordered from highest to lowest detail. Each level has a ScreenHeight threshold and a list of child subtree roots.

How a level is chosen

ScreenHeight is a fraction of the viewport height: 0.5 means half its height. Thresholds must descend strictly and remain between 0 and 1. The first threshold met by the projected group size is selected. Perspective selection uses camera distance and vertical projection scale; orthographic selection uses orthographic size and does not change when the camera moves closer. Different cameras, split-screen views and render targets choose independently.

For a 0.5 threshold and Hysteresis 0.1, a camera coming from lower detail needs about 0.55 screen height to enter the higher level. Coming from higher detail, it stays there until below about 0.45. Culling uses the same margin. Forced levels bypass hysteresis.

What belongs to the group

Roots are entity UUID references, not assets or file paths. Assign a child subtree root for each representation, such as an imported model parent or a primitive child. Its mesh/primitive descendants participate automatically. Do not assign the group itself. A root cannot appear twice, and roots in different levels cannot contain each other. Nested LOD groups are supported: their visibility also depends on the outer group.

LOD changes rendered geometry and shadows. Entity enabled states, scripts, colliders, rigidbodies, cameras, lights and audio continue operating. This avoids changing gameplay as the viewer moves. Hierarchy selection can still inspect inactive levels; viewport picking and outlines exclude their hidden geometry. Logical scene/physics queries keep their existing behavior and are not a camera visibility query.

Resources and transitions

Level changes retain GPU resources and materials, so switching does not reload a model or compile a shader. They reduce submitted geometry rather than unloading all inactive assets from memory. Models need authored simpler representations: this component does not generate simplified meshes. Transitions default to hard switches with hysteresis; add LOD Transition for supported dither cross-fades. Automatic mesh decimation is not provided. Invalid group assignments produce a rendering warning and leave geometry visible so the scene can be repaired.

Lua cluster setup

-- sources and proxy are children of clusterEntity.
local group = clusterEntity:AddComponent("HLOD")
group.Sources = {sources:GetUUID()}
group.Proxies = {proxy:GetUUID()}
group.Size = 20
group.ScreenHeight = 0.08
clusterEntity:SetComponent("HLOD", group)
local fade = clusterEntity:AddComponent("LODTransition")
fade.Duration = 0.3
clusterEntity:SetComponent("LODTransition", fade)
local image = proxy:AddComponent("Impostor")
image.Atlas = atlasAssetId
image.Size = Bazzalt.Vec2.new(20, 12)
image.Columns = 8
image.ViewCount = 8
proxy:SetComponent("Impostor", image)

Hierarchical proxy groups (HLOD)

Add HLOD to a cluster parent. Assign disjoint child subtrees to Sources and Proxies using the entity pickers. Sources can contain ordinary LOD groups or nested HLOD clusters. Proxies contain your authored merged or simplified mesh, or an Impostor entity. Do not put LOD and HLOD on the same owner. Size is the cluster diameter in local units; Center locates that bound. ScreenHeight selects sources above the threshold and proxies below it. CullHeight=0 keeps the proxy at arbitrary distance; a positive lower threshold enables far culling. Bias, Hysteresis and ForcedLevel follow ordinary LOD rules.

The renderer evaluates parents before nested groups and stops evaluating nested groups that neither representation can expose. It selects separately for each Scene, Game, split-screen and captured camera. It does not disable entities, scripts, rigidbodies, lights or audio. Use a proxy that matches the cluster content; moving/deforming children need a suitable authored proxy strategy. Mesh simplification, merging, lightmap baking and atlas generation are authoring steps, not automatic operations of this component.

Camera-facing impostors

Add Impostor to a distinct proxy child and assign its Atlas image or writable Texture asset. The renderer draws a shared quad with an unlit, depth-writing alpha-cutout material. It uses normal world-space Size and parent scale, so it gets smaller with distance. Center and Pivot place the quad; Pivot=(0.5,0) is useful for a tree rooted at its base. Spherical facing follows camera right/up; Cylindrical facing stays upright on world Y. Camera-facing transforms and atlas frame selection are private per-view state and never overwrite the entity transform.

Author ViewCount equally spaced views around local +Y, starting from +Z and progressing toward +X. Pack them left-to-right, then top-to-bottom using Columns and Rows. Every image must use the same framing and pivot. AzimuthOffset is in degrees. ViewCount may be 1..256 and cannot exceed Columns*Rows; grid dimensions are 1..64. Rows pack azimuth frames, not elevation samples. GetAtlasRect returns a normalized full tile; rendering adds a half-texel inset. Provide padded/extruded atlas borders and correct atlas mipmaps, or disable mipmaps when your source has no per-tile mip chain.

Color tints the atlas, AlphaCutoff clips transparency, and Visible, LayerMask, CastShadows and the component enabled checkbox control rendering. Shadows default off because a camera-facing quad is an approximation. Missing atlases render nothing. Runtime Texture atlases participate in camera capture dependencies and existing history rules for shared feedback. The Scene view supports quad picking and alpha-aware hover/selection outlines. Picking tests the quad, not per-texel alpha. These are color-atlas impostors, not depth/parallax or normal-mapped octahedral impostors.

Reversible dither transitions

Add LOD Transition beside LOD or HLOD. Duration is 0.01..10 seconds; Easing is Linear or Smooth Step. Fade Culling controls whether entering/leaving the culled state also fades. The transition uses unscaled rendering time and continues while the editor is paused. Forced levels, disabled groups, configuration changes and a camera first seeing a group settle immediately. Reversing between the same two levels preserves the current coverage; a jump to a third level starts from the dominant representation.

Outgoing and incoming geometry use complementary ordered pixel coverage with normal depth writes. Nested groups intersect their coverage ranges, preserving the parent partition. Engine surface presets, primitives, default Graphics draws, impostors, and surface shaders compiled from .shad/.bshader/Shader Graph support this path. Shared authored materials are not mutated: view-scoped copies are restored after rendering.

If any relevant renderer in either representation has an incompatible material, the entire group uses an atomic hard cut. Raw .mat/.filamat files, imported glTF provider materials and debug replacement shaders may take this fallback. The console reports it once per group/view. Authored compatible material overrides can enable transitions for imported meshes. The renderer never fades one side while abruptly hiding an unsupported other side.
