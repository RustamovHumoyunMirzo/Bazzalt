Drawing geometry from Lua

Bazzalt.Graphics draws world geometry without exposing the renderer. A vertex has Position, Normal, UV and Color. Mesh index values are zero-based even though Lua arrays holding them start at one.

Create once, submit every frame

local B = Bazzalt
local Behavior = COMPONENT("DrawTriangle")
function Behavior:OnCreate()
    local a = B.GraphicsVertex.new()
    local b = B.GraphicsVertex.new()
    local c = B.GraphicsVertex.new()
    a.Position = B.Vec3.new(-1,-1,-3)
    b.Position = B.Vec3.new(1,-1,-3)
    c.Position = B.Vec3.new(0,1,-3)
    self.Geometry = B.Graphics.CreateMesh({a,b,c}, {0,1,2})
end
function Behavior:OnUpdate(dt)
    B.Graphics.DrawMesh(self.Geometry)
end
function Behavior:OnDestroy()
    self.Geometry:Destroy()
end
return Behavior

The default material uses vertex colors without lighting. Pass a Material, Mat4 model transform and GraphicsDrawOptions after the mesh to customize rendering. DrawVertices accepts a vertex array, optional indices, topology, material, transform and options. DrawLine accepts two Vec3 points, optional Vec4 color and options; DrawTriangle accepts three points, color and options.

Camera callbacks

self.Subscription = B.Graphics.OnBeforeCamera(function(event)
    if event.IsEditorCamera then return end
    B.Graphics.DrawLine(B.Vec3.new(0,0,-3), B.Vec3.new(1,0,-3))
end, self.Entity)
-- To remove it before the script ends:
B.Graphics.Unsubscribe(self.Subscription)

Draws created by OnBeforeCamera are scoped to that camera/view. Other submissions draw in every camera unless options.Camera selects a camera UUID. Events are OnBeginFrame, OnCameraResize, OnBeforeCamera, OnBeforeDraw, OnAfterDraw, OnAfterCamera and OnEndFrame. Only OnBeginFrame and OnBeforeCamera callbacks may draw; the others are notifications. Lua callbacks have an instruction budget and are removed with their VM. Failed callbacks are disabled and reported.

2D and camera matrices

For a flat drawing choose an orthographic Camera, or unproject your pixel points using event.ViewProjection:Inverse():TransformPoint(...). Convert pixels to normalized coordinates: x = 2*pixelX/event.Width - 1, y = 1 - 2*pixelY/event.Height, z = 0. These are regular world draws with depth and material rules, not GUI elements.

Ordered camera material passes

local camera = self.Entity:GetComponent("Camera")
local first = B.Material.Create(B.ShaderPreset.Canvas)
local second = first:Instantiate()
camera.PostProcessing:AddMaterial(first)
camera.PostProcessing:AddMaterial(second, false)
camera.PostProcessing:MoveMaterial(1, 0)
camera.PostProcessing:SetMaterialEnabled(0, true)
self.Entity:SetComponent("Camera", camera)

Pass indices for AddMaterial/SetMaterialAt/SetMaterialEnabled/RemoveMaterial/MoveMaterial are zero-based. GetMaterials returns a one-based Lua array of CameraMaterialPass values. SetMaterials replaces the list, and ClearMaterials removes it. SetMaterial is the legacy replace-all operation. Copy a camera component back with SetComponent when editing a component snapshot.

See the Graphics reference, GraphicsMesh reference and camera post-processing reference.
