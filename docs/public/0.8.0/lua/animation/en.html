Animation in Lua

Lua uses the same native skeleton, clips, controller, IK and physics integration as C++. Global services use dot calls; rig, skeleton, controller and clip objects use colon calls. Entity components are copies: write modified settings back with SetComponent.

Animate a character

local B = Bazzalt
function Behavior:OnCreate()
    local animator = self.Entity:AddComponent("Animator")
    animator.Controller = B.UUID.Parse("YOUR-CONTROLLER-UUID")
    animator.AnimatePhysics = true
    self.Entity:SetComponent("Animator", animator)
    B.Animation.Play(self.Entity, "Walk", 0.2)
end
function Behavior:OnUpdate()
    B.Animation.SetParameter(self.Entity, "Speed", self.Speed)
    local status = B.Animation.GetStatus(self.Entity)
    for _, event in ipairs(B.Animation.GetEvents(self.Entity)) do
        if event.Name == "Footstep" then
            -- Play a sound or another authored response.
        end
    end
end

Pose math and IK

local rig = Bazzalt.Animation.GetRig(entity)
if rig then
    local pose = Bazzalt.Animation.GetPose(entity)
    local settings = Bazzalt.IKSettings.new()
    settings.Solver = Bazzalt.IKSolver.FABRIK
    settings.Root = 3; settings.Tip = 7 -- zero-based bone indices
    settings.Target = Bazzalt.Vec3.new(0.5, 1.0, 0.2)
    local solved, reached = Bazzalt.Animation.SolveIK(rig.Rig, pose, settings)
    Bazzalt.Animation.SetPose(entity, solved)
end

Lua pose/clip/skeleton lists use ordinary one-based table indexing, but stored Bone, Parent, Root, Tip, Source, Target and Clip index fields remain zero-based to match C++ and imported models. SolveIK returns the modified pose table followed by a convergence boolean; it does not mutate a supplied Lua table in place. GetRig returns nil without a rig.

Available operations

Animation exposes Play, Stop, Pause, Resume, Rebind, SetRig, GetRig, SetController, SetParameter, GetParameter, SetTrigger, SetTime, Evaluate, SetLayer, RemoveLayer, SetIK, RemoveIK, GetPose, SetPose, GetStatus, GetEvents, Blend, Additive, SolveIK, Retarget and MapByName. Optional arguments mirror C++ defaults. Invalid operations raise Lua errors. GetStatus includes State, Time, NormalizedTime, TransitionWeight, Playing, RootDelta and RootRotation. Event snapshots contain Name, State and Clip.

AnimationRig.Load resolves a model UUID. AnimationController.Load and FromSource load or build controller definitions. Skeleton, SkeletonBone, BoneTransform, AnimationClip, AnimationTrack, AnimationKey, AnimationMarker, AnimationState, AnimationBlendSample, AnimationTransition, AnimationCondition, RetargetBone, RetargetSettings and IKSettings support procedural data construction. RootMotionMode, IKSolver, AnimationChannel, AnimationInterpolation, AnimationBlendType and AnimationComparison are enums.

Animator and IKConstraint support the normal entity component operations and enable/disable state. For persistent IK helpers, pick AnimatorEntity, Target and PoleTarget UUIDs in the scene; GroundRaycast can place feet against the physics world. Read the animation manual for authoring, coordinate spaces, retargeting and resource limits. The C++ guide defines the shared operation contracts; the Lua reference lists every binding.
