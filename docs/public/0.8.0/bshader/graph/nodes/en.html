Shader Graph node reference

This catalog documents every node shipped with this editor. Input sockets accept connections or editable defaults. Float broadcasts to larger numeric vectors; different vector dimensions need explicit conversion. “Same” means the numeric type inferred from inputs. Property names define material parameters. Operation formulas describe behavior; they are not snippets to paste into Bshader source. Material and Vertex are output sinks.

Node behavior notes

Noise is smoothly interpolated value noise; Hash Noise produces an uncorrelated hash. These are not fractal or cellular noise implementations. Lerp is linear interpolation; Branch emits a real conditional. Normal Unpack converts an RGB normal map to a normalized signed tangent-space direction. SRGB/Linear conversion nodes use a 2.2 gamma approximation. Matrix nodes use the Bshader model transform and are restricted to Vertex. Texture Lod performs an explicit mip-level lookup. Texture nodes expose sampler properties; image formats and render-target availability follow the existing texture asset system.

Math domain errors, such as division by zero or normalizing a zero vector, follow shader-language behavior. Choose valid ranges for dynamic material parameters. This catalog is extensible; it does not claim compatibility with every vendor-specific shader-node library.
