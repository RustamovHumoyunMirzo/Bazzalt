Shader Graph panel

A shader describes how a surface is drawn. A material chooses a shader and supplies values such as color and roughness. Shader Graph lets you build a surface shader by connecting nodes instead of typing shader source. It produces the same runtime material packages as a handwritten shader.

Create and open a graph

  1. In Asset Browser, right-click a project folder and choose Create > Shader Graph. The new asset has the .shadg extension and a graph document icon.
  2. Double-click the asset, or choose Open Shader Graph in its context menu. Window > Shader Graph also opens the dockable panel.
  3. The node library is on the left, the graph canvas in the center, and node fields and a material preview on the right.

Add and connect nodes

Drop a project image onto empty canvas to create a Texture and Sample Texture pair. Search the library, then drag a node onto the canvas or double-click it to add it at the visible center. Drag from the circle on a node's right edge to an input circle on another node's left edge. Connections carry typed values. A scalar can broadcast into a vector, but different vector dimensions require Vector and Swizzle nodes. Cycles and incompatible connections are rejected with a diagnostic.

The Material node is the surface output. Color expects four channels, roughness and metallic expect a scalar, normal expects a three-channel tangent-space normal, emissive expects four channels, and AO expects a scalar. Unconnected outputs have useful defaults; an unconnected normal preserves the mesh normal. Unlit shading omits lit-only outputs. Add one optional Vertex output and connect a three-channel offset to deform vertices. Object matrix transforms are available only on that vertex branch.

Make an editable color

  1. Add Property. Select it, set Name to Tint and Kind to float4, then choose its four default values.
  2. Connect its output to Material > Color. A Property declares a parameter that appears in material inspectors; a Color node is a fixed constant in the shader.
  3. Create a Material asset and assign the .shadg asset to its Shader field. Set Tint on that material and assign the material to your object. No unlocking is required.

Preview a sphere or a project mesh

The preview renders the compiled shader on a sphere in a separate offscreen Filament scene. Use the project asset picker above the preview, or drop an OBJ, GLB or glTF asset into it, to preview your model. Clear the picker to return to the sphere. Model node transforms, available UVs, normals and vertex colors are preserved. Large meshes use the bounded geometry preview budget; this is a material-authoring preview, not a full model importer.

Edits are saved automatically and visible edits request a debounced preview. Update Preview requests another sample, which is useful for Time nodes. Compilation and rendering run on a dedicated worker, with stale results discarded. The preview never changes your open scenes, selected objects or game cameras. Texture nodes expose named texture parameters and can supply a project image default. An isolated preview cannot evaluate a scene's live camera render target; those textures are evaluated in the scene or game viewport.

Navigate and edit

Drag nodes to arrange them, middle-drag to pan, and use the wheel to zoom. Drag empty canvas to select several nodes. Delete removes selected nodes; the Material output is retained. Copy and paste duplicate selected nodes and their internal connections. Right-click a wire to disconnect it. Frame Graph fits all nodes. External source changes reload automatically when there are no pending edits. A detected conflicting external change is not overwritten; use Refresh to reload and discard pending local graph edits. The panel toolbar and Edit menu provide undo and redo while the graph has focus. Node fields use the editor's shared inputs and theme.

Pin and unlock

Pin Asset keeps the current graph open when another graph is activated. This is a panel navigation lock. A .shadg itself is a managed graph source: it is usable by materials and scripts while it remains a graph.

Unlock to Shader Source, in the panel or the asset's context menu, replaces the .shadg with generated .shad source. The original graph is removed and its .meta UUID is retained, so material references continue to identify the same shader. An existing destination is never overwritten. Conversion is destructive: graph structure cannot be reconstructed from the source later. Undo/Redo can reverse it within the current graph history; keep source control for recovery after closing or opening another asset. Undo refuses to overwrite external source edits.

Use it at runtime

Assign a graph to any shader picker. The editor/compiler validates the graph, generates Bshader, reflects its parameters and compiles its material package before runtime use. C++ Shader/Material and Lua Shader/Material APIs work with the same asset UUID and parameters. Games do not load Qt, Python, or a node-graph interpreter. See the graph format and node reference.

While a preview is being compiled or rendered, the previous image is dimmed beneath a circular loading indicator. The overlay clears when the replacement arrives or an error is reported. Toolbar tools use themed engine icons.
