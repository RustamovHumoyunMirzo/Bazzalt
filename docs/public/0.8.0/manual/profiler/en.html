CPU Profiler

A profiler records where time is spent. Open Window → CPU Profiler, click Start Capture, reproduce a slow interaction or play sequence, then click Stop Capture. The window is modeless, so the editor remains interactive.

Read results

Each row groups a named scope: Calls, Total milliseconds, and Maximum milliseconds. A large maximum can reveal a hitch; a large total can reveal repeated work. Nested scopes overlap and totals are not additive frame costs. Capture uses a bounded buffer of 100000 completed scopes, so keep recordings short. Normal editing does not copy or display profiler samples.

Export a timeline

Export Trace saves JSON that a Chrome trace or Perfetto viewer can inspect. Worker lanes show concurrency and waits. These are CPU measurements; GPU execution requires a GPU profiler. Closing the window stops an active capture. Starting another capture replaces the previous one. An unavailable native profiler reports an error rather than pretending to record.
