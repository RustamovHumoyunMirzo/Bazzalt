Profiler

Open Window > Profiler, start a capture, reproduce a slow interaction, then stop recording. The window stays modeless. Its minimize button is disabled so the child window cannot become inaccessible.

CPU frame graph

Select a frame bar to inspect scopes overlapping that frame, including worker threads. All captured scopes restores the complete recording. The table groups scopes by name: calls, total milliseconds and maximum milliseconds. Nested totals overlap; adding them does not give frame time. CPU scopes measure elapsed time, including waits, rather than CPU utilization.

Thread timeline

Each thread has its own lane and nested scopes have separate rows. Hover a bar for its name and duration. Ctrl + wheel zooms horizontally. Scroll to explore the recording. Tiny bars share pixels at low zoom; all original samples remain in the table and exported trace. Only instrumented scopes appear.

GPU and system graphs

During recording the window samples counters every 250 milliseconds, retaining the latest 240 observations. Choose a metric to graph GPU frame time, backend CPU time, resident process memory, primitive geometry cache bytes, entities, components, renderables, render primitives or GUI batches. The table shows the latest counters.

GPU timing is asynchronous. Pending or unsupported results show Unavailable. Multi-viewport swapchain changes can reset history: GPU observations are not correlated to the selected CPU frame. Render primitive counts describe resources, not executed draw calls.

Resident memory includes Python, Qt and the native engine. Current residency is available on Windows and Linux; other platforms may report it unavailable. Geometry cache bytes are tracked resources, not total GPU memory. These views do not provide allocation call stacks, leak attribution or per-draw GPU timing. Use an external graphics debugger for draw-by-draw inspection.

Export and capture lifetime

Export Trace saves CPU trace-event JSON for Perfetto or Chrome trace viewers, with timestamps and thread identifiers. System graph history is not included in the CPU export. Captures hold at most 100000 completed scopes; later samples are dropped. Keep recordings short. Starting again replaces the recording. Closing stops capture and polling. Normal editing does not copy profiler buffers or poll this window.
