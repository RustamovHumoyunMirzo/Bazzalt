Performance and profiling

0.8.0 removes repeated work in shared engine paths rather than lowering simulation rates or rendering resolution. The same core is used by the editor and standalone players. LOD is an optional new way to reduce geometry; existing scenes without it keep their representations.

What changed

  • Affine transform composition constructs scaled rotation columns directly. The general matrix operations and legacy handling of nonfinite inputs remain available.
  • Physics reuses each body's world pose within one synchronization and appends comparison keys without allocating a temporary string per field. Public mutable components are still read on every synchronization.
  • Primitive geometry and picking BVHs are shared in a bounded 32 MiB CPU payload cache. Repeated hover queries no longer tessellate a shape or linearly scan every triangle. Model ray queries use a bounded stack instead of allocating a work stack.
  • Unchanged mesh/primitive transforms, render flags, primitive colors and light parameters are not uploaded again. Live material values, animated shader time, moving objects and changed properties continue updating.
  • The inspector avoids resetting unchanged fields and enabled checkboxes during Play. Rejected component edits restore the stored value. New values are not delayed behind a lower inspector refresh rate.

Measure your project

Use Scene Statistics to inspect renderable counts and frame time. The native editor statistics dictionary additionally reports transform_uploads, render_state_uploads, primitive_color_uploads, light_uploads, primitive_cache_hits, primitive_cache_builds and primitive_cache_bytes. Upload counts are cumulative for the renderer instance. A static scene should stop accumulating unchanged-property uploads, while animation and editing should resume them.

Compare the same project, camera, rendering backend, resolution and build configuration. Warm shader/asset caches before measuring steady-state interaction. Separate first import/startup time, CPU work, GPU time and display frame rate; a microbenchmark improvement is not a promise of the same percentage increase in game FPS.

Reducing geometry with LOD

Use authored simpler models and screen-height thresholds for distant objects. LOD reduces submitted geometry and shadow geometry per camera while retaining resources for smooth switches. See the LOD guide. It does not disable gameplay or physics and does not automatically simplify a model.
