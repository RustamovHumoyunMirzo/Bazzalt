Supported platforms and rendering backends

BAZZALT currently supports Windows, Linux and macOS for both the editor and standalone games. Other platforms are listed below so that unsupported targets are explicit. A standalone game is the executable and runtime produced by Build, not the editor's Game panel.

Hub, Editor and the game compiler require x64, or arm64 on macOS. A 32-bit machine can run an x86 game output with its required libraries and drivers, but cannot run the editor. Windows/Linux ARM and 32-bit macOS targets are not supported. Unsupported platforms do not have a supported editor, player SDK or packaging workflow; their presence in this table does not announce a planned release.

Rendering backend support

A rendering backend is the graphics API used to submit rendering work to the GPU. The same private rendering layer serves the Scene view, Game view, camera render textures and standalone player. Gameplay code uses BAZZALT APIs rather than backend objects.

Availability depends on the installed runtime SDK and GPU driver. The editor's rendering-backend preference lists backends compiled into that build; choosing Automatic uses the renderer's default and does not guarantee that an incompatible driver can render. A critical backend change requires an editor restart. Metal or WebGPU integration hooks in source code, or platform support in the renderer dependency, do not establish support for a BAZZALT release target.

See the macOS guide for native menus, architecture profiles, application signing and player Keychain storage. Metal is the macOS release backend; Vulkan and OpenGL are Windows/Linux targets.

Choosing a game build target

Choose Windows or Linux and x64 or x86 in Build Settings. Build on the target operating system using a matching prebuilt runtime SDK. The game compiler cooks project content and compiles game scripts; it does not build the engine or cross-compile between operating systems. Unsupported host/target combinations are rejected before cooking or launching the output.

Linux presentation uses X11; Wayland sessions require XWayland. Native Wayland surfaces are not supported. See Linux setup for required libraries and 32-bit output requirements, and settings for editor preferences and build configuration.

Support is for the current alpha version. Test the selected backend and architecture on the actual target machine before distributing a game.
