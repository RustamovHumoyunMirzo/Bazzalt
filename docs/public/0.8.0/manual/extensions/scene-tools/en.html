Scene extension tools

The Controls menu at the right of the Scene toolbar shares the existing Gizmos, Scene Icons, Grid and Statistics toggles. Extensions can add checked scene tools below them. Checked tools can handle pointer/key events, selection changes and scene changes; returning true from a pointer/key callback consumes that event before normal scene navigation or selection.

Register a tool

AssetRegistry:
  - Id: paint_source
    Path: Editor/Paint.lua
Scripts:
  Paint:
    Id: paint_source
    Scope: Editor
Extends:
  Scene:
    - Id: paint
      Title: Paint terrain
      Script: Paint
      Function: OnRun
      Shortcut: Ctrl+Alt+P
      Checked: false

Extends.Scene is a list with unique Id values. The script must be editor-scoped Lua. Function defaults to OnRun; Shortcut is optional and may not collide with existing editor actions. Checkable defaults to true. Set Checkable: false for a one-shot menu/shortcut command; its function receives enabled=true and invoked=true. Controls remember their checked state in editor settings. Checking a tool calls its function with enabled=true; unchecking calls it with enabled=false and removes its input/guide participation. On a new project, checked tools are initialized against that project.

Scene scripts run in their own Editor API VM. Existing EditorRegistry/entry adapters retain the declarative widget service; they do not share Lua globals with scene tool instances.

Handle scene input

return {
  OnRun = function(self, state)
    self.enabled = state.enabled
  end,
  OnScenePointerDown = function(self, event)
    if event.button ~= 1 then return false end
    local hit = Editor.Raycast(event.origin, event.direction)
    if hit then Editor.Log("Hit at " .. hit[1]) end
    return true
  end,
  OnSelectionChanged = function(self, ids)
    Editor.Log("Selected " .. #ids .. " objects")
  end
}

Pointer tables contain x/y in logical viewport coordinates, button/buttons and modifiers using Qt integer values, plus world origin/direction arrays. Key tables contain key, text, repeat and modifiers. OnScenePointerMove and OnScenePointerUp use the same pointer shape; OnSceneKeyDown and OnSceneKeyUp use the key shape. OnSceneChanged receives active scene information; OnSelectionChanged receives entity UUID strings. Selection notifications include scene and programmatic selections and are coalesced over a short UI interval. Scene change notifications are coalesced; edits are not recursively echoed to their originating tool. These are authoring callbacks, not game lifecycle events. Input is suspended during Play.

World tools and terrain authoring

Use ScreenRay/Raycast for placement, GetEntity/GetEntities and SetTransform/SetComponentProperty for editing, and DrawLines for editor-only 3D guides. CreateMeshAsset writes a project OBJ from vertices and zero-based triangle indices; assign its returned asset UUID to a Mesh component. Larger terrain tools should work in bounded chunks. Asset writes are confined to Assets and do not expose arbitrary filesystem or process access. All panels can be discovered/opened/closed through the shared API; assets can be queried and selected. See the full API contract.
