Scene view

Scene view is where you look around and place objects. Its editing camera is not your game's camera.

What movement changes

Looking around moves the editor camera only; it does not change a selected Camera entity. The grid gives a spatial reference. Camera/light icons let you find non-mesh entities. An outline shows hovered/selected geometry, and a gizmo supplies manipulation handles for the active tool.

The panel displays the active scene. If you select an entity in an inactive loaded scene, activate that scene to view it here. Hidden/locked objects and hidden overlays can explain a missing icon or handle.

Navigate step by step

  1. Click Scene view so its controls are active.
  2. Select an object and press F to frame it. This centers the editor camera on the selection; it does not teleport the object.
  3. Hold right mouse and drag to look around with focus-point navigation.
  4. Hold right mouse and use W/A/S/D/Q/E to fly: forward, left, back, right, down, up. Looking around during flight rotates around the camera position.
  5. Release the right button to leave navigation. Shift with right-drag pans/moves the camera.

Do not use a letter shortcut while typing in an Properties field and expect camera movement. Menu shortcuts and flight movement are gated to the appropriate interaction.

Choose a manipulation tool

1 selects; 2 translates; 3 rotates; 4 scales. You can also use the toolbar. Click/drag a gizmo axis, not arbitrary nearby geometry, to manipulate a selected object. A selection rectangle selects multiple objects and updates selection while dragging.

Translate changes position. Rotate changes orientation around the chosen pivot. Scale changes size. Local aligns the axes to the active object's orientation; when off, the axes align with the world. These modes do not change the stored component type.

Pivot versus Center

With one selected object the gizmo is at its origin. With a group, Pivot rotates/scales objects around their own origins, whereas Center rotates/scales around a shared center. Translation moves the group in either mode. Choose the mode before a group operation so objects do not unexpectedly orbit a point.

Visibility and guides

Grid, Gizmos, and Statistics are independent toolbar toggles. Top-level selection chooses the highest model object instead of each internal part. Camera and light guide lines belong to selected objects; they help inspect frusta, ranges, and cones and are not game geometry.

The orientation widget in the top corner indicates world axis directions relative to the editor camera. Clicking a direction changes the view. Preferences can hide it. View also contains preset angles, focus/frame actions, and debug shading modes.

Why this is not Game output

Free move

In Translate, Rotate or Scale mode, drag an already-selected object's visible surface or icon to move the selection parallel to the editor camera. Gizmo handles keep their normal axis/rotation/scale behavior and take priority. A simple click still selects; the move starts after a short drag threshold. Ctrl-click/drag retains additive selection. In Select mode, dragging creates a selection box rather than moving objects. Free move participates in undo/redo and uses the translation snapping/sensitivity settings.

Transform trajectories

During a transform, the Scene view can show the starting point and a move path, a rotation arc, or reference/current scale boxes. Use Edit > Preferences > Scene to toggle move, rotate and scale trajectories independently and choose how long they remain after release. These guides are editor-only and never appear in Game output or scene files.

Game output uses enabled scene Camera components, their viewports and post-processing. Scene view has editor overlays, its own camera and a grid. Atmosphere comes from the scene Fog settings. Do not diagnose game camera depth of field by looking only at the editor camera. Read Game output next.

Remember Scene camera position

In Edit > Preferences > Scene, enable Remember Scene camera position to restore the editor view on your next launch. It saves the position, look direction, focus point and orbit distance per project and scene, automatically after navigation and on close. This is personal editor data, stored in the platform app-data settings, and does not modify a game Camera or dirty a scene. Disabling it skips restoration and further camera saves; it retains earlier saved views.

Move with G

Select objects and focus Scene, then press G to start moving them with the pointer in the camera plane. Press X, Y or Z to constrain the move to a world axis. Left-click or Enter applies the move. Escape or right-click cancels it. A completed move is one undo step. The same controls work for selected terrain spline anchors and Bézier handles.

Scene atmosphere and spline controls

Select a scene heading in Hierarchy to edit its Fog section. Fog is saved with the scene and applies to both Scene and Game views. Disable its header checkbox for a clear atmosphere. Exponential creates distance haze, Height also varies density with elevation, and Volumetric integrates density through space using animated noise and directional-light scattering. Start distance leaves nearby objects clear. Density increases opacity per metre. In volumetric mode, Maximum distance bounds integration. Maximum opacity limits the strength in every mode. In volumetric mode, more depth slices improve the froxel volume at additional GPU cost. Affect sky applies fog to the background as well as geometry. When selecting Volumetric from the original fog range, the editor initializes density to 0.002, start distance to 0, maximum distance to 1000 metres and Affect sky to enabled. Re-select Volumetric to initialize an older scene that still has those original defaults. Authored fog ranges stay available when switching modes. For a clear gap around the camera, increase Start distance. Volumetric start distance is measured along camera-forward depth, with a smooth density fade over the following one to five world units. Fog extinction remains independent of light direction. When Affect sky is disabled, fog appears against scene geometry. A missing environment map can be repaired separately while you edit fog.

While using terrain splines, press Tab in Scene to hide or restore the neighbouring controls without leaving the tool. The controls icon beside terrain settings also restores them. Editing points and handles remains available while controls are hidden. G followed by X, Y or Z shows a bold colored guide along that world axis. Apply with left-click or Enter, cancel with Escape or right-click.

Fog height and distance

Volumetric fog can fill the environment or form a low layer. Set Height Falloff to 0 for uniform atmospheric density. Positive falloff makes fog denser below Height and thinner above it. The default editor volumetric profile uses zero falloff when the original height settings are unchanged. Re-select Volumetric to update an older default profile, or edit Height Falloff directly. Existing custom height settings are preserved. Fog still accumulates with distance and stops at visible surfaces.

Fog and scene scale

Density measures extinction per world unit. At density 0.002, an unobstructed 50-unit path has about 10% fog opacity; at 0.02 it has about 63%. Moving closer to a surface shortens that path. Changing the camera field of view alone does not change its distance. Noise is sampled at world positions. For an older dense editor preset, re-select Volumetric to use the calibrated atmosphere, or set Density to 0.002 directly. Blended model foliage now contributes alpha-covered depth so nearby leaves are not treated as distant sky. Partially transparent glass remains a single-depth coverage approximation.
