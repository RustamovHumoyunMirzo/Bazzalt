Local fog

Local Fog places a fog bank inside a box attached to an entity. Scene fog fills the environment; local fog affects only the part of a viewing ray that passes through its box. Both may be enabled together.

Create a fog bank

  1. Create an empty entity in Hierarchy and select it.
  2. Choose Add Component, search for Local Fog, and add it.
  3. Move the entity where the fog should be. Set Size to its full width, height and depth.
  4. Use Transform rotation and scale to orient and resize the region. Parent transforms also apply.
  5. Keep StartDistance at zero initially. Walk the Scene camera into and out of the selected box to inspect the result.

The selected entity shows its bounds as guide lines in Scene. These guides are excluded from Game output. The component checkbox turns the fog bank off without removing its settings.

Choose the medium

Exponential creates uniform density inside the box. Height changes density along the box’s local Y axis, using Height and HeightFalloff. Volumetric also supports animated noise and directional light scattering. Density controls extinction per world unit. Color supplies ambient scattered light, so the medium can remain visible while looking away from a sun.

Blend Distance softens the region’s edges in local units. A zero value gives a hard box boundary. MaximumOpacity limits the bank’s coverage; overlapping banks can accumulate more coverage together. Affect Sky permits fog on background rays that cross the box.

Distance and quality

StartDistance is a camera-relative clear gap; leave it at zero for a region that begins at its world-space box. MaxDistance limits camera-forward integration range. Steps controls depth resolution. A very thin fog bank or rapidly varying noise needs more slices. The low-resolution volume approximates density near boundaries, so soft edges are usually preferable.

Scene fog can be disabled while local fog remains visible. Hiding the owning entity in the editor hides its fog in Scene only. Disable the component to remove it from Game output too. A zero-scale transform has no volume and produces no fog.

See the C++ LocalFog reference and Lua LocalFog reference for gameplay controls.
