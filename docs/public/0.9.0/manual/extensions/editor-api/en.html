Editor Lua API

This API belongs to macros and Extends.Scene scripts. Call Editor.Method(...), using a dot. Arrays use Lua's one-based indexing unless a method explicitly asks for mesh indices. Services return ordinary tables, strings, booleans or nil. Gameplay's Bazzalt namespace is deliberately absent.

Scene and selection

MethodContract
GetVersion()Returns editor API version (api=1) and engine version.
GetScene(), GetScenes()Active scene information or the loaded-scene list. UUIDs identify scenes across names.
GetEntities(offset=0, count=1024), GetEntity(id)Page scene entity summaries (count at most 4096), or read entity details/components by UUID. Unknown entities return nil.
GetSelection(), SetSelection(ids)Read or replace editor entity selection and synchronize hierarchy/inspector. Locked objects cannot be selected.
InstantiateModel(assetOrPath,parent="")Instantiate a project model with its authored node hierarchy; returns the new root UUID.
CreateEntity(name, parent=""), DeleteEntity(id), RenameEntity(id,name), SetParent(id,parent="")Create, remove, rename or reparent authoring entities. Creation returns a UUID. Reparenting preserves world placement.
SetTransform(id, position, rotation, scale), Translate(id, delta)World-space vectors; rotation is a normalized quaternion {x,y,z,w}. Numbers must be finite. Writes honor entity locks.
AddComponent(id,type), RemoveComponent(id,type), SetComponentProperty(id,type,property,value)Use inspector component/property names. The ordinary component validation and default-component removal rules apply. Writes return success.

Assets and panels

MethodContract
GetAssets(offset=0,count=1024), GetAssetFolder(), SelectAsset(uuidOrPath), RefreshAssets()Page project asset records, read the current browser folder, select a project asset, or refresh imports/browser. Asset selection preserves its containing folder.
ReadAssetText(relativePath), WriteAssetText(relativePath,text)Read/write UTF-8 .obj, .css, .shad or .matinst files under the project's Assets root, through symlink-aware path validation. Writes are atomic and undoable. Text is limited to 1 MiB.
CreateMeshAsset(relativeObjPath, vertices, triangleIndices)Write an OBJ and import it, returning its asset UUID. Vertices are {x,y,z}; indices are zero-based integers grouped into triangles. At most 4096 vertices and 4096 indices per call. Chunk larger geometry.
GetPanels(), OpenPanel(id), ClosePanel(id)Panel records contain id/title/open. Built-in and extension dock IDs are supported; pinned close protection still applies.

Viewport and history

MethodContract
GetSceneCamera(), SetSceneCamera(state)Read/restore editor navigation state: version=1, target, distance, yaw, pitch. This does not alter a game Camera component.
ScreenRay(x,y), Raycast(origin,direction)Generate a world ray from logical Scene coordinates, or query editor geometry and return a hit position/nil. This is scene geometry picking, not a physics query.
DrawLines(lines), ClearLines()Set this session's editor-only world guides. Each line is {ax,ay,az,bx,by,bz,r,g,b,a}; the combined visible guide budget is 2048. Guides never enter the Game viewport or saved scene.
SetSceneInput(enabled)Opt a running macro into scene callbacks, or stop listening. Extension tools use their Controls checkbox for this state.
BeginUndo(label), EndUndo(), CancelUndo()Group a gesture across callbacks, commit it, or restore it. Finish every gesture. Without an explicit group, each mutating callback is one command. Errors cancel pending changes.
Log(text)Add an item to the editor Console under this macro/tool's name.

Owned UI

CreateDialog(id,title,options) creates an owned, nonmodal child dialog, initially hidden. Pass {modal=true} as options for a window-modal dialog. AddWidget(dialogId,spec) adds an element and returns its dialog/widget handle. IDs are unique identifiers of at most 64 characters. ShowDialog(id) shows it; CloseDialog(id) hides it. GetValue(handle)/SetValue(handle,value) read/write fields without recursively firing callbacks.

Widget spec fields: id, type, text, callback. Types: label/button/text/number/checkbox/choice. Number supports min/max/value; checkbox supports value; choice supports options. callback defaults to OnUI. The callback argument contains widget and value. See the macro dialog example.

Execution boundaries

Editor scripts run on the editor UI thread with an instruction budget of one million instructions per callback and a 32 MiB Lua allocator limit. Keep work incremental; they are tools, not background render loops. At most 16 sessions, eight dialogs per session and 32 dialogs total may be active. Each dialog is bounded to 512 Qt child objects. API tables have at most 4096 entries and 16 nesting levels; text results are limited to 1 MiB.

There is no io, os, package, debug, arbitrary load, native-module loader or gameplay API. require resolves only the snapshotted/registered modules. Protected-call and finalizer facilities are unavailable so errors and limits cannot be hidden from the editor transaction boundary. Invalid code, modules or values report Console errors; invalid edits do not bypass component/asset validation. This is a bounded capability interface, not permission to execute shell commands. Personal macro stores are not a game scripting format.
