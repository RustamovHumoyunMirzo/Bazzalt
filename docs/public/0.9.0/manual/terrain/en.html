Terrain editing

A terrain is an entity with a Terrain component. Its surface is a heightfield: each position on its local XZ plane has one height. The default terrain covers 10 by 10 metres. Its built-in white material has metre grid lines.

Create and select a terrain

  1. In Hierarchy, open Add New and choose Terrain.
  2. Select the entity. Expand Terrain in Inspector to set Size, sample Resolution and Chunk Size.
  3. Open Terrain at the right of the Scene toolbar and enable Edit terrain. This starts disabled each session.
  4. Choose the terrain in the overlay. This target remains independent of ordinary scene selection.

The overlay is confined to Scene, below its toolbar. Drag the six-dot handle to reposition it. Its position and brush settings save automatically. The separate Terrain settings button opens a nonmodal window, so you can keep sculpting while adjusting the brush.

Sculpt a surface

Choose Raise, Lower, Smooth or Flatten and hold the left mouse button on terrain. Radius is measured in terrain-local metres. Strength controls metres per second for height changes. Falloff controls softness at the brush edge. Flatten approaches Target height. A full press/drag/release stroke is one undo command. Shift reverses Raise, erases Paint or fills Holes. Right-button scene navigation remains available.

A brush heightmap is an optional project image picked in Terrain settings. Bright pixels apply more of the brush. The editor keeps a bounded, cached stamp rather than decoding the image on every sample.

Height and splat layers

Expand Layers in Inspector. Add, remove and reorder entries with the list controls. Each layer has an enable switch, opacity, height blend mode, heightmap, splatmap, material, color and tiling. Reordering existing entries preserves their samples. At least one layer must remain.

Add accumulates height. Replace interpolates toward that layer's height. Maximum and Minimum keep the higher or lower surface, weighted by opacity. These operations are evaluated in list order. Flatten and spline tools edit the chosen layer, so layers above it may still affect the final height.

In Terrain settings choose a zero-based Layer index, then Import heightmap or Import splatmap. Height import multiplies normalized image values by Import height scale. Splat values control surface coverage. Painting redistributes other layers' weights so coverage stays normalized. Image imports support linear 8-bit and 16-bit values, plus HDR floats; importing is explicit so a reference change cannot silently overwrite hand edits.

Paint blends built-in layer colors continuously. When assigning custom material assets, each triangle uses its dominant layer's material, with its Tiling value. Arbitrary shader programs are not blended together. Use higher sample resolution for finer custom-material boundaries.

Vegetation

Add entries under Vegetation. Pick an imported Model and optional Material with the same filtered asset pickers used elsewhere. Configure density, height/slope bounds, spacing, scale range, normal alignment, seed and instance limit. Choose the zero-based Vegetation prototype in Terrain settings. Generate vegetation distributes placements across the terrain; the Vegetation brush places instances locally and Shift erases them.

The generation seed is repeatable for the same terrain and existing placements. Models use the renderer's existing asset and material pipeline. Holes reject placements. Generated instances belong to terrain data, rather than creating thousands of hierarchy entities. Regenerate after sculpting to snap existing placements to the changed surface.

Roads, rivers and surface booleans

Add a Spline in Inspector. Enter local-space control points in its expandable Points list, or select Spline in the overlay and click terrain to append points. Width defines the centre strip, Shoulder adds smooth falloff and Depth lowers the strip for a river bed. Select its zero-based index in Terrain settings and choose Apply spline. Closed connects the last point to the first. This edits the selected height layer; a spline does not create water or a separate road mesh.

Choose another upright terrain as Boolean source. Union keeps the higher surface; Intersection keeps the lower; Subtract carves by the source's positive height. These are heightfield operations on the overlap, not volumetric CSG: caves and overhangs require meshes. Rotation around the up axis is supported; tilted source transforms are rejected because they cannot describe an upright heightfield.

Rendering, collision and saving

The renderer uses independent chunks with distance-based LOD and skirts covering LOD seams. Chunks containing holes keep full detail. Only changed chunk geometry is uploaded after edits. Filament handles chunk frustum culling, materials, shadows and editor selection outlines. Runtime cameras and Scene share the terrain surface.

Add a non-convex Mesh Collider to use the full-resolution terrain in Jolt. The collision bake omits rendering skirts and respects holes. Vegetation does not automatically gain individual physics bodies. Save the scene normally; terrain samples, layers, splines and placements are included in the scene's YAML. Referenced textures, models and materials participate in asset dependency tracking and game cooking.

Authoring budgets

Resolution must be 2^n + 1, from 3 to 257. Chunk Size is a power of two from 2 to 64 and cannot exceed Resolution minus one. Each terrain allows eight layers, 64 vegetation prototypes, 10,000 placements and 128 splines with up to 1,024 points each. Use multiple terrain entities for a larger world. Automatic edge welding between separate terrain entities is not performed; match their border samples and transforms when tiling.
