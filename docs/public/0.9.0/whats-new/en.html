What’s new in 0.9.0

This release adds Android game packaging and separate Debug and Release builds. Existing Windows, Linux and macOS projects retain independent platform profiles.

Inspector sections and quieter Git refreshes

Component fields can be grouped into nested, collapsible sections. Camera depth of field, projection and output fields use this layout, along with light, audio and rigidbody settings. C++ and Lua behaviors can declare sections with SECTION and the Section property option. The scene toolbar removes its Statistics chip. View menu and preference controls remain available. Git background refreshes preserve unchanged list items, selection and diff text, avoiding periodic disabled-button flashes.

Navigation and pathfinding

Recast/Detour navigation adds NavMesh Surface baking, persistent .bnavmesh assets, agents, path queries, area costs, dynamic box/cylinder obstacle carving, Jolt collider geometry and kinematic character movement. The separate bazzalt_ai runtime ships with game builds. Inspector controls bake and assign navigation assets. C++ and Lua share the public navigation service. Asset-browser refreshes retain existing items to avoid a macOS thumbnail-delivery race. Read the Navigation guide.

Cinematic sequencing

Timeline assets and a dedicated dock panel add transform keyframes, cinematic camera shots and blends, typed Global Event signals, markers, frame snapping, undo/redo and restorable editor preview. Timeline Director components and C++/Lua controls play sequences in standalone games. VFX assets and panel tabs use the updated themed artwork. Read the Timeline guide.

Android game output

Android ARM64 and x86_64 runtime SDKs provide OpenGL ES 3 and Vulkan. The editor discovers installed SDK/NDK directories and validates the selected toolchain before packaging. Engine binaries come from CI-built SDKs. Read the Android build guide.

Signing and content delivery

Android profiles select APK-bundled content, a signed content split APK, OBB expansion files or app-specific external data. Signed inventories and optional AES-GCM encryption apply to each delivery mode. Android Keystore protects per-install wrapping keys. SaveGame slots use private SharedPreferences.

Debug and Release

Build Debug enables script debug information and disables script optimization. Build Release optimizes scripts. Separate cache and bin subdirectories prevent either configuration from replacing the other. Runtime SDK libraries remain production builds.

Application icons

Each platform profile has its own icon field. Windows uses ICO, macOS uses ICNS, Linux uses square PNG and Android uses a 512-pixel square PNG that produces density-specific launcher icons.

Android SDK downloads in Hub 1.2

The updated Hub accepts Android Core SDK packages and installs their runtime templates alongside desktop SDKs. Use the matching Hub and Editor release when installing the Android SDK.
