Using extension SDKs in Lua

Install and enable the package in Window > Extensions, pin the enabled SDKs to the project, and reopen it. Public SDKs are available through Bazzalt.require; gameplay scripts do not load files from the editor's installation directory.

Load a public module

local Math = Bazzalt.require("StudioMath")
local value = Math.Double(4)
-- Bazzalt:require("StudioMath") is also accepted.

SelfContained modules use their ModuleName. A module configured with SelfContained: false uses ExtensionId.ModuleName. Bazzalt.Extensions.HasModule(name) tests availability; GetModules returns public names. Modules are cached within each script VM. Native functions use dot syntax and receive the same supported scalar/math/UUID values as the C++ extension API. No sol2 or Lua C headers are needed by a native SDK author.

A required Lua module must return a table. Unknown/private modules, circular require calls, invalid native arguments and module execution errors produce script errors. Private Runtime helpers can be required by modules from their own extension; they are not project-facing SDK APIs. Standard Lua filesystem/process libraries are not enabled.

For dynamic dispatch, Bazzalt.Extensions.Call(moduleName, functionName, argumentArray) calls a public SDK function and returns its supported value. Bazzalt.Extensions.GetAsset(extensionId, assetId) returns a registered runtime asset UUID, or zero when unavailable. Pass that UUID to the normal asset APIs.

Read scene settings

Use Scene:GetExtensionProperty(extensionId, name, optionalFallback), Scene:SetExtensionProperty(extensionId, name, stringValue) and Scene:GetExtensionProperties(). These properties persist in scene files. Inspector-authored values use JSON string encoding; parse them appropriately for your own SDK contract.

Built games

The same module names work after building a game. Runtime SDK bytecode/native modules are packaged with it; editor-only controllers are excluded. See installation and project pins. Extension creation has a separate authoring reference.
