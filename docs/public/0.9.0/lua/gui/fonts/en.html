Font assets in Lua

Lua uses the same imported fonts and FreeType GUI renderer as C++. The engine owns initialization. Font and component values are edited through the normal copy/write-back API.

Example behavior

local B = Bazzalt
local Label = COMPONENT("LabelFont")
Label.Typeface = PROPERTY("Font", B.Font.new())

function Label:OnCreate()
    if not self.Typeface:IsValid() then return end
    local text = self.Entity:GetComponent("GuiText")
    text:SetFont(self.Typeface)
    text.FontSize = 24
    text.Kerning = true
    text.LetterSpacing = 0
    text.LineSpacing = 1.2
    self.Entity:SetComponent("GuiText", text)
end
return Label

The entity needs GuiText and RectTransform under a Frame. Pick a project font in Typeface. To refer to an existing UUID value, call Bazzalt.Font.Load(assetUUID, faceIndex), where faceIndex defaults to 0. GuiText.Font stores the UUID, and FontFace the collection index.

Metadata and measurement

local info = self.Typeface:GetInfo()
local size = self.Typeface:MeasureText("AV example", 24, 240)
-- info.Valid, Family, Style, FaceCount, GlyphCount, Scalable, Kerning
-- size.X and size.Y are pixel dimensions.

MeasureText has optional size (16) and wrapWidth (0). Invalid/unavailable input returns zero dimensions; invalid handles return default FontInfo. See Font, FontInfo, and font contracts and limits. HarfBuzz shaping and SheenBidi mixed-direction layout apply automatically to assigned fonts, including contextual joining, Indic substitutions and combining marks. Supply logical UTF-8 text and a font covering the script. Measurement and rendering share the same cluster-based wrapping. Automatic font fallback, vertical writing and IME editing are not implemented.
