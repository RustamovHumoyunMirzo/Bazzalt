VFXGraph

Immutable compiled data graph. Load resolves an imported .vfx UUID and transitive graph imports; FromSource parses a versioned data document. IsValid/GetError report failures. No arbitrary expressions execute. GetDependencies includes imported graphs and output material/texture assets.

Lua members and signatures

Use Bazzalt.VFXGraph. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VFXGraph.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
