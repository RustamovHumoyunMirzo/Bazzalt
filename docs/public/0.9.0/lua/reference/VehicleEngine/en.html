VehicleEngine

Chassis powertrain engine. Torque uses Nm; speed uses RPM; Inertia uses kg m². LowTorque, PeakRPMFraction and HighTorque define a normalized three-point torque curve. Disable or omit for an unpowered vehicle; an enabled differential is required to deliver torque to wheels.

Lua members and signatures

Use Bazzalt.VehicleEngine. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VehicleEngine.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
