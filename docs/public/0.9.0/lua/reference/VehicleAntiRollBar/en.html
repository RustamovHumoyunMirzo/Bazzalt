VehicleAntiRollBar

An axle anti-roll spring between two wheel entities of the same vehicle. Stiffness uses N/m. It opposes unequal suspension compression and suspends its action when either linked wheel is disabled.

Lua members and signatures

Use Bazzalt.VehicleAntiRollBar. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VehicleAntiRollBar.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
