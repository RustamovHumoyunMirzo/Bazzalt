VFX

Engine-thread particle controls scoped to one live entity. Requires ParticleEmitter and a scene ParticleSystem. Play/Restart/Stop/Pause/Resume manage simulation; SetGraph replaces the runtime graph; Emit and Simulate are bounded manual operations. Snapshot queries never expose renderer internals. See the VFX guide for units, errors and limits.

Lua members and signatures

Use Bazzalt.VFX. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VFX.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
