Skeleton

Validated local bind hierarchy. Parent is -1 for a root; indices are zero-based. ForwardKinematics returns model-space matrices; FindBone returns -1 or throws on ambiguous names.

Lua members and signatures

Use Bazzalt.Skeleton. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Skeleton.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
