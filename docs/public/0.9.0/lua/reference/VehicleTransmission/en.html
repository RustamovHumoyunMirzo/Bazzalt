VehicleTransmission

Automatic or manual gearbox with one to ten forward ratios and one negative reverse ratio. GearCount determines the active forward ratios. Shift thresholds use RPM and timing fields use seconds. ClutchStrength controls the engine-to-wheel coupling. Manual controls are PhysicsScene.SetVehicleGear; ordinary driving uses SetVehicleInput.

Lua members and signatures

Use Bazzalt.VehicleTransmission. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.VehicleTransmission.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
