EventInvocation

Snapshot delivered to GlobalEvent subscribers. Event is the asset UUID, Name is the schema name, Arguments describes fields and Values stores typed values in schema order. C++ Get<T>(name) and Lua GetValue(name) validate access. Do not retain native references after delivery.

Lua members and signatures

Use Bazzalt.EventInvocation. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.EventInvocation.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
