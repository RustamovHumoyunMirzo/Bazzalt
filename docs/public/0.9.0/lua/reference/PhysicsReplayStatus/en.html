PhysicsReplayStatus

Read-only status returned by GetStatus. Tick is the current restored/simulated physics tick; FrameCount includes the initial frame. Cursor is a zero-based frame index. MemoryBytes measures recorder-owned checkpoints. LimitReached reports a stopped bounded recording; AtEnd means the cursor addresses the last stored frame.

Lua members and signatures

Use Bazzalt.PhysicsReplayStatus. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PhysicsReplayStatus.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
