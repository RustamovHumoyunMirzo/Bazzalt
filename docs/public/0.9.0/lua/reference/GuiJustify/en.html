GuiJustify

GuiJustify declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

See the GUI guide for layout, rendering, component write-back and input examples.

Values

Start (0), Center (1), End (2), SpaceBetween (3) distribute positive main-axis space remaining after flex sizing. SpaceBetween adds to Gap only when there are at least two participating children. Overflow stays aligned to Start. Default: Start.

Lua members and signatures

Use Bazzalt.GuiJustify. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.GuiJustify.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.

Construction / enum values

Enum values: Bazzalt.GuiJustify.Start, Bazzalt.GuiJustify.Center, Bazzalt.GuiJustify.End, Bazzalt.GuiJustify.SpaceBetween.

Native declaration and binding adapter
api.new_enum("GuiJustify","Start",GuiJustify::Start,"Center",GuiJustify::Center,"End",GuiJustify::End,"SpaceBetween",GuiJustify::SpaceBetween);

Binding source: src/Script/LuaGUI.cpp. Inherited component operations use the Entity component APIs.
