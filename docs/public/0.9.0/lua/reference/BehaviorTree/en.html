BehaviorTree

BehaviorTree declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

AI::BehaviorTree is a move-only execution instance. FromSource/Load validate .bbtree XML, Initialize fills missing defaults, Tick advances a caller-supplied Context, and Reset cancels active work. In Lua, use Bazzalt.BehaviorTree.FromSource or Load, then Tick/Reset with an Entity, Blackboard and optional callbacks.

See the behavior tree guide for complete usage and lifetime rules.

Lua members and signatures

Use Bazzalt.BehaviorTree. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.BehaviorTree.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
