Blackboard

Blackboard declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

AI::Blackboard stores case-sensitive keys with bool, double, string or Vec3 values. C++ Get<T> uses exact types. Lua Blackboard.new owns memory; AI.GetBlackboard(entity) returns a checked live agent view. Reset preserves memory.

See the behavior tree guide for complete usage and lifetime rules.

Lua members and signatures

Use Bazzalt.Blackboard. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Blackboard.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.

Get

memory:Get(key: string) -> boolean|number|string|Vec3|nil
Native declaration and binding adapter
template<class T> const T* Get(const std::string& key) const;
[](LuaBlackboard& b,const std::string& key,sol::this_state state)->sol::object{
        auto& values=b.Resolve().Values;auto found=values.find(key);if(found==values.end())return sol::make_object(state,sol::lua_nil);
        return std::visit([&](const auto& value){return sol::make_object(state,value);},found->second);
    }

Set

memory:Set(key: string, value: boolean|number|string|Vec3)
Native declaration and binding adapter
void Set(std::string key,Value value);
[](LuaBlackboard& b,const std::string& key,sol::object value){
        if(value.get_type()==sol::type::boolean)b.Resolve().Set(key,value.as<bool>());
        else if(value.get_type()==sol::type::number){double n=value.as<double>();if(!std::isfinite(n))throw std::invalid_argument("Non-finite AI number");b.Resolve().Set(key,n);}
        else if(value.get_type()==sol::type::string)b.Resolve().Set(key,value.as<std::string>());
        else if(value.is<Vec3>()){auto v=value.as<Vec3>();if(!std::isfinite(v.X)||!std::isfinite(v.Y)||!std::isfinite(v.Z))throw std::invalid_argument("Non-finite AI vector");b.Resolve().Set(key,v);}
        else throw std::invalid_argument("Blackboard expects boolean, number, string or Vec3");
    }
