LightBakeHandle

Copyable asynchronous bake result. Poll GetStatus, GetProgress and GetError; Cancel abandons work without altering existing data. Apply validates the unchanged source snapshot and runs on the thread that began the bake. Destruction does not implicitly cancel.

Lua members and signatures

Use Bazzalt.LightBakeHandle. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LightBakeHandle.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
