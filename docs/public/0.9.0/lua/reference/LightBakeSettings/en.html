LightBakeSettings

Validated offline diffuse transport settings. Samples is 16..16384, Bounces 0..4, MaxTriangles 1..4000000. RayBias is positive and less than MaxDistance. AmbientRadiance is an explicit constant linear sky input; DefaultAlbedo is linear RGB in [0,1].

Lua members and signatures

Use Bazzalt.LightBakeSettings. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LightBakeSettings.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
