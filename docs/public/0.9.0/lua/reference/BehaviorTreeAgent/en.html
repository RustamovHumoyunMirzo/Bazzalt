BehaviorTreeAgent

BehaviorTreeAgent declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Attach Bazzalt::BehaviorTreeAgent to an NPC and assign a .bbtree UUID to Tree. Loop restarts terminal trees; Enabled controls execution. Scene serialization, Lua component copies, inspector picking and cooked dependency retention use the same component.

See the behavior tree guide for complete usage and lifetime rules.

Lua members and signatures

Use Bazzalt.BehaviorTreeAgent. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.BehaviorTreeAgent.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
