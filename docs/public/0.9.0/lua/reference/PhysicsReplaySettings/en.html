PhysicsReplaySettings

Recording limits include the initial checkpoint. MaxFrames defaults to 3600 (range 2..100000); MaxMemoryBytes defaults to 64 MiB (range 1 KiB..512 MiB). Recording stops with LimitReached when the next complete frame would exceed either budget; old frames remain available. Caller-retained checkpoint handles have independent lifetimes.

Lua members and signatures

Use Bazzalt.PhysicsReplaySettings. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PhysicsReplaySettings.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
