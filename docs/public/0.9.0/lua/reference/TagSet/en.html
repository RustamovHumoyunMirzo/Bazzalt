TagSet

Case-sensitive sorted unique semantic labels. Empty sets are supported. Names must be 1–64 UTF-8 bytes, without commas, control characters or surrounding spaces. A set holds at most 64 labels. Add validates and deduplicates, TryParse atomically reads the comma-separated storage form. Tags are separate from physics and rendering layer masks.

Lua members and signatures

Use Bazzalt.TagSet. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.TagSet.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
