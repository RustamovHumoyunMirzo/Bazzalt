Animation

Engine-thread animation service. Controls Animator playback, numeric parameters/triggers, layers, IK and copied poses/events. Pure Blend/Additive, FK, IK and Retarget operations are renderer independent. See the animation guides for spaces, errors, root motion and physics ownership.

Lua members and signatures

Use Bazzalt.Animation. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Animation.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
