IKSettings

Model-space target/pole, zero-based root/tip and bounded solver iteration/tolerance/weight. TwoBone requires exactly three joints; CCD/FABRIK accept longer chains. Unreachable goals return best effort and false.

Lua members and signatures

Use Bazzalt.IKSettings. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.IKSettings.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
