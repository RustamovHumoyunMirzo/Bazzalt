LODTransition

Attach beside LOD or HLOD to request reversible timed ordered-coverage transitions. Duration uses unscaled render time (0.01..10 seconds), Easing is Linear or SmoothStep, and FadeCulling includes entering/leaving culling. Unsupported materials cause an atomic whole-group hard cut. Histories and overrides are private per-view state.

Lua members and signatures

Use Bazzalt.LODTransition. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.LODTransition.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
