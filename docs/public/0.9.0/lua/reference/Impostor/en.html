Impostor

World-sized camera-facing alpha-cutout quad with an authored color atlas. Columns/Rows pack azimuth frames left-to-right and top-to-bottom; ViewCount is 1..256 and starts at local +Z toward +X. AzimuthOffset is in degrees. Pivot positions the local unit quad relative to Center. GetMatrix maps Pivot to the world center. Camera-facing state never writes the entity transform.

Lua members and signatures

Use Bazzalt.Impostor. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Impostor.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
