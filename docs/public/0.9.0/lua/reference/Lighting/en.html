Lighting

Scene-based diffuse probe baking and sampling. BeginBake snapshots static contributors and schedules detached CPU tracing. CreateProbeGrid and Clear mutate the scene on its owning thread. Runtime material support and transport limits are documented in the baked-lighting guide.

Lua members and signatures

Use Bazzalt.Lighting. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Lighting.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
