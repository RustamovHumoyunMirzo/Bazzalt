CVar

Process-wide typed console variables. Register on the engine thread; Get/Set enforce exact types, bounds and flags. Changed callbacks observe committed values or Pending changes. Archive import validates all values before publication. Re-register from OnReload to reconnect callbacks after hot reload.

Lua members and signatures

Use Bazzalt.CVar. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.CVar.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
