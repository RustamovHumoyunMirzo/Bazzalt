FontInfo

FontInfo declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Metadata fields

Valid is true only for a loaded supported face. Family and Style identify the selected face and may be empty if its naming tables do not supply them. FaceCount is the number of faces in the asset; FontFace is zero-based. GlyphCount is the number of glyphs in the selected face, not the number of Unicode characters. Scalable reports outline scaling support. Kerning reports FreeType pair-kerning metadata; this flag does not gate HarfBuzz shaping or GPOS features. Shaping is automatic and depends on the font's script coverage and tables. Invalid metadata has false flags, zero counts and empty strings. Values are snapshots and editing this value does not edit the asset.

Lua members and signatures

Use Bazzalt.FontInfo. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.FontInfo.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
