CVarDefinition

Unique case-insensitive console name, description, typed DefaultValue, combinable Flags and optional inclusive numeric Minimum/Maximum. DefaultValue fixes Boolean/int64/double/string type. Registration rejects collisions and invalid defaults.

Lua members and signatures

Use Bazzalt.CVarDefinition. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.CVarDefinition.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
