ReflectionProbe

World-oriented HDR cubemap capture with GGX roughness mips. Radius and BlendDistance control influence; BoxSize is world-space half extents for BoxProjection. Resolution configures the next bake; CapturePosition and BakedResolution describe saved Radiance. Moving a probe disables stale captures. Enabled is inherited.

Lua members and signatures

Use Bazzalt.ReflectionProbe. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.ReflectionProbe.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
