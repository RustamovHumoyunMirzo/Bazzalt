Cinematics in Lua

Bazzalt exposes TimelineSequence, TimelineTransformTrack, TimelineTransformKey, TimelineCameraShot, TimelineSignal, TimelineDirector, TimelineStatus, TimelineEvent, TimelineInterpolation and TimelineEventType. Data objects use .new(). Methods on data instances use colons. Cinematics service methods use dots.

Play an authored asset

local B = Bazzalt
local Intro = COMPONENT("Intro")
function Intro:OnCreate()
    -- This entity already has a configured Timeline Director in the scene.
    B.Cinematics.Play(self.Entity)
end
function Intro:OnUpdate(dt)
    local status = B.Cinematics.GetStatus(self.Entity)
    for _, event in ipairs(B.Cinematics.ConsumeEvents(self.Entity)) do
        if event.Type == B.TimelineEventType.Completed then
            -- Continue gameplay here.
        end
    end
end
return Intro

Create or load sequence data

B.TimelineSequence.Load(assetUUID) loads a ready timeline asset. B.TimelineSequence.FromSource(yamlText) parses version-1 sequence data. A sequence instance exposes Name, Duration, FrameRate, Tracks, Cameras and Signals, plus Validate and ToSource. Transform keys expose Time, Value and Interpolation. Tracks expose Name, Target, WorldSpace, Muted and Keys. Shots expose Name, Camera, Start, End and BlendIn. Signals expose Time, Name, Event and Arguments. UUID fields use B.UUID objects. Typed signal arguments can be authored using FromSource with the documented argument records.

To add a Director, call entity:AddComponent("TimelineDirector"). It exposes Sequence, Speed, PlayOnAwake, Loop, UseUnscaledTime, RestoreOnStop and RestoreOnCompletion. Components are copies in Lua, so write modified settings back through entity:SetComponent("TimelineDirector", settings). The Sequence field is an asset UUID. Alternatively, call Cinematics.SetSequence(entity, sequence) to install in-memory data.

Service methods and results

Cinematics.Play(entity) starts at zero. Pause(entity) and Resume(entity) control advancement. Stop(entity) releases camera control and applies the Director's stop restoration setting. Seek(entity, seconds, fireSignals) samples the sequence, with fireSignals defaulting to false. GetStatus(entity) exposes Time, Duration, Playing, Paused and Error. GetOutputCamera(entity) returns its temporary camera entity. ConsumeEvents(entity) drains an array of events, each containing Type, Time and Name. StopAll(scene) releases all Director players in a scene.

TimelineInterpolation has Step, Linear and Smooth. TimelineEventType has Started, Paused, Resumed, Stopped, Completed, Looped and Signal. Use project Global Events for authored callbacks. Preview scrubbing is silent. Read the Timeline manual for the asset schema, binding rules, physics restrictions, camera blending and budgets.
