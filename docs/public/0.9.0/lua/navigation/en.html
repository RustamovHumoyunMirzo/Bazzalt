Navigation in Lua

Use the global Bazzalt.Navigation service. Service functions use dots. Entity component operations use colons. Navigation components are copied by GetComponent. After editing a copy, pass it to SetComponent.

Request a destination

local B = Bazzalt
local Behavior = COMPONENT("Walker")
function Behavior:OnCreate()
    -- A Navigation Agent with its Surface is configured in the inspector.
    local accepted = B.Navigation.SetDestination(self.Entity, B.Vec3.new(8, 0, 5))
    if not accepted then B.Console.Warning("No navigation route target") end
end
function Behavior:OnUpdate(dt)
    local state = B.Navigation.GetAgentState(self.Entity)
    if state.Status == B.NavigationAgentStatus.Arrived then
        -- Feed navigation velocity/status into your animation logic.
    end
end
return Behavior

Components and enums

NavMeshSurface, NavigationAgent, NavigationObstacle and NavMeshModifier use .new() for values and the standard AddComponent, GetComponent, SetComponent, RemoveComponent and component-enabled operations. Component values expose the same public fields as C++. NavigationPathStatus contains Invalid, Partial and Complete. NavigationAgentStatus contains Idle, Moving, Arrived, Blocked and Invalid. NavigationObstacleShape contains Box and Cylinder.

Service methods

Bake, Clear, IsReady, Save, Load, LoadAsset, CalculatePath, SamplePosition, Raycast, SetAreaCost, SetDestination, ResetPath, Warp, GetAgentState and GetStatistics mirror C++. Save/Load accept UTF-8 path strings. LoadAsset accepts an asset UUID. CalculatePath and Raycast default their optional area mask to 65535. SamplePosition defaults extents to Vec3(2,4,2) and the same mask. Corners is a native sequence exposed to Lua. Invalid inputs raise script errors. A missing route is represented by the result status, not an exception. See the API reference for each member and the Navigation editor guide for setup, physics ownership and limits.
