Terrain C++ API

Include Bazzalt/Terrain.h. Terrain is a normal enabled component. Its serialized data contains no editor or renderer handles. Coordinates passed to terrain methods are local to the terrain entity; use its world matrix to convert world positions.

Sculpt through code

#include <Bazzalt/Terrain.h>
auto& terrain = entity.AddComponent<Bazzalt::Terrain>();
terrain.Size = {10, 10};
Bazzalt::TerrainBrush brush;
brush.Radius = 2;
brush.Strength = 1;
terrain.ApplyBrush(Bazzalt::TerrainTool::Raise, {0, 0}, brush, 0.5f);
float height = terrain.GetHeight(0, 0);
auto hit = Bazzalt::TerrainGeometry::Raycast(terrain, {0, 20, 0}, {0, -1, 0});

Mutation and sampling

IsValid checks all fields and storage budgets. MarkDirty assigns a new render/collision revision. Call it after modifying public fields or sample arrays directly. Methods that change data call it automatically. Resize resamples existing heights, coverage and holes. AddLayer returns a zero-based index; RemoveLayer keeps at least one layer.

GetHeight samples the composed heightfield. Use TerrainGeometry::Raycast to query a surface affected by volumetric caves or overhangs. GetNormal and GetSlope return its local normal and slope in degrees. Sampling outside its XZ extent clamps to its edge. IsHole reads a cell coordinate. ApplyBrush accepts a TerrainTool, local XZ centre, TerrainBrush and elapsed seconds. ImportHeightmap and ImportSplatmap accept finite row-major samples and dimensions; height import has an optional scale.

ApplySpline applies a saved spline to a layer. ApplyBoolean combines an upright source terrain using its source-to-local matrix. GenerateVegetation rebuilds one prototype's placements; PaintVegetation places or erases a bounded area. Invalid operations throw standard exceptions. Validate direct edits before publishing them to a live component.

Geometry and queries

TerrainGeometry.BuildChunk returns CPU vertices and triangle indices for chunk coordinates and optional LOD. Vertices include position, normal, UV and blended color. Render skirts are included when SkirtDepth is positive; set it to zero on a copy when baking collision. Raycast returns an optional TerrainHit containing Position, Normal and Distance. It uses the authoritative full-resolution surface, including holes, independently of visual LOD. Ray directions are normalized; the distance is in terrain-local units.

Configuration records

TerrainLayer stores Heightmap, Splatmap and Material UUID references, color, tiling, opacity, blend mode and optional Heights/Weights arrays. TerrainBrush stores radius, strength, falloff, target height, layer index and an optional normalized row-major stamp. TerrainVegetation stores model/material references and generation filters. TerrainInstance stores prototype index, position, rotation and uniform scale. TerrainSpline stores local points, width, shoulder, depth, strength and closed state.

The generated reference pages list every field and signature for these types. See the editor manual for default values, budgets, material-boundary behavior and volume extraction budgets.

Caves and overhangs

Add a record under Terrain → Caves and overhangs. Carve subtracts an ellipsoid from the ground. Add solid joins an ellipsoid to the ground and can form an overhang. Center and Radius use terrain-local metres. Volume height range must enclose the affected ground and the complete ellipsoid. Vertical samples controls extraction detail. Affected chunks keep full detail. Ray picking and non-convex Mesh Collider use the extracted surface.

Spline surfaces and neighbours

Enable Generate surface on a spline to create a ribbon for a road or water surface. Set Material to a project material instance, Texture scale to metres per UV repeat, and Surface offset to separate the ribbon from the ground. Surface collision controls whether the ribbon joins the terrain collider. The material determines the appearance and animation of water.

In terrain tools, choose a neighbouring terrain as the source, select an edge and use Match edge to neighbour. The operation resamples the source border into the destination and raises destination resolution when necessary. Both terrains must have adjacent upright edges. The selected layer must remain editable through subsequent layer composition. The edit supports undo and scene saving.

Build a cave from C++

auto& terrain = ground.AddComponent<Bazzalt::Terrain>();
Bazzalt::TerrainVolume cave;
cave.Center = {0, -1, 0};
cave.Radius = {2, 2, 2};
cave.Operation = Bazzalt::TerrainVolumeOperation::Subtract;
terrain.Volumes.push_back(cave);
terrain.MarkDirty();
// Attach a non-convex MeshCollider for static world collision.

Blend custom terrain materials

Assign a material instance to each painted terrain layer. Surface shaders compiled from Bshader, shader graphs or material source receive a terrain variant automatically. The renderer interpolates splat coverage across triangles and blends layers with per-pixel stochastic sampling. Each material retains its parameters, textures, animation and shading model. The Scene viewport enables temporal anti-aliasing while layered materials are visible. Use TAA or TAA + FXAA on game cameras to resolve the sampled transition. Coverage grain is visible with anti-aliasing disabled.

Material edits update shared material instances at runtime. Splat painting updates the layer distribution. The game compiler packages terrain variants alongside ordinary shader packages. Binary-only shader packages require a matching terrain coverage variant.
