AI behavior trees in C++

Include Bazzalt/AI.h, Bazzalt/Components/BehaviorTreeAgent.h and Bazzalt/Systems/BehaviorTreeSystem.h. Public types live in Bazzalt::AI; the component and scene system live in Bazzalt. Jolt implementation types remain private. Read the authoring guide and complete XML/block catalog for the file contract.

Scene-owned agents

auto npc = scene.CreateEntity("Guard");
auto& agent = npc.AddComponent<Bazzalt::BehaviorTreeAgent>();
agent.Tree = treeAssetUUID;
agent.Loop = true;
auto& ai = scene.GetSystem<Bazzalt::BehaviorTreeSystem>();
auto& memory = ai.GetBlackboard(npc);
memory.Set("target", Bazzalt::Vec3{10, 1, 0});
memory.Set("alert", 0.8); // numeric values are double
ai.SetHandlers(npc,
  [](const std::string& name, Bazzalt::AI::Context& c, bool cancelled) {
    if (cancelled) return Bazzalt::AI::Status::Failure;
    if (name == "Watch") {
      c.Memory.Set("watching", true);
      return Bazzalt::AI::Status::Running;
    }
    return Bazzalt::AI::Status::Failure;
  },
  [](const std::string& name, Bazzalt::AI::Context& c) {
    return name == "Alert" && c.Memory.Number("alert") > 0.5;
  });

BehaviorTreeSystem is installed on every scene. Agents tick automatically before physics on fixed gameplay updates. Scene clearing cancels agents and removes blackboards, callbacks and traversal state. Recreated entity UUIDs begin with fresh state. System Action/Condition fields are assignment-compatible ownership-aware callback slots. GetBlackboard requires a live BehaviorTreeAgent in this system's scene. Its returned reference is owned by the system; do not retain it after component/entity removal, scene teardown or system replacement. Loop=false stops after a terminal result. Reset(entity) cancels running work, clears traversal/cooldown state, preserves memory and permits another run.

Handlers, cancellation and lifetime

SetHandlers(entity, action, condition, owner=nullptr) installs per-agent callbacks, cancelling old work first. Null callbacks fall back to the system's Action and Condition fields. ClearHandlers(owner) cancels and disconnects all per-agent handlers with that owner token, retaining blackboards and allowing future execution. Native script registrations automatically inherit the script owner, retain the gameplay module, and disconnect before script destruction, streamed unload, or hot reload. Explicit owner tokens are also supported. Call ClearHandlers for non-script owners before destroying them. A callback receives the node name, Context and, for actions, a cancellation flag. Context contains Self, Memory, DeltaTime, Action and Condition. Actions return Status; conditions return bool. Missing handlers fail. Self can be invalid during entity cleanup: check it before touching components. Callbacks run on the engine thread; avoid structural entity changes during a system traversal.

Running custom actions own their cleanup. On cancellation, release movement, animation, subscriptions and other resources; the cancellation return status is ignored. Completed actions are not sent a cancellation notification. Explicit Reset, reactive/utility preemption, timeout, component disable and scene stop cancel running branches. Do not use a raw Lua callback as a C++ module callback; use the Lua registration API, which tracks VM lifetime.

Standalone trees

auto tree = Bazzalt::AI::BehaviorTree::FromSource(
  "<BehaviorTree version='1'><Tree>"
  "<Sequence><Wait seconds='.5'/><Succeed/></Sequence>"
  "</Tree></BehaviorTree>");
Bazzalt::AI::Blackboard memory;
tree.Initialize(memory);
Bazzalt::AI::Context context{npc, memory, fixedDeltaTime};
auto status = tree.Tick(context);
tree.Reset(context); // cancels active work, keeps memory

BehaviorTree::Load(UUID) resolves a ready .bbtree asset through AssetManager, using its runtime cache. FromSource parses and validates XML. Trees are move-only; construct one execution instance per independently ticking NPC. Initialize fills missing blackboard defaults. Tick rejects negative or non-finite delta time. Standalone callers supply the same blackboard and handlers when resetting, and must call Reset before releasing a tree with active resource-owning actions. Destroying a tree cannot invent the Context required for cancellation. Invalid source or unavailable assets throw std::invalid_argument.

Blackboard API

AI::Value is variant<bool,double,std::string,Vec3>. Blackboard::Set replaces a key; Contains checks presence; Erase removes it. Get<T> returns a pointer of the exact stored type, or nullptr. Number(key, fallback=0) reads only double values. Values exposes the map for C++ iteration. Use std::string for text and double for numbers; pointers/references into Values can be invalidated by replacement or removal. Initialize never overwrites an existing key. Blackboard access is an engine-thread operation.
