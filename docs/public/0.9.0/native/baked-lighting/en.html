Baked lighting in C++

Include Bazzalt/Lighting.h and Bazzalt/Components/LightProbe.h. Lighting operates on a Scene; it does not expose graphics handles or require control of the engine loop. Normal gameplay can use data already saved in the scene without running a bake.

Sample saved irradiance

#include <Bazzalt/Lighting.h>
#include <Bazzalt/Scene.h>
// scene is a Scene reference; position and normal are world-space.
auto irradiance = Bazzalt::Lighting::Sample(scene, position, normal);

The result is diffuse irradiance in linear RGB. A Lambertian outgoing diffuse color is albedo * irradiance / Pi. A matching Lightmap is sampled first; otherwise four diffuse probes are blended. No valid influence returns zero. Invalid or zero normals throw. The four strongest overlapping probes blend with squared radius falloff divided by squared distance; the result is clamped nonnegative.

Asynchronous authoring

auto probes = Bazzalt::Lighting::CreateProbeGrid(
    scene, {-5, 1, -5}, {5, 5, 5}, 2, 2, 2, 15);
Bazzalt::LightBakeSettings settings;
settings.Samples = 512;
settings.Bounces = 2;
auto request = Bazzalt::Lighting::BeginBake(scene, settings);
// Store request; poll in a later editor tool update on the same owning thread.
if (request.GetStatus() == Bazzalt::LightBakeStatus::Complete) {
    if (!request.Apply(scene)) {
        auto error = request.GetError(); // source scene changed, for example
    }
}

CreateProbeGrid validates all dimensions and the 65,536-probe resource budget before creating entities, with rollback on construction failure. BeginBake validates settings and builds a detached snapshot before scheduling work. Apply is transactional and belongs on the thread that created the request. It validates the source again; it does not save a file. Cancel is safe from another thread and does not clear existing scene data. Clear removes baked coefficients, preserving probes and lights. Handle destruction does not implicitly cancel work; call Cancel when a tool closes. Jobs retains detached data until its work exits.

Settings and constraints

Samples: 16–16384. Bounces: 0–4. MaxTriangles: 1–4000000, default 1000000. RayBias must be finite, positive and less than MaxDistance. AmbientRadiance is nonnegative linear radiance; DefaultAlbedo is linear RGB in [0,1]. Probes store nine real, world-space SH irradiance coefficients ordered constant, Y, Z, X, XY, YZ, 3Z²âˆ’1, XZ, X²âˆ’Y². They are already cosine-convolved. Baked, Radius and Intensity control runtime participation. Match C++ and Lua behavior; see the editor guide for material support and transport limitations.

UV lightmaps

Add a Lightmap component to static Primitive Object or Mesh entities, or select them and choose Add lightmaps to selection in Window > Lighting. Resolution is a power of two from 16 to 4096. Padding is the gutter around each triangle chart. Increase resolution if the charts do not fit. Bake lighting writes a non-overlapping triangle-chart irradiance atlas. Runtime reconstructs chart coordinates from the baked world triangles, preserving the model’s original texture UV sets and material textures. This is non-directional diffuse lighting. A matching lightmap replaces probe diffuse at that surface; it is not added twice.

Moving a lightmapped entity invalidates its atlas until it returns to its baked transform or is rebaked. Animated/deformed geometry is unsuitable. Meshes need not have a pre-authored UV2 channel. Each triangle receives an equal-sized chart, so dense models need higher resolution or separate receivers. Disable the component to fall back to probes.

Reflection captures

Create a Reflection Probe in Window > Lighting, or add the component to an entity. Position it in empty space. Resolution (4–256) controls each cubemap face. Radius limits influence; Intensity scales HDR radiance; Blend Distance feathers the edge into the scene environment. Box Projection uses Box Size as world-space half extents for local parallax correction. Bake lighting captures contributing static triangles, analytic lights and the cached HDR environment, then generates GGX-filtered roughness mip levels. Realtime lights appear in the capture as a frozen snapshot; rebake if they change.

The four strongest overlapping captures blend per fragment. Moving a capture disables its stale result until rebaked or restored. Disabling it removes its contribution. Native material BRDF, roughness, AO, clearcoat and environment fallback remain in use. A scene without an environment uses a black fallback, not an extra light.

Material support

Built-in lit materials, original imported glTF PBR materials and cooked source surface shaders receive baked lighting. Imported textures and UV mappings are retained. Unlit materials and GUI overlays remain unlit. Source material compilation adds private engine parameters without adding them to the public material inspector. Existing precompiled opaque material packages must be rebuilt from source to participate; their bytecode cannot be safely rewritten.

Budgets and data lifetime

There is no 64-probe rendering cap. Up to 65,536 diffuse probes are supported as an explicit resource budget. A spatial lookup stores all overlapping influences; excessive overlap uses exact global lookup rather than silently dropping probes. The GPU atlas is bounded by hardware support and 4096×4096 RGBA32F texels. An oversized atlas reports an error and disables baked sampling. Split very large worlds into streamed cells.

MaxBakeTexels limits lightmap and reflection storage together (default 1,048,576, maximum 8,388,608). Lightmap Samples and Reflection Samples control integration quality independently of diffuse-probe samples. Baked vectors are stored losslessly as little-endian float32 data in YAML scene fields. Scene size is limited to 256 MiB; saves publish atomically, retaining the previous file on failure. Settings and results travel with scenes through cooking and streaming.

C++ controls

#include <Bazzalt/Components/Lightmap.h>
#include <Bazzalt/Components/ReflectionProbe.h>
auto& map = entity.AddComponent<Bazzalt::Lightmap>();
map.Resolution = 128;
auto& capture = probeEntity.AddComponent<Bazzalt::ReflectionProbe>();
capture.Resolution = 32;
settings.LightmapSamples = 16;
settings.ReflectionSamples = 64;
settings.MaxBakeTexels = 1048576;
auto radiance = Bazzalt::Lighting::SampleReflection(scene, position, direction, 0.5f);

All positions and directions are world-space. SampleReflection returns linear HDR RGB; roughness is [0,1]. Invalid vectors/settings throw. Lightmap and ReflectionProbe inherit Enabled. IsValid checks authoring values and payload consistency. BakedResolution records the result separately from the next-bake Resolution. Tools replacing Geometry, Texels or Radiance in place must call Lighting::Invalidate(scene) after editing; ordinary scalar changes and vector replacement are detected automatically. Apply and Clear invalidate caches themselves. Do not edit vectors concurrently with rendering or baking.
