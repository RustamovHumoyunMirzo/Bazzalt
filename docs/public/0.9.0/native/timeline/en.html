Cinematics in C++

Include Bazzalt/Timeline.h for sequence data, evaluation and controls. Include Bazzalt/Components/TimelineDirector.h to attach a Director. Scene installs TimelineSystem automatically. Timeline poses evaluate after scene animation and game logic and before camera rendering.

Build and play a sequence

auto actor = scene.FindEntityByName("Cube");
auto director = scene.CreateEntity("Intro");
director.AddComponent<Bazzalt::TimelineDirector>();
Bazzalt::TimelineSequence sequence;
sequence.Duration = 2;
Bazzalt::TimelineTransformTrack track;
track.Target = actor.GetUUID();
Bazzalt::TimelineTransformKey start, finish;
start.Value = actor.GetComponent<Bazzalt::Transform>();
finish = start;
finish.Time = 2;
finish.Value.Position.X += 5;
track.Keys = {start, finish};
sequence.Tracks.push_back(track);
Bazzalt::Cinematics::SetSequence(director, sequence);
Bazzalt::Cinematics::Play(director);

Sequence data

TimelineSequence owns Name, Duration, FrameRate, Tracks, Cameras and Signals. Validate checks time ordering, finite values, quaternion and scale validity, UUIDs, overlapping shots and resource budgets. FromSource parses version-1 YAML. ToSource writes a validated JSON-form YAML document. Load resolves a ready .btimeline asset through AssetManager.

TimelineTransformKey contains Time, Value and Interpolation. TimelineTransformTrack contains Name, Target, WorldSpace, Muted and Keys. Targets must be unique across transform tracks. TimelineCameraShot contains Name, Camera, Start, End and BlendIn. TimelineSignal contains Time, Name, Event and Arguments. A zero Event UUID creates a marker. Arguments use the same EventValue variants as GlobalEvent.

Director controls

Cinematics::SetSequence installs an in-memory sequence on a Director. Play starts at zero using its Loop and Speed fields. Pause freezes advancement. Resume continues a paused sequence. Stop restores transforms according to RestoreOnStop and returns camera control. Seek samples an absolute time in [0, Duration], with optional forward signal dispatch. GetStatus returns Time, Duration, Playing, Paused and Error. GetOutputCamera returns the temporary output camera entity or an empty entity. ConsumeEvents drains a bounded event queue. StopAll releases all scene Director players.

TimelineEventType includes Started, Paused, Resumed, Stopped, Completed, Looped and Signal. Each event includes Type, Time and Name. Restore On Completion emits completion followed by stop while preserving the final cursor time. Use GlobalEvent subscriptions for callbacks at authored cues, and ConsumeEvents for transport lifecycle observations.

Standalone evaluator and preview

TimelinePlayer takes a Scene reference and TimelineSequence value. Play accepts loop and speed. SetLoop and SetSpeed change playback settings. Advance accepts a nonnegative delta in seconds. Pause, Resume, Stop, Seek, GetStatus, GetOutputCamera and ConsumeEvents mirror Director controls. Stop accepts a restore flag. Destruction restores its captured scene state. A scene lifetime guard prevents later cleanup from dereferencing a destroyed scene.

Seek is silent by default. A stopped player can be evaluated again with Seek. A non-looping TimelinePlayer holds its final sample until Stop or destruction. Editor preview uses this evaluator without dispatching signals. Restore state before saving authoring scenes. See the Timeline manual for bindings, blending, limits and authoring behavior.
