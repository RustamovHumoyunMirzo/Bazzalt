Jobs

Include Bazzalt/Jobs.h for the shared CPU scheduler. A job is a function executed on a background worker. Use jobs for independent calculations on owned data. Scheduling does not make scenes or components thread-safe.

Schedule and wait

auto result = std::make_shared<std::vector<float>>(10000);
auto job = Bazzalt::Jobs::ParallelFor(result->size(), 256,
    [result](std::size_t begin, std::size_t end) {
        for (auto i = begin; i < end; ++i) (*result)[i] = float(i) * 2;
    });
// Other independent work can run here.
job.Wait(); // Results are now safe to read on this thread.

Schedule(work) returns a copyable JobHandle. The callback runs once. An empty callback throws std::invalid_argument. There is no guarantee of execution order or a particular worker. Results should use owned storage such as a shared pointer; exceptions are retained in the handle.

ParallelFor

ParallelFor(count, batchSize, work) partitions indices [0,count) into batches. Each callback receives begin and exclusive end. Batch size must be positive; empty work throws. Zero count executes no callbacks. At most the worker count of child jobs is submitted. Batches may run concurrently, so write disjoint elements and synchronize shared state. A failing batch stops its worker loop; already scheduled workers are joined before the first observed exception is rethrown by Wait. Some remaining batches may not execute after failure.

JobHandle

IsComplete() polls without blocking. Wait() waits and rethrows the callback exception; repeated waits are supported. A default handle is complete and waiting is a no-op. Destroying a handle does not cancel the job. A worker waiting for a child helps execute queued jobs, avoiding pool starvation in ordinary nested fork/join. Cyclic dependencies and waiting for a main-thread action can still deadlock.

Workers and teardown

GetWorkerCount() lazily starts the shared pool: hardware concurrency minus one, bounded to 1–8 workers. This conservative default leaves capacity for Filament, Jolt and audio; Jolt retains its own scheduler. WaitAll() is a host-thread barrier after producers have stopped submitting work. It does not consume exceptions; inspect each handle. Calling it on a worker throws a logic error. Native script teardown drains the owning module's jobs before destroying script instances; unrelated engine I/O is not joined by that barrier. Jobs retain their native module code, including nested jobs. Do not capture script objects or scene handles for asynchronous access.

Thread ownership

Never call scene/ECS mutation or queries, Lua, Qt, input, audio, or rendering APIs from worker jobs. Copy inputs on the main thread, calculate on workers, then apply results on the main thread after waiting. Native module retention protects code lifetime, not data lifetime. The pool drains at process teardown. There is no cancellation, main-thread continuation queue, or automatic parallel ECS execution in this foundation.

Public declarations

Header: Bazzalt/Jobs.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.

class Jobs {
Jobs() = delete;
static JobHandle Schedule(std::function<void()> work);
/// Runs [begin,end) batches; callback receives an exclusive end index.
    static JobHandle ParallelFor(std::size_t count, std::size_t batchSize,
        std::function<void(std::size_t, std::size_t)> work);
static unsigned GetWorkerCount();
/// Host-thread barrier. Stop producers first; never call from a worker.
    /// Exceptions belong to individual handles and are not rethrown here.
    static void WaitAll();
};
