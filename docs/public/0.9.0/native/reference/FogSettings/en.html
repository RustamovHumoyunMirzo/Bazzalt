FogSettings

Scene-owned atmosphere shared by Scene and Game cameras. Enabled defaults true. Exponential and Height use native depth fog. Volumetric uses a reduced-resolution froxel volume with height density, world-space animated noise, ambient scattering and anisotropic directional lighting. Steps controls 4–128 quadratic depth slices. StartDistance and MaxDistance use positive camera-forward depth; physical integration accounts for ray angle. A smooth one-to-five-unit fade follows a nonzero start. Density is inverse metres, distances/heights are metres, Wind is noise-coordinate velocity. AffectSky controls background fog, MaximumOpacity caps coverage. Noise and anisotropy apply only in Volumetric mode. No forced editor-only fog is applied. Edit a copy of SceneEnvironment.Fog and call Scene.SetEnvironment to validate and publish it.
