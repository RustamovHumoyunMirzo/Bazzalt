BehaviorTreeAgent

BehaviorTreeAgent declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Attach Bazzalt::BehaviorTreeAgent to an NPC and assign a .bbtree UUID to Tree. Loop restarts terminal trees; Enabled controls execution. Scene serialization, Lua component copies, inspector picking and cooked dependency retention use the same component.

See the behavior tree guide for complete usage and lifetime rules.
