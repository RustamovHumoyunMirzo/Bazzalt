LocalFog

Entity-owned oriented fog box. Size is full local width, height and depth; Transform including parents determines its world position, rotation and scale. BlendDistance softens box edges in local units. Fog holds the same FogSettings used by scene atmosphere, including mode, color, density, height, noise and light scattering. Enabled disables this component independently. Multiple volumes mix extinction and scattering before integration. IsValid validates dimensions and medium settings. Singular transforms produce no fog. Lua component values use Get/Set write-back.

Example

#include <Bazzalt/Components/LocalFog.h>

auto& fog = entity.AddComponent<Bazzalt::LocalFog>();
fog.Size = {12, 4, 8};
fog.BlendDistance = 1;
fog.Fog.Mode = Bazzalt::FogMode::Volumetric;
fog.Fog.Density = 0.08f;
fog.Fog.StartDistance = 0;
// Move/rotate/scale the entity using its Transform.
entity.SetComponentEnabled<Bazzalt::LocalFog>(false);
