CameraPostProcessing::DepthOfFieldSettings

Camera lens/blur settings. Depth of field blurs geometry away from the focus distance; enable both post-processing and this effect. Lua calls this type DepthOfFieldSettings.

C++ header: Bazzalt/Components/Camera.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/Camera.h>
struct DepthOfFieldSettings

Enabled

bool Enabled = false

Enables this depth-dependent blur effect; also requires camera post-processing.

FocusDistance

float FocusDistance = 10.0f

World-space focus distance, default 10. Surfaces away from it blur.

Aperture

float Aperture = 16.0f

Lens f-stop, default 16. Lower values increase blur, independently of exposure compensation.

ShutterSpeed

float ShutterSpeed = 1.0f / 125.0f

Exposure-model shutter time in seconds, default 1/125.

Sensitivity

float Sensitivity = 100.0f

Exposure-model sensitivity (ISO), default 100.

CocScale

float CocScale = 1.0f

Circle-of-confusion blur scale multiplier, default 1.

CocAspectRatio

float CocAspectRatio = 1.0f

Circle-of-confusion aspect multiplier, default 1.

MaxApertureDiameter

float MaxApertureDiameter = 0.01f

Maximum aperture-diameter setting, default 0.01.

Quality

DepthOfFieldQuality Quality = DepthOfFieldQuality::Medium

Low, Medium or High quality tier.

NativeResolution

bool NativeResolution = false

Whether to use native-resolution DoF processing, default false.
