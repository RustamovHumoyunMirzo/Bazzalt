PhysicsReplay

Scene-scoped physics checkpoints, deterministic fixed stepping and bounded in-memory recording/playback. Construct from a live Scene (Lua: ForScene). Checkpoints belong to one running world session and compatible physics topology/configuration. They capture solver state and physics-related poses, not scripts, game time, inputs or random generators. Playback requires AutoSimulation=false and explicit AdvancePlayback; seek does not emit collision callbacks.
