Subsystems

Find loaded C++ subsystems by registered type name, or obtain a checked shared project interface. Returned pointers and references expire when the subsystem is unloaded.

Lookup and lifetime

Find(name) takes the registered C++ type name and returns a non-owning Subsystem*, or null if it has not loaded. Get<T>(name) uses a checked dynamic cast to a shared project interface and returns T&. Missing instances or incompatible interfaces throw std::logic_error. Resolve dependent services at the proper startup level; lookup does not initialize a service. Do not keep results after session teardown.

Public declarations

Header: Bazzalt/Subsystem.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.
