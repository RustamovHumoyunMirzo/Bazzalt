HLOD

Authored hierarchical render proxy group. Sources and Proxies are disjoint child subtrees; nested source LOD/HLOD groups are supported. GetLOD exposes the equivalent two-level selection settings. IsValid checks property data; IsConfigured also requires both root lists. This does not bake or simplify meshes or disable simulation.
