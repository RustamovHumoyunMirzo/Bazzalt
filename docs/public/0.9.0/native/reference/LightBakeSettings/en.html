LightBakeSettings

Validated offline diffuse transport settings. Samples is 16..16384, Bounces 0..4, MaxTriangles 1..4000000. RayBias is positive and less than MaxDistance. AmbientRadiance is an explicit constant linear sky input; DefaultAlbedo is linear RGB in [0,1].
