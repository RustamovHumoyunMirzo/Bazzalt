Spline

Independent gameplay Bézier path. Each SplinePoint supplies a position, relative incoming/outgoing handles, up vector, scale and roll in radians. Zero handles form a linear segment. Parameters span 0–1, open paths clamp and closed paths wrap outside the interval. Distances and cached arc lengths use path-local units, approximated with 32 samples per span. Optional world matrices transform sampled poses and query positions. FindClosestPoint uses the sampled polyline. PlaceEntities applies full world poses in array order, handles parent/child arrays in hierarchy order, rejects duplicate/invalid/root entities and restores poses on failure. Mutations require caller synchronization with readers. Lua point indices are zero-based.
