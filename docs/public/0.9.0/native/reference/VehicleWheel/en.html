VehicleWheel

One independently configured wheel entity under a Vehicle chassis. Position is a chassis-local suspension attachment in metres and remains stable while the animated entity Transform moves. Radius/Width define the contact wheel, Inertia uses kg m², and AngularDamping affects spin. Requires WheelSuspension; omit separate rigidbodies and colliders. Mesh children can adapt imported model axes.
