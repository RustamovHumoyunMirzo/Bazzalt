BehaviorTree

BehaviorTree declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

AI::BehaviorTree is a move-only execution instance. FromSource/Load validate .bbtree XML, Initialize fills missing defaults, Tick advances a caller-supplied Context, and Reset cancels active work. In Lua, use Bazzalt.BehaviorTree.FromSource or Load, then Tick/Reset with an Entity, Blackboard and optional callbacks.

See the behavior tree guide for complete usage and lifetime rules.
