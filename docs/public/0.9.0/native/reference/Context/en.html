Context

Context declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Bazzalt::AI::Context supplies Self, Memory, DeltaTime and custom Action/Condition callbacks for a standalone tree tick. Self may be invalid during cleanup; test it before component access. The caller owns the blackboard lifetime.

See the behavior tree guide for complete usage and lifetime rules.
