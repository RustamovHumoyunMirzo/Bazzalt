Profiler

Include Bazzalt/Profiler.h for bounded CPU timing. Captures include all instrumented threads in this process. This measures elapsed CPU scope time, including waits; it does not measure GPU execution or memory allocation.

Capture

Bazzalt::Profiler::BeginCapture();
{
    Bazzalt::ProfileScope scope("Build terrain");
    BuildTerrain();
}
Bazzalt::Profiler::EndCapture();
Bazzalt::Profiler::ExportTrace("terrain-trace.json");

BeginCapture(capacity = 100000) replaces previous samples and starts recording. Capacity must be 1–10000000, otherwise invalid_argument is thrown. Memory is bounded by sample count, though long custom names increase storage. Only completed scopes are recorded. Scopes active when a capture stops or is replaced are discarded. EndCapture() stops recording and keeps results. IsCapturing() polls capture state.

ProfileScope

Create a noncopyable RAII scope with a name. Its destructor records elapsed time on the creating thread, even during exception unwinding. Names are copied only when capturing. Keep the object on its creating thread. Disabled scopes perform an atomic check without recording samples.

Samples and export

GetSamples() returns a synchronized snapshot of completed ProfileSample values: Name, StartMicroseconds relative to capture start, DurationMicroseconds, and Thread identifier. Nested durations overlap: do not add them as independent frame time. GetDroppedSampleCount() reports scopes rejected because the buffer was full; it resets with BeginCapture. ExportTrace(path) writes a snapshot as Chrome/Perfetto trace JSON. It accepts filesystem paths and throws on write failures. Stop capture first for consistent final results. File paths belong to the caller; parent directories are not created.

Engine instrumentation

Scopes cover runtime and editor frames, fixed physics steps, system callbacks, script updates, overlays, render submission/presentation and scheduled jobs. Rendering scope time is CPU submission/presentation, not GPU time. Worker thread IDs let trace viewers separate concurrent work.

Header: Bazzalt/Profiler.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.

class Profiler {
Profiler() = delete;
/// Starts a new bounded capture. Old in-flight scopes cannot enter it.
    static void BeginCapture(std::size_t capacity = 100000);
static void EndCapture();
static bool IsCapturing();
static std::vector<ProfileSample> GetSamples();
static std::uint64_t GetDroppedSampleCount();

    static void ExportTrace(const std::filesystem::path& path);
};
