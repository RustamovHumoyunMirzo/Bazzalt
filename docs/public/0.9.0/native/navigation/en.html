Navigation in C++

Include Bazzalt/Navigation.h and the component headers in Bazzalt/Components. Public types contain engine data only. Recast and Detour remain private to bazzalt_ai. Navigation is scene-owned and automatically steps during game simulation.

Bake and request movement

auto surface = scene.CreateEntity("Navigation");

auto& bake = surface.AddComponent<Bazzalt::NavMeshSurface>();

bake.Size = {40, 15, 40};

Bazzalt::Navigation::Bake(surface);

auto character = scene.FindEntityByName("Character");

auto& agent = character.AddComponent<Bazzalt::NavigationAgent>();

agent.Surface = surface.GetUUID();

bool accepted = Bazzalt::Navigation::SetDestination(character, {8, 0, 5});

auto state = Bazzalt::Navigation::GetAgentState(character);

Queries

CalculatePath(surface, start, end, areaMask) returns NavigationPath. Check Status before consuming Corners. Length is the sum of corner segments. SamplePosition(surface, position, extents, areaMask) returns NavigationHit with Found, Position and Distance. Sample hits leave Normal at zero. Raycast(surface, start, end, areaMask) reports a traversability boundary, its normal and distance. It is a NavMesh query. Physical queries live on Scene.

Controls and lifecycle

SetDestination returns false if no compatible surface or nearby target exists. ResetPath cancels movement. Warp places the agent at the nearest mesh position and returns success. GetAgentState reports status, navigation position, velocity, destination and remaining route length. Stopped retains the route with zero requested speed. Arrival is reported when the agent enters StoppingDistance. Blocked includes partial/failed routes and blocked physical movement. Navigation.Clear(scene) releases scene-owned navigation state. Scene unload and engine Stop clean it automatically.

Bake data and costs

Bake(surface) replaces the mesh transactionally from current scene geometry. Save(surface, path) atomically writes versioned little-endian .bnavmesh layer data. Load(surface, path) validates the entire file before replacing the mesh. LoadAsset(surface, uuid) resolves an imported bake. Data loads on simulation update. GetStatistics reports surface, tile, agent and obstacle counts and pending obstacle work. SetAreaCost(surface, area, cost) accepts areas 1–16 and finite costs from 1 to 100,000. Query area masks contain 16 bits. Mutating these APIs and components is an engine-thread operation.

Components

NavMeshSurface defines bake bounds, voxel resolution, agent clearance, slope/step limits, source mode and capacities. NavigationAgent defines the bound surface, physical dimensions, speed, acceleration, turning, stopping, area mask, origin offset, avoidance and transform ownership. NavigationObstacle carves an upright box or cylinder. NavMeshModifier assigns an area or excludes render geometry. See each API reference page for the complete member contract, and the editor Navigation guide for budgets and constraints.
