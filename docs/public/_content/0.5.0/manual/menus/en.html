Menus and play controls

The menubar operates on the editor/project. The play controls start and inspect runtime behavior; they are not scene-saving commands.

File

Open/load scene actions choose a scene asset, not another project. Save writes authoring scene changes; Save As chooses another scene file path. Project Settings edits project metadata. Exit closes the editor and can ask how to handle unsaved changes.

The Hub manages choosing/creating projects. A scene .bscene and project .bproject are different files.

Edit

Undo and Redo navigate authoring history. Other edit commands act on the current appropriate selection or editable field. Preferences opens editor-wide settings. A disabled action usually means it has no valid current target; selecting text in a field is not the same as selecting scene objects.

Object

Object contains selection and placement tools, including manipulation modes and snapping/alignment helpers. A snapping operation changes object placement; Frame/Focus view commands change the editor camera instead. Check the selection and pivot/local modes before a group operation.

View

Maximize Viewport enlarges the active viewport for focused work. Camera presets choose editor viewing directions. Focus Selected (F) frames chosen objects; Frame All (A) frames the scene, except movement keys are reserved while flying with right mouse.

Gizmos and overlays toggle editor handles, grid, icons, and statistics. Shading modes are diagnostic: Lit, Unlit, Wireframe, Lighting Only, and Overdraw help examine geometry/lighting/rendering. They are not automatically shader changes saved onto every material. A disabled NavMesh item does not indicate an implemented navigation system.

Window and Help

Window shows/hides panels and resets the workspace. Checkmarks indicate open/existing panels; a hidden tab is not a deleted scene. The current Help → About entry is disabled; do not treat it as a working information dialog.

Play, Stop, Pause, and Step

Play enters runtime execution, compiling enabled attached C++ behavior modules as needed. Lua source has already been imported into bytecode; Lua-only Play does not compile a native module. Read Console if entering Play fails.

Stop leaves runtime execution and restores authoring state. Pause/Step are controls for inspecting execution rather than changing the application's private loop from scripts. If a control is disabled, it is not applicable to the current play state.

Click Game output when testing player Input. Scene view's flying controls navigate the editor camera instead. Save authoring changes separately with File's save commands.
