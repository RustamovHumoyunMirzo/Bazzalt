Inspector

The Inspector edits whatever you selected: an object, a scene, or an asset. Empty content often means nothing is selected, not that a component disappeared.

Open it and select something

  1. Show the Inspector from Window if its tab is missing.
  2. Click a single object in the Hierarchy or Scene view.
  3. Read the selected name at the top before changing values. It helps avoid editing a different object than you intended.

Object components appear as stacked sections. Click a section header to expand or collapse its fields. A field is one editable value, such as a number, checkbox, vector, color, or asset reference.

Position, rotation, and scale

Transform's X/Y/Z fields describe three coordinate axes. Position moves the object, Rotation changes its orientation, and Scale changes its size. The editor presents world values; changing a child's field keeps that world-space meaning even under a transformed parent.

To type a value, click its input, enter the number, and confirm/leave the field. Do not confuse selecting text in a number input with selecting an object in the scene. Use Undo if you accidentally change a value.

In C++ the Transform component stores local values and quaternion rotation; the editor is a friendlier authoring display over those APIs. You do not need to type quaternion components merely to rotate a cube in the editor.

Add, enable, and remove components

At the bottom, Add Component opens a searchable list. Choose a component, then expand its section to edit it. An optional component has an enabled checkbox in its header. Turning it off retains the values while preventing its ordinary processing; it is not deletion.

The three-dot section menu contains supported remove and field-copy/paste actions. Required identity/name/hierarchy/transform data cannot be removed like an ordinary light or script. An already attached component/type cannot be added a second time.

Asset references

A material/model/texture field refers to a project asset. Drag a compatible item from Asset Browser into the field, or open the field's picker and choose a registered project asset. Pickers filter the expected type. A shader is not a material, and an image is not a model.

The field shows a name rather than its raw UUID. Clearing a reference removes the assignment, not the file. A component can still be enabled with an unassigned asset; that does not mean it has visible geometry.

Scenes and assets are different

Select a scene header for environment settings. Choose map/material mode first; the matching reference field is then relevant. Image-based lighting and skybox visibility are separate. A scene is not an entity, so it has no Add Component button.

Select an asset in Asset Browser for that asset's available details/settings, not the components of a scene instance. Editing a material asset can affect every object that references it; editing one object's Transform affects that instance.

Multi-selection and Play

When several objects are selected, shared editing can apply to the group. Select one if you need a full per-object component list. Locked objects cannot be edited through ordinary tools.

Play changes are runtime state. Stop restores authoring state; use editing mode and save the scene when you intend a lasting change. Temporary materials created by scripts do not automatically become saved material assets.
