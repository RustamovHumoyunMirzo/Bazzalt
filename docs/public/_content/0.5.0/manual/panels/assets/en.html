Asset Browser

Asset Browser shows the source files your project uses. Placing an asset into a scene creates an instance; it does not turn the file itself into a scene entity.

Folder tree and item area

Open Asset Browser from its tab or Window. The folder tree selects a directory; the larger item area lists that directory's contents. Click a folder to browse it. Use the search field to narrow the visible items and clear it when you want the full listing again.

An item's label normally hides its extension. Renaming displays the complete filename. A 3D preview is a generated thumbnail, not another interactive real-time game viewport.

Create and import files

Right-click the current folder/item area for the creation menu. A Scene creates a .bscene asset. Native/Lua behaviors create editable script source. Material creates material instance data. For models/images, add a supported source file beneath the project's asset directory.

The importer produces cached runtime data. A failed import appears in Console; the visible source file does not mean its cache is usable. Avoid renaming a random file extension to .bscene/.lua/.glb and expecting valid conversion.

Use an asset

  1. Select an entity and find its relevant asset field in Inspector.
  2. Drag a compatible Asset Browser item onto that field, or use the field's project picker.
  3. For a model, drag/place it into the Hierarchy to instantiate its node tree.

A field rejects wrong asset types. A shader goes into a material's Shader field, not a mesh's Material Asset field. A model file may contain many nodes that become separate child entities when instantiated.

Open and rename

Double-click a scene or choose Load scene to add it to Hierarchy; already loaded scenes are not offered for duplicate loading. Right-click supports rename, copy/paste and reveal-in-explorer actions where applicable. Reveal selects the actual disk file, while Open follows the asset's supported open behavior.

For C++ source, Open remembers the chosen application after the first selection. Open with always asks. Reset/change file association preferences when you want to use another source editor.

Keep metadata with assets

A matching .meta sidecar holds an asset's stable UUID. Keep it with the source when moving files outside the editor or committing project assets. Renaming in the browser preserves tracked identity; deleting metadata can break identity-based references on reimport.

Selecting is not editing an instance

Clicking an asset opens its asset Inspector. Clicking its placed entity in the Hierarchy opens that entity's components. Editing one instance's Transform does not rewrite the model file; editing a shared material asset can affect every instance using it.
