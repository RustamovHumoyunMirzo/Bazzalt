Console

Console lists log messages as individual entries. Use it to read script errors and import failures rather than guessing from a missing object.

Read one entry

Each entry has a message, optional level icon, and a source at its end. The source identifies who reported it, such as Editor or Compiler. Info, warning, and error are different levels; an iconless message can also be valid.

Click a row to select it. Rows support multi-selection and per-item context menus. Copy the actual error text/path when reporting a problem; an isolated screenshot of a red icon does not say which asset or compiler failed.

Filters and searching the cause

Filters is a multi-select dropdown rather than a row of independent filter buttons. Choose the levels you need, and use source filtering to limit messages from a subsystem. Filtering hides entries; it does not fix the error that produced them.

If the panel looks empty while you expect a failure, clear the filters before concluding no message exists. A script build may produce several related lines; read the earliest relevant error, not only the final “failed” summary.

Clear or remove messages

The controls include clearing messages, clearing the filtered set, and removing selected entries. Right-click a row for its supported actions. These operations remove console history, not source files, imports, or scene objects.

If you remove a recurring error entry, the underlying operation can report it again. Resolve the source/import/build problem instead of repeatedly clearing the panel.

Common situations

  • C++ Play fails: read Compiler messages for the source line and toolchain error.
  • Lua does not run: read import/runtime errors for invalid syntax, wrong component names, or script limits.
  • Model/material is invisible: check asset import readiness and shader/material references as well as camera placement.
  • Environment conversion fails: keep the reported source path and converter error; changing intensity does not repair an unavailable cache.

After fixing a source error

Save the source file, allow its import/compile to complete, and try the action again. Do not assume an old cached result replaced a failed import. See the Lua behavior guide or C++ behavior guide for minimal working examples.
