Initializing the Renderer

The renderer owns the GPU device, swapchain, and frame graph. Create it once at startup and pass it to every system that draws.

Creating a device

Describe what you need in a RendererDesc. BAZZALT picks the best available backend and falls back in the order you list.

#include <bazzalt/renderer.h>

using namespace bz;

int main() {
    Window window({ .title = "Sandbox", .width = 1600, .height = 900 });

    RendererDesc desc;
    desc.backends = { Backend::Vulkan, Backend::D3D12 };
    desc.vsync    = true;
    desc.msaa     = 4;   // samples per pixel

    // Returns nullptr on failure; see Renderer::LastError()
    auto renderer = Renderer::Create(window, desc);
    if (!renderer) return 1;
}
Info

The renderer must be created on the thread that owns the window.

Frame lifecycle

Each frame is recorded between BeginFrame and EndFrame. Submission happens inside EndFrame.

Render loop

while (window.IsOpen()) {
    window.PollEvents();

    renderer->BeginFrame();
    renderer->Draw(scene.View<Mesh, Transform>());
    renderer->EndFrame();
}
Warning

Calling Draw outside a frame is undefined behavior in release builds.

Entity Component System

Entities are lightweight IDs. Components are plain structs stored contiguously by type, so iteration stays cache-friendly.

Defining components

Any trivially copyable struct can be a component.

struct Transform { Vec3 position; Quat rotation; Vec3 scale{1.0f}; };
struct Velocity  { Vec3 linear; };

Creating entities

Scene scene;
Entity player = scene.Create();
scene.Add<Transform>(player, { .position = {0, 1, 0} });
scene.Add<Velocity>(player);

Querying

A view visits every entity that has all of the requested components.

for (auto [e, t, v] : scene.View<Transform, Velocity>().each()) {
    t.position += v.linear * dt;
}
Warning

Adding or removing components while iterating a view invalidates it. Defer changes with scene.Commands().

Shader Pipelines

A pipeline binds shader stages to fixed-function state. Shaders are compiled to SPIR-V offline and loaded at runtime.

Loading a pipeline

PipelineDesc desc;
desc.vertex   = Shader::Load("shaders/pbr.vert.spv");
desc.fragment = Shader::Load("shaders/pbr.frag.spv");
desc.depthTest = true;
desc.cull      = CullMode::Back;

Ref<Pipeline> pbr = renderer->CreatePipeline(desc);

Writing a fragment shader

Uniform layout

#version 450
layout(set = 0, binding = 0) uniform Camera { mat4 viewProj; vec3 eye; } cam;
layout(location = 0) in vec3 vNormal;
layout(location = 0) out vec4 outColor;

void main() {
    float light = max(dot(normalize(vNormal), vec3(0.3, 1.0, 0.2)), 0.0);
    outColor = vec4(vec3(light), 1.0);
}
Info

Run bzshader --watch to recompile on save and hot-reload pipelines in a running game.
