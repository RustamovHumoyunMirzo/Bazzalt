Application controls in Play mode

Application controls affect the running game, not the editor’s own window or initialization loop. A game’s quit request ends Play; it does not close your project.

Change game behavior

Frame limits and background behavior are configured by gameplay code. For the complete methods, arguments, defaults and errors, see the C++ Application reference or Lua Application reference. The programming guide contains examples.

Global event setup

Use Window > Global Subsystems to register project-wide C++ services. Ordinary entity scripts do not receive application lifecycle listeners. Errors appear in Console and stop the failed Play session.
