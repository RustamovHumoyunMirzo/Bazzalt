Author GUI layout and inheritance

GUI objects are ordinary hierarchy entities with GUI components. Use Hierarchy > Add New > GUI to create a Frame, container, rectangle, image, text, button or text input. Place widgets under a Frame; attaching a widget to the Frame object itself does not draw it.

Arrange children

Select a container in the Hierarchy and expand RectTransform in the inspector. Set Layout to Row or Column to position its direct GUI children automatically. Set Gap and Padding to create spacing, Align for cross-axis alignment and Justify for main-axis alignment. Insets use left, top, right, bottom order.

On each child, Size is its preferred size, MinSize/MaxSize constrain it, Margin reserves space, FlexGrow allocates extra room and FlexShrink controls shrinking. Ignore parent layout lets that child keep anchored placement. Absolute remains the default, so existing scenes do not move when loaded. A RectTransform on the Frame entity controls children without resizing the Frame surface. Reordering siblings changes flow order; ZIndex only changes drawing order.

Inherit a style value

For rectangles, expand Rectangle and enable the desired Inherit color/opacity/border checkboxes. Text offers inheritance for color, font size and wrapping; images offer tint-color inheritance. Put the source component on a parent, including the Frame root when useful. A text color inherits from parent text, not from a rectangle background.

Inheritance updates live when a parent changes. The inspector still displays the child's own local fallback value; changing that value while inheritance is enabled does not override the parent's effective value. Turn the inheritance checkbox off to use it again. Disabled sources are skipped, and inheritance never crosses the nearest Frame boundary. These edits participate in the normal scene save/dirty and undo history paths.

Programming and detailed rules

See C++ layout and inheritance or Lua layout and inheritance for examples and exact contracts. Rows and columns are single-line layouts for now; CSS stylesheets, automatic content measurement, wrapping and advanced fonts remain separate work.
