GUI layout and inheritance in Lua

Lua uses the same layout, inheritance and rendering system as C++. Read the layout and inheritance contract for units, constraints, frame boundaries and fallback behavior. The editor owns the loop and GUI initialization.

Create a responsive row

This code belongs inside an entity behavior callback where self.Entity exists. Lua component operations return copies: commit each edited component with SetComponent.

local B = Bazzalt
local scene = self.Entity:GetScene()
local hud = scene:CreateEntity("HUD")
hud:AddComponent("Frame")
local row = hud:AddComponent("RectTransform")
row.Layout = B.GuiLayoutMode.Row
row.Padding = B.Vec4.new(16, 12, 16, 12)
row.Gap = 8
row.Align = B.GuiAlignment.Stretch
row.Justify = B.GuiJustify.Start
hud:SetComponent("RectTransform", row)

local child = scene:CreateEntity("Panel")
child:SetParent(hud, false)
local item = child:AddComponent("RectTransform")
item.Size = B.Vec2.new(240, 80)
item.MinSize = B.Vec2.new(120, 40)
item.FlexGrow = 1
child:SetComponent("RectTransform", item)
child:AddComponent("Rectangle")

Inherit without losing local values

local parent = hud:AddComponent("Rectangle")
parent.Style.Opacity = 0.8
hud:SetComponent("Rectangle", parent)

local box = child:GetComponent("Rectangle")
box.Style.Opacity = 0.5 -- local fallback, preserved
box.Style.InheritOpacity = true
child:SetComponent("Rectangle", box)
local effective = B.GUI.ResolveStyle(child)
-- effective.Opacity is now 0.8; the local component still stores 0.5.

box.Style.InheritOpacity = false
child:SetComponent("Rectangle", box) -- visible opacity becomes 0.5

Text supports InheritColor, InheritFontSize and InheritWrap directly on GuiText. Image supports InheritColor directly on GuiImage. They inherit only from matching enabled ancestor components within the nearest Frame. GUI.ResolveText(entity) and GUI.ResolveImage(entity) return effective copies, preserving the child's own text or texture source. These functions do not write components.
