GUI stylesheets in Lua

Stylesheets are imported .css assets. Assign their UUID to GuiElement.Stylesheet for a whole GUI Frame, or GuiElement.Stylesheet for a subtree. A nested Frame starts a new scope. Existing explicit component fields remain authored fallbacks.

Assign metadata and styles

This example runs in a behavior callback. stylesheetUUID is an existing imported asset UUID selected by your game/editor code; it is not a path or source-code string.

local B = Bazzalt
local element = self.Entity:HasComponent("GuiElement")
    and self.Entity:GetComponent("GuiElement")
    or self.Entity:AddComponent("GuiElement")
element.Stylesheet = stylesheetUUID
element.ID = "play"
element.Classes = "primary wide"
element.Tags = "action navigation"
element.Attributes = '[state="active"]'
self.Entity:SetComponent("GuiElement", element)

-- After the next automatic layout, inspect computed values:
local text = B.GUI.ResolveText(self.Entity)
local bounds = B.GUI.GetBounds(self.Entity)
local diagnostics = B.GUI.GetStyleDiagnostics(self.Entity)

Rules and scope

Classes/tags are space-separated tokens, without leading dots. Attributes use presence/exact forms such as [disabled] or [state="active"]. Node types are Frame, Button, TextInput, Image, Text, Rectangle and Container. An empty ID uses the entity name. Tags are queried with [tags~="action"]. Actual input supplies hover, active, focus and disabled states.

See the complete stylesheet language/application contract for supported properties, asset references, inheritance and diagnostics. C++ and Lua receive the same computed results; there is no Lua-only CSS renderer.

Typed stylesheet inputs

Declare @require(name, default, type, ...); at a stylesheet root, then use require(name) in its rules. Assign that stylesheet to GuiElement to generate inspector fields, including typed project asset pickers. Scene saves retain per-element overrides. See the stylesheet input syntax and types for all declarations, bounds, vectors and enum options.

local B = Bazzalt
local fields = B.GUI.GetStylesheetProperties(stylesheetUUID)
assert(B.GUI.SetStyleProperty(entity, "accent", "#ff8844"))
assert(B.GUI.SetStyleProperty(entity, "caption", '\"Start\"'))
local value = B.GUI.GetStyleProperty(entity, "caption")
B.GUI.ResetStyleProperty(entity, "accent")

Values are CSS literals. String literals include their quotes; textures/fonts use asset("uuid") or none. Invalid values return false. These service methods update the actual entity directly; no component copy/write-back is needed. Field descriptors contain Name, Type, DefaultValue, Label, Tooltip, HasMinimum, HasMaximum, Minimum, Maximum and Options.
