AudioMixer

Runtime mixer routing, effects and snapshots. Load replaces mixer configuration transactionally. Snapshot application changes mix state while retaining current routing.

See the audio reference for units, ranges, errors, effect parameters and playback/routing behavior.

Lua members and signatures

Use Bazzalt.AudioMixer. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AudioMixer.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
