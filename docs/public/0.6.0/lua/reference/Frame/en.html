Frame

GUI root component. Only descendants render as its widgets: widgets attached to the Frame entity itself do not render. Supports viewport, camera-bound and spatial placement.

See the GUI guide for layout, rendering, component write-back and input examples.

Lua members and signatures

Use Bazzalt.Frame. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Frame.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
