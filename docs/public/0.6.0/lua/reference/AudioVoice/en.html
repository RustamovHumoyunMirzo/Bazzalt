AudioVoice

Non-owning playback handle. Stopped, completed, replaced or stolen voices invalidate it. Time and duration use seconds; Seek is absolute. Entity-owned component values overwrite persistent voice volume/pitch edits at the next synchronization.

See the audio reference for units, ranges, errors, effect parameters and playback/routing behavior.

Lua members and signatures

Use Bazzalt.AudioVoice. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.AudioVoice.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
