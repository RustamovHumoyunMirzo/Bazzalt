ConsoleFilter

Editor-console query and clear filter. Runtime Console calls are inert when no editor host is bound; reads return no value rather than gameplay data.

Lua members and signatures

Use Bazzalt.ConsoleFilter. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.ConsoleFilter.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
