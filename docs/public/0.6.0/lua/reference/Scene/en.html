Scene

Entities, hierarchy, environment and geometry queries in one scene. The host advances systems; gameplay cannot call the private scene update loop.

Underlying public header: Bazzalt/Scene.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

This is an enum/static service, host-owned scene, or returned behavior table, not a constructible Lua value. Use the static service or the host-provided value.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local scene = Bazzalt.SceneManager.GetActiveScene()
if scene then
    local cube = scene:CreateEntity("Cube")
    cube:AddComponent("PrimitiveObject")
end

Lua members and signatures

Use Bazzalt.Scene. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.Scene.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.

    }

template<typename SystemType>
    bool RemoveSystem();
[](Scene& value,const std::string& name){
        if(!value.HasSystem<LuaSystems>())return false;auto& systems=value.GetSystem<LuaSystems>();if(systems.Updating)throw std::logic_error("Cannot remove systems during system updates");
        auto found=systems.Entries.find(name);if(found==systems.Entries.end())return false;LuaSystems::Invoke(found->second.Object,"OnDestroy",value,0,false);systems.Entries.erase(found);return true;
    }
