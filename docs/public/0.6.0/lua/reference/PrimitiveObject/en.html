PrimitiveObject

Procedural renderable geometry. Shape decides which dimension fields are used. Entity Transform still controls placement, orientation and overall scaling.

Underlying public header: Bazzalt/Components/PrimitiveObject.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

In call notation, argument = default describes an optional argument and its default; Lua does not use named arguments here. Supply the value positionally or omit it. The C++ declaration below is comparison data, not Lua syntax.

Construction

Bazzalt.PrimitiveObject.new()

Each line is an accepted construction form. The argument names stand for values you supply; an empty call uses default values. Plain data types construct with their declared default fields.

Component values returned by Entity are copies. After changing fields or methods, call entity:SetComponent(typeName, value). Derived components inherit Component.Enabled, IsEnabled and SetEnabled; core Identity, Hierarchy, Name and Transform have entity-level restrictions.

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

local primitive = self.Entity:GetComponent("PrimitiveObject")
primitive.Shape = Bazzalt.PrimitiveShape.Sphere
primitive.Radius = 0.75
self.Entity:SetComponent("PrimitiveObject", primitive)

SetMaterial

value:SetMaterial(material)

Assigns a material UUID override. The Mesh slot overload targets a zero-based slot (0–4095); the single-argument overload overrides all slots. PrimitiveObject has only one slot.

Returns: no value.

ArgumentMeaning
Material materialOperand/value of the type shown in the declaration; see this method's behavior and coordinate-space description.

Invalid arguments and C++ exceptions are reported as Lua errors at the protected script boundary. Check the specific absence/false result rules above; not every missing value is an error.

Lua members and signatures

Use Bazzalt.PrimitiveObject. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.PrimitiveObject.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
