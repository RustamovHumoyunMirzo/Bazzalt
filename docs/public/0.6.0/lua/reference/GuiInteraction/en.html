GuiInteraction

Snapshot of a widget’s hover, press and focus states plus one-frame pointer/click/value/submit pulses. Poll during gameplay update rather than retaining pulses across frames.

See the GUI guide for layout, rendering, component write-back and input examples.

Lua members and signatures

Use Bazzalt.GuiInteraction. Each member below is actually registered in Lua. The adapter declarations are C++ binding notation, not Lua example code. sol::property exposes a field, sol::overload lists alternatives, sol::optional accepts an omitted/nil argument, and std::make_tuple returns multiple Lua values. sol::as_table returns a Lua table. Instance methods use value:Method(...); service/static calls use Bazzalt.GuiInteraction.Method(...) unless a colon overload is explicitly registered. An engine exception becomes a Lua script error. See the examples and behavior notes above for usage.
