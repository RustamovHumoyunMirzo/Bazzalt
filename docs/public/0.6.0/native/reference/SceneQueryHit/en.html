SceneQueryHit

Result of a scene ray/pick query. An empty Target means no hit; other fields describe the hit surface when valid.

C++ header: Bazzalt/SceneQuery.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/SceneQuery.h>
struct SceneQueryHit

Example

Gameplay snippets run inside a behavior callback or helper. Variables such as scene, camera, savedText and assetUUID are existing values, not automatically declared global variables.

auto hit = scene->Raycast(ray);
if (hit) { auto selected = hit.Target; }

Target

Entity Target{}

Hit entity; invalid means no hit.

Point

Vec3 Point{}

World-space hit point.

Normal

Vec3 Normal{}

World-space hit surface normal.

Distance

float Distance = 0.0f

Distance from the query ray origin in world units.

StartedInside

bool StartedInside = false

Whether the ray began inside the tested shape.

operatorbool

explicit operator bool() const

Tests handle/hit validity or nonzero UUID. This does not make a non-owning entity safe after its scene lifetime ends.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
