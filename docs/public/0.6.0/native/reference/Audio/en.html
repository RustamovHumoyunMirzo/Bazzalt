Audio API reference

Public headers: Audio.h, AudioClip.h, AudioMixer.h, Components/AudioSource.h and Components/AudioListener.h, all under Bazzalt/. Names below belong to namespace Bazzalt. Control operations run on the gameplay/main thread. The engine owns initialization, audio devices and shutdown.

AudioClip and AudioClipInfo

AudioClip is a copyable, non-owning UUID handle. Its default constructor represents no clip. static AudioClip Load(UUID) constructs a reference without decoding or playing. UUID GetAssetUUID() const returns that identity. bool IsValid() const checks for a ready Audio Clip in the active asset database. AudioClipInfo GetInfo() const decodes metadata from the cached asset; on failure it returns zero-initialized fields.

AudioClipInfo fieldMeaning
double DurationLength in seconds.
uint64_t FrameCountPCM frames; one frame contains a sample per channel.
uint32_t Channels1–8 channels.
uint32_t SampleRateFrames per second, in Hz.

Formats: WAV, MP3, FLAC, Ogg/Vorbis (.ogg/.oga). The file is imported and cached, with a .meta UUID; no audio device is required for inspection. File limits: 2 GiB, 8 channels, 8–384 kHz and 24 hours.

AudioSource

A local component, not inherited from a parent. Position/orientation use the composed world transform. Component Enabled controls the whole source; disabling removes its voice. bool IsValid() const validates settings and the custom curve, not clip existence. Public field writes are supported; invalid updates do not replace the last valid playing settings.

Field / typeDefault and behavior

AudioListener

Enabled listener with highest Priority wins; equal priorities use the smallest UUID. No listener means silent gameplay audio. Listener settings do not affect editor-only preview gain.

FieldDefault / meaning
float MasterVolume1, [0,1]; multiplies gameplay source output.
bool Muted / Pausedfalse each. Muted zeros gain; Paused preserves transport except for IgnoreListenerPause sources.
int Priority0; higher wins (unlike source voice priority).
float DopplerFactor1, [0,5].
float SpeedOfSound343.3, [1,10000] metres/second.
UUID MixerAssetEmpty; optional .bmixer asset selected when this listener becomes active.

AudioVoice

Default constructor is invalid; the explicit uint64_t constructor refers to an existing numeric handle but does not create playback. IDs are not reused across sessions. Completed, stopped, replaced or stolen voices invalidate their handles. These methods are const because a handle controls runtime state, not its own value.

AudioBus and AudioBusSettings

Copyable UUID routing handles. Default constructor is Master (UUID zero), not a null bus. static AudioBus Load(UUID) constructs a reference. UUID GetUUID() returns its identity; bool IsValid() checks current mixer membership. AudioBusSettings GetSettings() returns a copy, or default settings if absent.

AudioBusSettings contains UUID Id and Parent (both default zero), string Name ("Bus"), float Volume=1 and Pitch=1, bool Muted=false, Solo=false and Paused=false. Volume range is [0,4], pitch [.25,4], names 1–128 UTF-8 bytes. Master must have Parent zero. Up to 256 buses; cycles and missing parents are invalid.

Lifecycle and limits

Audio follows the active gameplay scene, not every scene loaded in the editor hierarchy. Sources/listeners do not inherit enable/disable from other components. Asset and component state is serialized; active voice handles/cursors are not. Audio transport and fades use unscaled real time; source pitch must be adjusted explicitly for slow motion. Per-source priority is 0 highest, unlike listener Priority where larger values win. No hardware/device control is exposed.

Read the C++ audio guide for examples and the editor guide for preview and mixer authoring.
