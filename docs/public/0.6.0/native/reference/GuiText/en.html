GuiText

GuiText declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

See the GUI guide for layout, rendering, component write-back and input examples.

Text style inheritance

InheritColor, InheritFontSize and InheritWrap default to false. When true, each property resolves from matching enabled ancestor GuiText components within the nearest Frame. Missing components are skipped, chained inheritance is honored, and no matching source leaves the authored value as fallback. Text Value is never inherited; color does not come from Rectangle background styles. GUI.ResolveText returns an effective copy without modifying the local component.
