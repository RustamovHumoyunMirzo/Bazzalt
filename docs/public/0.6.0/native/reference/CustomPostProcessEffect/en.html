CustomPostProcessEffect

One custom full-screen effect referring to a precompiled shader asset. Order controls its position in the camera stack.

C++ header: Bazzalt/PostProcessing.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/PostProcessing.h>
struct CustomPostProcessEffect

ShaderAsset

UUID ShaderAsset{}

Precompiled full-screen shader asset UUID.

Name

std::string Name

Optional effect label, not identity.

Enabled

bool Enabled = true

Enable flag; false retains the data while ordinary processing skips it. Required default entity components cannot be disabled through Entity APIs.

Order

int Order = 0

Execution order in the camera effect pipeline.

Parameters

std::vector<PostProcessParameter> Parameters

Named typed parameter values supplied to the shader.

SetParameter

PostProcessParameter & SetParameter(PostProcessParameter parameter)

Adds or replaces one named post-process parameter and returns its stored reference. Empty names throw. Lua edits Parameters on its copied effect value instead.

Result: the return type at the start of each declaration. void returns no value; bool reports true/false; & is a reference rather than a copy. Constructors create a value; deleted declarations cannot be called.
