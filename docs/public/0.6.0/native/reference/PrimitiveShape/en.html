PrimitiveShape

Available built-in procedural shapes; no model asset needs to be imported for these.

C++ header: Bazzalt/Components/PrimitiveObject.h.

Read signatures together with the behavior notes below. The reference introduction explains arguments, return values, value copies, and errors.

#include <Bazzalt/Components/PrimitiveObject.h>
enum class PrimitiveShape : std::uint8_t

Cube

Cube

Box geometry controlled by Size (X/Y/Z).

Sphere

Sphere

Sphere controlled by Radius, Segments and Rings.

Cylinder

Cylinder

Closed cylinder along local Y, controlled by Radius, Height and Segments.

Capsule

Capsule

Cylinder plus rounded end caps along local Y. Height is its central section; total length also includes two radii.

Plane

Plane

Flat local X/Z rectangle controlled by Width and Depth, facing local +Y.

Cone

Cone

Cone along local Y with a base cap, controlled by Radius, Height and Segments.

Torus

Torus

Ring controlled by MajorRadius, MinorRadius, Segments and Rings.
