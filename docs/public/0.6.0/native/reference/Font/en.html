Font

Font declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Handle and operations

Load(asset, face=0) creates a value handle to an imported Font asset and a zero-based collection face. It does not initialize the engine. GetAssetUUID and GetFaceIndex return that identity; a default handle has the root UUID. IsValid checks current asset readiness and face validity, so reimport can change its answer. GetInfo returns metadata by value; failure returns Valid=false and empty/zero fields.

MeasureText(text, size=16, wrapWidth=0) returns pixel advance width and line height as Vec2. Size must be finite and between 1 and 512; wrapWidth must be finite and nonnegative (zero disables wrapping). UTF-8 input is bounded to 256 KiB. Newlines, glyph advances and pair kerning are included. Invalid arguments/assets return zero size. Measurement includes HarfBuzz shaping and SheenBidi visual run layout, sharing cluster-based wrapping with GUI rendering. Store text in logical UTF-8 order and use a font covering its script. Limits include 65,536 decoded scalars; invalid/over-limit input returns zero. Use gameplay services on the engine thread.

Assign a handle through GuiText.SetFont, or assign its UUID and face to the Font/FontFace fields on GuiText or GuiTextInput. See the font guide for examples, supported formats and boundaries.
