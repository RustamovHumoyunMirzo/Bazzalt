FontInfo

FontInfo declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

Metadata fields

Valid is true only for a loaded supported face. Family and Style identify the selected face and may be empty if its naming tables do not supply them. FaceCount is the number of faces in the asset; FontFace is zero-based. GlyphCount is the number of glyphs in the selected face, not the number of Unicode characters. Scalable reports outline scaling support. Kerning reports basic FreeType pair-kerning support; it does not promise complex-script shaping. Invalid metadata has false flags, zero counts and empty strings. Values are snapshots and editing this value does not edit the asset.

Public declarations

Header: Bazzalt/Font.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.
