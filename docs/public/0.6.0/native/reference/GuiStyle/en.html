GuiStyle

GuiStyle declares the values and operations listed below. Types, defaults and overloads are part of its contract; it is not an editor panel.

See the GUI guide for layout, rendering, component write-back and input examples.

Per-property inheritance

The InheritColor, InheritHoverColor, InheritPressedColor, InheritDisabledColor, InheritBorderColor, InheritBorderWidth and InheritOpacity booleans default to false. A true flag resolves that property from the nearest enabled ancestor Rectangle; if that ancestor's flag is also true, resolution continues. Missing components are skipped. The nearest Frame is included, then traversal stops. If no source exists, the authored local value remains the fallback.

Each property is independent. Opacity is assigned, not multiplied. Local authored values and flags are never overwritten by rendering. Disable the flag to restore the local value. See GUI.ResolveStyle for effective copies.

Public declarations

Header: Bazzalt/GUI.h. Namespace: Bazzalt. Declarations below list public members, overloads, field types and default values. Inline implementation bodies and private storage are omitted. Inherited members are declared on the base type. A reference (&) is not a value copy; check lifetime notes before retaining it.

struct GuiStyle {
Vec4 Color{0.22f,0.24f,0.28f,1};
Vec4 HoverColor{0.3f,0.34f,0.4f,1};
Vec4 PressedColor{0.12f,0.22f,0.36f,1};
Vec4 DisabledColor{0.16f,0.17f,0.19f,0.7f};
Vec4 BorderColor{0.05f,0.06f,0.08f,1};
float BorderWidth=0;
float Opacity=1;
// Explicit, per-property inheritance. Local authored values remain unchanged.
    bool InheritColor=false,InheritHoverColor=false,InheritPressedColor=false;
bool InheritDisabledColor=false,InheritBorderColor=false;
bool InheritBorderWidth=false,InheritOpacity=false;
};
