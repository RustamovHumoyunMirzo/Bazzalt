Font assets and text rendering

Import a font into Assets, then assign it to GuiText or GuiTextInput. The private FreeType renderer rasterizes Unicode glyphs for viewport, camera-bound and spatial Frames. Gameplay never initializes FreeType or receives its handles.

Import and preview

Source extensions are .ttf, .otf, .ttc, .otc, .pfa, .pfb, .bdf, .pcf and .woff, subject to the actual file being accepted by FreeType and having a Unicode character map. Renaming an extension does not convert a font. Import creates a stable UUID, .meta and cached copy. Invalid files show the Asset Browser warning icon and inspector error.

Select a font to see family, style, face count, glyph count, scalable status and kerning availability. The inspector preview uses the runtime FreeType rasterizer, editable text, size and collection face index. It never installs fonts into the OS. Font fields use the project asset picker and support validated drag/drop, not a file-manager dialog.

Text fields

FieldContract
FontFont asset UUID on GuiText/GuiTextInput. Zero or unavailable references use the built-in bitmap fallback.
FontFaceZero-based collection index, default 0; serialized range 0–255. An index outside the selected file's faces is invalid.
FontSizeLogical GUI pixels, scaled by the Frame. Text accepts positive sizes through 512; input accepts 1–512. Actual raster sizes round up and clamp to 1–512.
GuiText.LetterSpacingAdditional logical advance, default 0; range −1000 to 1000.
GuiText.LineSpacingFont line-height multiplier, default 1; range 0.1–10.
GuiText.KerningPair kerning, enabled by default.
GuiText.InheritFontOpt in to Font/FontFace from enabled ancestor GuiText components within the nearest Frame. Authored local fields are preserved.

Missing glyphs use replacement/notdef glyphs or a fallback box. Fixed-size bitmap fonts choose a nearest strike and scale it when needed. Wrapping is based on glyph advances. Color fonts, complex-script shaping, bidirectional layout, ligature substitution and font-fallback chains are not implemented; Unicode decoding and FreeType rasterization alone do not provide them.

C++ example

Attach this behavior to a GUI text entity under a Frame. Pick the imported font in the script's Typeface field.

#include <Bazzalt/Script.h>
#include <Bazzalt/GUI.h>
#include <Bazzalt/Font.h>

COMPONENT(LabelFont) {
public:
    PROPERTY(Bazzalt::Font, Typeface, Bazzalt::Font{});
    void OnCreate() override {
        auto* text = GetEntity().TryGetComponent<Bazzalt::GuiText>();
        if (!text || !Typeface.IsValid()) return;
        text->SetFont(Typeface);
        text->Value = "Hello, world!";
        text->FontSize = 24;
        text->Kerning = true;
    }
};

Font service

Font is a non-owning value handle from Bazzalt/Font.h. Load(UUID, face = 0) creates a reference. IsValid checks a ready asset/face. GetInfo returns FontInfo: Valid, Family, Style, FaceCount, GlyphCount, Scalable and Kerning. Invalid handles return default information. Asset and library initialization are runtime-owned.

MeasureText(text, size = 16, wrapWidth = 0) returns pixel width/height with default spacing and pair kerning. Zero wrap width disables wrapping. Size must be finite, 1–512; wrap width finite and nonnegative; text is limited to 256 KiB. Invalid input returns zero dimensions. Measurement is independent of Frame scaling: supply the pixel size appropriate to your coordinate space. These operations run on the main gameplay thread.

CSS and live changes

Use font-family: asset("FONT-UUID") or url("asset://FONT-UUID") in a stylesheet. Font-size, letter-spacing, line-height and white-space map to GUI text too. Used fonts/stylesheets are watched for targeted, debounced reimport, including during Play. See stylesheets and Lua fonts.

Limits and shipping

Fonts are limited to 32 MiB, 256 faces and 200,000 glyphs. Renderers use bounded 1024×1024 RGBA glyph pages: up to 8,192 cached codepoints per page and 16 live font/face/size/revision pages. Unreferenced pages can be retired without destroying active samplers. Overflow uses fallback rendering instead of unbounded allocation. CPU face caches are separately bounded. Cooked builds retain fonts referenced by scenes and stylesheet dependency manifests.

No system font is redistributed by default. Projects must have permission to ship their chosen fonts. Runtime packages include the FreeType license and bundled zlib notice. FreeType is a private static dependency of bazzalt_gui, fetched through pinned get_freetype scripts; no FreeType DLL or headers are required by gameplay.
